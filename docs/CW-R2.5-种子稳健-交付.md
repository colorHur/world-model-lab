## §4 为什么只用一条判据（不重复计证）

`Δ2` 在 R2.4 是 **30/30 全正**。因此在 `sign(Δ2) ≡ +1` 下

```
#{u : sign(Δ2)=sign(Δ3)} ≡ #{u : Δ3>0}
```

⇒ "符号一致性检验"与"`Δ3` 符号检验"是**同一个统计量**，`p` 值逐位相同。
本轮**只报一次**。★ 若把它当两条证据写（"一致性 30/30" + "符号检验 p=9e-10"），
就是把同一个 `p` 加了两遍权 —— 这是 R2.4 之后最容易犯的新错，已写进预注册 §4.2 与 §8-1。

## §5 ★ 幅度：只有描述，**没有判词**（并给出量化理由）

| 量（`A_t`） | 数值 |
|---|---|
| `median|Δ3|` | **25.443** |
| `median|Δ2|`（R2.4） | 27.172 |
| 比值 `median|Δ3|/median|Δ2|` | **0.9364**（`A_T`：0.9869） |
| 逐单元比值 `|Δ3|/|Δ2|` 中位 / 最小 / 最大 | 0.9795 / 0.4168 / 1.5932 |
| `|Δ3| < |Δ2|` 的单元数 | 18/30 |
| `median f_S`（强臂换种子地板） | 1.1699（= R2.4 同值） |
| `median f_W`（弱臂换种子地板） | 2.6982 |
| `median|Δ3| / f_S` | 21.75 |
| `action_diff_frac`（`W3` vs `W2`）中位 | 0.3008（trace 30/30 不同） |

**为什么不出幅度判词**（`S4b` 定量）：`r` = 让 `beat` 掉到 `k_need` 以下的幅度缩放因子，
实测 **`r ≤ 0.001`**（落在网格下界，`_ERRATA` E2）⇒ 这条腿**只有在效应相对 `Δ2` 崩塌
≥1000 倍时才可能 FAIL**。它对"同量级 / 弱一点 / 弱一半"**完全没有分辨力**；
在这种情况下发一个 `p` 值，是在暗示一个不存在的分辨率。

★ 同时 `S4a`（MC 4000 次）证明：两种 floor 在 iid 噪声零假设下逐对 `beat` 率
**都是 `1/2`**（`0.5009±0.0926`、`0.4979±0.0917`）⇒ **零分布本身合法**，
拒发幅度判词的理由是**功效**，与零分布无关。这两件事不许混。

⇒ 允许写的最强表述：**"未见量级崩塌（中位 0.94×）"**。
**不许**写"幅度复现"、"效应量稳健"、"量级不变"。

## §8 本轮**自己的错**（含一条"我改了闸"的记录，请自行判断）

### 自伤 1（跑前，**最重**）：预注册里的论据被我自己的 MC 推翻

- 原卡 §4.3-2 写：`f_W` 与 `Δ3` 共享 `W3` ⇒ 逐对 `beat` 的 `1/2` 零分布**不成立**。
- `S4a` 4000 次 MC：`0.5002 ± 0.0910` ⇒ **就是 `1/2`**。
- 代数原因：`W2,W3,S3` iid 时，交换 `W2↔S3` 把 `(W2−W3, W3−S3)` 映到 `(−B,−A)`，
  联合律不变 ⇒ `P(|A|>|B|)=1/2`。**共享分量本身不破坏 `1/2`**。
- ★ **牵连到一次"改闸"**：`S4` 原写 `pass = 偏离>0.03`（即"我的论断成立"才算过）。
  数据出来后它 FAIL。我把 `pass` 改成 `≈0.5`，并把卡里的论断划掉。
  这个动作在形式上就是"为过闸改判据"，必须如实记，判断交给读者。可核查的事实是：
  ①主判 `C-SIGN-3` 一字未改；②改正留在 §10 跑前修订 1，**推翻它的原始数字原样保留**；
  ③面板**当时尚未跑**（`run_episode`=0），不存在"看了结果再改"。

## §9 局限（逐条，不许淡化）

1. **只换了 1 个备用种子**。`2001` 与 `3102` 两次采样同号、量级 0.94×，
   不等于"对一切种子稳健"。写论文时最多写"两个规划器种子下一致"。
2. **只测规划器噪声**（§2）。世界侧只有 30 个固定 ep，**没有扩大**。
3. **幅度无判词**（§5）。任何"效应量稳健"的说法都超出本轮证据。
4. 两臂都**不是学习模型**（零参数读后验 vs 只报先验）⇒ 本轮**不能**支持任何"世界模型有效"。
5. `A_t` 的未送达填补是"温和下界"，`A_T` 是整期惩罚；两个口径都过，但**没有第三个口径**。
6. 成本侧**没有改善**：3102 下 50/60 用户成本上升（§6）。
7. 30 个 `(plant,ep)` 单元已被 R2.1–R2.5 反复使用 ⇒ **不是**独立确认集。
