## §2 结论（按证据等级）

### 2.1 ★★★ `P-A` 被否证：3 用户 2 次发送**不**转正，而且**免费**探测也不转正

`b=16`（2 量子 = 2 次发送）在 **3 用户**上：`IV_free`（`p=0`）**逐位 `0.0`**，`p=1/4`、`p=1` 同样 `0.0`，
**4 个 `n_m` 点全部如此**。就是说：把探测当成**既不要钱、又不多占时间**（`τ=4` 有 4 槽，2 发送 + 1 探测 = 3 槽），
DP 仍然**一分钱都拿不到**。

⇒ 「人人能被服务时读数无用」（STATE §7.2 的原表述）**也不是**本轮的解释：3 用户 2 发送时**不是**人人能被服务
（3 人里只能服务 2 人），读数照样零。

### 2.2 ★★★ 真正的分界是**预算粒度 = 一次发送**，不是"发送/用户比"

同一 plant、同一 `n_m`、只改预算：

- `b=8`（1 量子，**只够一次发送**）：2 用户 `3.1456e-4`、3 用户 `6.1746e-4`，**两个用户数都为正**；
- `b=16`、`b=24`：**44 格逐位零**（含 2 用户、3 用户、两种构成、`p∈{1,1/4,0}`）。

⇒ 有价值当且仅当**整个预算只能换一次发送**。此时"发给谁"是全部决策，读数直接决定它；
一旦够两次发送，DP 用预算把候选**都覆盖**掉，读数不再改变任何动作。

**机制（假说，与 R3.4 的鞅恒等一致，但本轮没做路径统计）**：信息的期望收益只能来自"动作改变"
（`E[p_succ|信息] = p_succ|先验`，R3.4 `G8` 实测恒等残差 `1.11e-16`）。`G5` 在本轮直接测了这条：
在 3 用户 `b=16` 上把探测读数**整条丢掉**（`drop_obs`），`V` **逐位不变**（`dV = 0.0`）
⇒ 该预算下读数**不进任何取值路径**。

### 2.3 ★★ 3 用户读数比 2 用户大约一倍，但这是**跨实例**，不许当"多一个用户值多少"

`6.1746e-4 / 3.1456e-4 = 1.963`，折算成发送是 `0.206 / 0.105`。两个 `A0` 不同（`0.0944` vs `0.1494`，
目标函数是 `q·ΣP_i`，用户数不同）⇒ **只能报各自的比值**（`IV/A0` = `0.333%` vs `0.413%`），
**不能相减**说"第三个用户贡献 +0.10 次发送"。

### 2.4 ★★ 幅度的两轴收敛：`n_m` 四点 + `GH` 两档 ⇒ 真值区间约 `±5%`

- `n_m = 33 / 65 / 129 / 257` ⇒ `3.2201 / 2.9048 / 3.1457 / 3.1456 e-4`：
  **非单调**（`65` 凹 `7.7%`、`33` 凸 `2.4%`），但 `129` 与 `257` 只差 **`1.0e-5` 相对** ⇒ **已收敛**。
- `GH 21 → 41`：`3.1457e-4 → 2.9959e-4`（**`−4.76%`**）；3 用户 `b=16` 两档都是 `0.0`（符号不翻）。
- ⇒ 幅度口径：**`3.0–3.15e-4`（`n_m≥129`，`GH∈{21,41}`），即 `A0` 的 `0.32%–0.33%`，`0.10` 次发送。**

### 2.5 ★★ 更正 R5.1 的幅度：`0.0848–0.107 次发送` 的 21% spread **主要是网格**，不是"非单调"

把 R5.1 的四个 `n_m` 点（`17/33/65/129`）换成 `17/33/65/129/257` 后：
`2.5445 / 3.2201 / 2.9048 / 3.1457 / 3.1456 e-4` ⇒ R5.1 的 `2.544453e-4`（`n_m=17`）
比收敛值低 **`19.1%`**，而它当时报的"非单调、spread 21%"**在 `n_m≥129` 上消失**。

⇒ R5.1 当时"只报符号与区间、不报点值"是**正确**的（那时只有 `n_m≤129`，`129` 还没跑第二点）；
现在可以报点值了：**`0.105` 次发送（`GH=21`）/ `0.100` 次发送（`GH=41`）**。
**这不是"撤回"，是同一批格换分辨率后的收敛。**

## §5 对论文的影响（这一轮改变了什么）

1. **主结论的范围被砍掉一半**：信道测量的"决策价值"**只存在于单次发送区**。
   在 `(α=2.5, P=0.01, κ=1, τ=4)` 上，它的全部价值 = **`0.105`（2 用户）/ `0.206`（3 用户）次发送**，
   占 `A0` 的 **`0.33%` / `0.41%`**；预算一旦够两次发送，价值**逐位归零**（不是"很小"）。
2. **论文里"预算受限"这五个字必须写成"整数发送粒度"**：可执行的自变量是 `floor((b−8p)/8)`、
   可用发送次数、以及**是否只够一次**；名义单价在 `(0,1]` 内不改变任何东西（R5.1 已证）。
3. **可以给点值了**：`0.105 次发送`（`GH=21`，`n_m≥129`），误差口径写"`n_m` 收敛 `1e-5` 相对、
   `GH` 节点 `−4.76%`"。R5.1 的 `0.0848–0.107` 区间作废（那是 `n_m` 分辨率，见 §2.5）。
4. **仍然不能说的三件事**：不能说"预算受限下测信道值得买"（没有一条格过 1 个量子）；
   不能说"多用户放大信息价值"（跨实例）；不能说"2 次发送时读数无用是因为对冲"（只到价值层，无路径统计）。

## §6 交接三句话

1. **本轮新证据使项目更接近哪个具体结论**：更接近「读数的价值是一个**单次发送区**现象，幅度 `0.10–0.21` 次发送、
   `A0` 的 `0.3–0.4%`，跨过两次发送即逐位归零」——这是论文里可以直接写成条件句的一条。
2. **它还没有排除什么解释、不能支持什么结论**：没有排除「`τ≥5` 的更长窗口下 2 次发送会用上读数」
   （只扫了 `τ=4`）；没有排除「别的 `σ_w` / `P` / `κ` 下 2 次发送会用到读数」；
   没有任何策略路径统计，所以"对冲使读数无用"只是**假说**；也不能把 3 用户与 2 用户的 `IV` 相减。
3. **用户可以从中练习哪一个判断**：**"我给机制起名字的时候，名字里的每个词是不是都能被自己的数据打掉？"**
   —— 我把机制叫「收件人选择自由度（发送次数 < 用户数）」，数据告诉我 `2/3` 也是零 ⇒ 名字里的
   "发送次数 < 用户数"这半句是**我自己编的**，不是数据给的。正确的名字是"**预算只够一次发送**"。

## §7 下一轮建议（不是本轮结论）

`CW-R5.3`：把"单次发送区"这条边界**从 `τ` 那一侧钉住** —— 固定 1 次发送（`b=8`、`p=0`），
扫 `τ ∈ {2,3,4,5,6}`（规模随 `τ` 指数 ⇒ 先算整腿，`n_m` 只取 `{65,129}` 两点）。
可证伪预测：`τ=2` 时"先探测再发送"没有余槽 ⇒ `IV=0`；`τ≥3` 转正且随 `τ` 上升。
**不许**拿它去找"2 次发送也行"的参数组合（那是调参数追正收益）。
