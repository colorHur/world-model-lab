## §1 判词（一句话）

**`A-RECONSTRUCT-EXACT` + `B-HEADROOM-PRESENT` ⇒ 合并结论 `R2-BELIEF-CLOSED-FORM`。**

- **A 支**：视图里的 `telemetry.x_hat / P_hat` 可以**只用公开历史（13 键白名单）中的 3 个键
  （`data_delivered / user / y_t`）＋协议公开常量**逐位重建，6/6 跑的最大绝对误差 **`0.0`**（不是 `1e-12`，是**逐位**）。
  ⇒ R2.7 卡 §7.2 的 A 方案（"去掉 `x̂/P̂` 输入、让模型从历史重建"）**信息缺口 = 0**：
  目标是输入的确定性函数，学它只能是**重复实现**。
- **B 支**：把 `A` 变成未知（`A = 1 ± w`），参数自适应（5 点精确混合卡尔曼 `mmkf`）相对名义参数滤波器
  （`plug`）的 MSE 收益：`w=0.5%` 时 **0.03%–1.90%**，`w=2%` 时 **2.58%–45.79%**（6 格中 5 格 CI 不含 0）。
  ⇒ "参数不确定性值多少"这件事**有真实量级**，但它属于**估计器设计**，不属于"学习"：
  `mmkf` 在**离散 θ** 下是**精确**贝叶斯 ⇒ 任何只吃同一信息的学习模型对它的期望上界是**打平**。
- **合并**：信念层的最优估计**可闭式算出且成本极低**（5 条标量卡尔曼）⇒
  **在本协议下，"强模型 vs 小学习模型"这场比较没有一个"学习能赢"的对手**。
  这不是"世界模型无用"（见 §6 边界），是**本协议没有给学习留位置**。

### 3.1 补充诊断（`r2_8b`，跑后，**无判词**）：`h_B` 不是只由 `A>1` 一侧撑起来的

| `w_A` | `p` | `A<1`（`h_B`） | `A>1`（`h_B`） | 读法 |
|---|---|---|---|---|
| 0.005 | 0.5 | +0.72% | +3.04% | 两侧都小 |
| 0.005 | 0.1 | +0.16% | +0.73% | 两侧都小 |
| 0.005 | 0.02 | **−0.14%** | +0.19% | 符号相反、量级 = 地板 |
| 0.02 | 0.5 | **+17.59%** | **+58.40%** | 两侧都正，不稳定侧更大 |
| 0.02 | 0.1 | +1.52% | +25.91% | **主要来自不稳定侧** |
| 0.02 | 0.02 | **−4.86%** | +5.30% | **两侧符号相反** ⇒ 聚合的 +2.58% 是两种相反效应的混合 |

⇒ 两条必须写进结论的话：
1. `w=2%,p=0.5` 的 45.79% **不是**单侧的伪影（`A<1` 侧仍有 +17.6%），但**不稳定侧贡献更大**；
2. `p=0.02` 那格的聚合值 **不可单独引用**（两侧符号相反，聚合掩盖了"边缘化在稳定侧反而更差"）。

## §5 自伤（本轮 6 条，逐条写"下次怎么防"）

1. **B 支设计被三次 dry run 推翻**（预注册 §9-A1）：原卡写 `u=−K·x̂` + `A∈[0.90,1.10]`，
   第一版实现后立刻看到 `MSE ~ 1e2`（`A>1` 且无控制 ⇒ 指数发散），第三版才定成"开环 + 窄不确定性剂量表"。
   **防**：写 B 支之前先算 `A^T` 的量级（`1.1^64 = 445`），一个乘法就能否掉整个设计。
2. **dry run 的数字污染了预注册**（R2.7 §7.5-4 已立规，本轮再犯）：`w_A` 从 10% 收到 2% 是在看过
   dry run #1/#2 之后定的。处置 = §9 把三次 dry run 的**当时所见**全表披露 + 正式面板换更大样本；
   但**必须承认** `w_A` 的取值受了已见数字影响，读者应据此打折。
3. **`S10` 判据本身写错**：原写成"每格地板 ≤ `h_B/5`"，与 `judge()` 的判词条件**重复**，
   并把"这一格效应本来就小"判成程序缺陷。已改为诊断门槛（`floor_rel < 5%`）。
4. **合并判词标签与自己写的 §7-3 冲突**：`LEARNING-SPACE-AT-UNKNOWN-PARAMS` 暗示"学习有空间"，
   而 `mmkf` 是精确贝叶斯 ⇒ 学习只能打平。代码里两个标签都落盘（`overall_prereg` / `overall_corrected`），不覆盖。
5. **诊断脚本第一版随机流错位**：漏抽了 `b_cell` 里的 `Z2`，`D` 流错位 ⇒ 聚合 `h_B` 差 **1.1 个百分点**。
   被 `D1`（与主面板逐位对账）当场抓住。**教训**：只要是"同一套数的第二份实现"，就必须有一条
   "与第一份逐位相等"的闸，否则两个实现各说各话。
6. **首跑崩在 JSON 序列化**（`StreamIDs` 不可序列化），白跑约 2 分钟；
   崩点在 `mkdir` **之后**、`panel_a` 落盘之前 ⇒ 未丢数据，但违反"一跑完即落盘"的省事写法。

## §6 边界（不许外推的三处）

1. **A 支的"精确"是数值事实，不是数学定理**：它证明的是"**这份实现**的 `x̂/P̂` 是公开历史的确定性函数"。
   它**不**证明"视图没有别的问题"（那要另立闸），也**不**说明"信念没被用过"。
2. **B 支的抽象很粗**：`p_deliver` 外生、`A` 是唯一未知量、θ 先验是 5 点离散、开环 `u≡0`。
   `w_A` 只能到 2%（再宽 `|x|` 就按 `A^T` 放大，MSE 被轨迹尺度主导）。**闭环下的同类量未测**。
3. **`h_B = 45.79%` 不是"学习模型能拿到的收益"**：它是"参数自适应估计器 vs 名义参数估计器"的差距，
   而 `mmkf` 本身可算且便宜 ⇒ 学习模型的对手是这个解析滤波器，**不是** `plug`。
   把它写成"学习有 45% 的空间"是**错的**。

**不许写的话**（照抄进任何汇报前先看这一条）：
- 不许写"世界模型无用" —— 本轮只否证**本协议信念层**的学习空间。
- 不许写"参数未知没有价值" —— B 支实测有量级。
- 不许写"学习模型能拿到 B 支的收益"。
- 不许把 `oracle` 臂当上界（它只是"知道真 θ"的诊断）。
- 不许写"R2 失败" —— R2 得到的是**结构性的负结果 + 判据**，这正是 v4 §8 表 `R2` 行写的出口（"无则重审模型必要性"）。
