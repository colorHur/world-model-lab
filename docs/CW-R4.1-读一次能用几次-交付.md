## 0. 一句话结论

把信道从快衰（`ρ=0.85`，去相关 6.15 槽）一路拉到近静态（`ρ=0.999`，去相关 999.5 槽），
**完美 CSI 的毛价值只从 `0.114` 涨到 `0.162` 个量子（+42%），而按 `1/(1−ρ²)` 的有效期定律本该涨 138.8×**；
而且 **`ρ≥0.98` 就饱和**（0.1552 / 0.1603 / 0.1617，彼此 ≤4.2%）。
按 1 个量子出售，**210/210 格 `IV_paid` 比特零** ⇒ **"读一次能用多久"这条轴救不了它**。

R4.0 的"边界是价格"因此**加强**，但价格门槛要修订：
**从 ≤0.106 改为 ≤0.162 个量子（便宜 6.2×）**；在 `ρ=0.85`（v1.1 的档）上是 **≤0.114（便宜 8.8×）**。

## 4. 机制：有效期定律**为什么**破（这是本轮真正的发现）

`P-A` 的推导错在**把"读数能活多久"直接当成"能多服务几次发送"**。价值要落地，必须有一个
**尚未花掉的发送**去用它；而本面板 `τ≤5`、`b≤4`：

1. 峰值格是 `b=1` —— **单次发送的时机问题**（这一次发在哪个槽）。读数一旦**覆盖整个窗口**
   （`ρ≥0.95` 时 `1/(1−ρ²)≥10.3 > 5`），"更耐放"就没有第二个发射机会可服务 ⇒ **饱和**。
2. 饱和在数据上就在 `ρ≈0.98`：0.1552 → 0.1603 → 0.1617（+3.3%、+0.9%）。
3. `b=2` 的格在慢衰下**从 0 变正**，说明"一次读数服务多次发送"这条通道**存在**，
   只是窗口太短、基数太小（0.044 量子）。

★ 因此 `P-A` 的否证**有明确边界**：它否证的是「在 `τ≤5`、`b≤4` 的窗口里，记忆长度能把
完美 CSI 的价值放大到 1 个量子」，**不是**「有效期机制不存在」。
**窗口 ≫ 有效期**（`τ≥6` 且 `b≥3`）的格子本轮**没扫**（状态爆炸，见 §6）——
这句话必须与负结果同报，否则就是把"窗口太短"写成"信息不值钱"。

## 5. 对旧轮次的更正（保留旧证据，只加指针）

1. ★ **R4.0 的价格天花板 `0.106` → `0.114`**（`ρ=0.85`、`n_m=129` 收敛值）。
   **不是结论变，是数变了**：R4.0 报的是 `n_m=65` 的读数，而它自己的 `B3b` 已显示 `65→129` 有 **7.59%**
   偏差（当时判"稳定"是对的，但**写进标题的数取了粗格**）。本轮补第三点 `257` 证明 `129` 已收敛。
   ⇒ R4.0 的"便宜 9.5×"应写 **8.8×**；本轮静态极限是 **6.2×**。方向、判词、`IV_paid≡0` 全部不变。
2. ★★ **R4.0 的机制句"用户间噪声不对称是毛价值的来源"只在快衰下成立**。
   `α=1`（对称 plant `σ_w=(0.02,0.02)`）的 `IV_free`：`ρ=0.85/0.90/0.95` 三档恒 **1.39e−17**（比特零），
   但 `ρ=0.98` 起转正：`0.0115`（@129）、`ρ=0.995` `0.0157`、`ρ=0.999` 腿未跑 `α=1`（未扫）。
   机制：慢衰时「知道公共信道状态 ⇒ **选时机**」本身就值钱，**不需要**用户间不对称。
   **幅度只有同档天花板的 7.4% / 9.8%**，所以它把 R4.0 的机制句**限量改写**为：
   *快衰（`ρ≤0.95`）下毛价值只来自用户间噪声不对称；慢衰（`ρ≥0.98`）下多出一条"公共信道的时机价值"，量级小一个数量级。*
3. `R3.5`/`R3.2` 的结论**不动**：`(m,v)` 在 `exact` 下非充分（ACK 不进信道信念）、`SCALE-EXPLODES`
   都成立于各自的条件，本轮没有触碰。

1. ★★★ **refine 的靶子取错（第 6 次"无靶子"同族）**：`meta["argmax_ratio"]` 写成

   后果：首跑 `refine` 挑中全 0 格，`(max−min)/max = 0/0` 被写成 `spread_rel=0.000`，
   **`R6` 判 `GRID-STABLE` —— 假通过**（分母 0 的"稳定"）。
   修复：`max(fin, key=)` + 新增闸 `gate_g_argmax_consistent` + `skipped="no-target-below-floor"` 分支；
   **变异测试**：拿首跑的实况 `meta` 喂新闸 → **11/11 转红**（`pass=False`），闸有分辨力。
2. ★★★ **两点分辨率判据分不清"粗格量化偏置"与"不收敛"**：预注册只写 `n_m∈{65,129}`，
   `R6` 因 `α=1` 的小数（`0.0042→0.0115`）判 `GRID-DEPENDENT`（相对差 63%）。
   补第三点 `257` 后：`129` 之后**完全收敛**（gap `≤7.07e−6`）⇒ 那 63% 是 `65→129` 的**一次性偏置**，
   不是"还在动"。**新规则：分辨率检查必须三点起步，两点只能报"有偏置"，不能报"稳/不稳"。**
3. ★★ **主面板读数用 `n_m=65`（沿用 R4.0 口径）**，天花板因此**低估 6.0–7.7%**。
   本轮两个数都报；判词方向已逐条核过用 129 值重算不变（单调、饱和、`IV_paid≡0` 与网格无关——
   后者是**比特零**，不受量化影响）。
4. ★ **`Arms.sec_build` 只计构造、不计求值**（`lru_cache` 惰性）⇒ 证据里 `sec_build≈0.001` 别当耗时；
   真实耗时只有 `sec_total`。
