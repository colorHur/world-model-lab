## 2 本轮真正新增的两件事

### 2.1 交换率测出来了：一个量子 = 一次发送（`J-A`）

`ΔV_q ≡ V(b−1) − V(b)`（成本降幅 = 多一个量子的价值）与 `p̂·ΔV_succ`（一次发送的期望收益）之比，
`b=1` 的 16 格：**`1.000, 1.000, 1.000, 1.000, 1.041, 1.008, 1.003, 1.000, 1.055, 1.011, 1.004, 1.000,
1.087, 1.013, 1.004, 1.000`**（`τ=2..5` × `P∈{0.005,0.02,0.05,1.0}`）。
⇒ **`ΔV_q ≈ p̂·ΔV_succ` 是实测恒等式，不是假设**；这条恒等式让"探测要不要买"变成**无量纲**比较。

`ΔV_succ` 本身也有物理读法：`τ=4,P=0.005` 时 `1.580e-3 ≈ q·g·P·(τ−1) = 1×0.111×0.005×3`（**一次成功 ≈ 把 `P` 的 `gP` 降幅保持 `τ−1` 个槽**）。

### 2.2 判据：`(b − c_probe)·Δp̂_UB > p̂`（推导 + 两侧实测）

DP 在每次发送处对 `p̂` **线性** ⇒ 知道更多带来的收益 = `Δp̂ · ΔV_succ · 受影响发送次数`。
探一次最多影响探完剩下的 `b − c_probe` 次发送 ⇒

    增益 ≤ (b − c_probe) · Δp̂_UB · ΔV_succ ，代价 = ΔV_q ≈ p̂·ΔV_succ
    ⇒ 买得起 ⇔ (b − c_probe) · Δp̂_UB > p̂        ← 槽不在里面

`Δp̂_UB`（`v=1, σ_csi=0.05`，网格 1601 点）= **0.13865**，`p̂ = 0.5` ⇒ **`b* = 4.606`，即需 `b ≥ 5`**。
`Δp̂_UB` 随先验（`σ_csi=0.05`）：`v=1 → 0.13865`、`0.25 → 0.08658`、`0.05 → 0.03588`、`0.01 → 0.00756`
⇒ `b* = 4.61 / 6.78 / 14.94 / 67.1`。**先验越窄，探测越买不起**（`v` 从 1 掉到 0.01 使 `b*` 涨 14.6 倍）。
`σ_csi` 敏感性（`v=1`）：`1e-3 → 0.13899`、`0.05 → 0.13865`、`0.2 → 0.13370`、`0.5 → 0.11106`（**松到 0.5 只掉 20%**）。

**两侧实测（本轮唯一能测阈值的地方）**：

| 格 | `UB_paid/ΔV_q` | 实测 `IV_paid` |
|---|---|---|
| `τ=4, b=3, P=0.05` | 1.81 | **0** |
| `τ=4, b=4, P=0.05` | `ΔV_q = 0`（预算饱和，判据不适用） | 0 |
| `τ=5, b=4, P=0.05` | 4.16 | **0** |
| `τ=5, b=5, P=0.05` | `ΔV_q = 0` | 0 |
| `τ=6, b=5, P=0.02`（粗网格 `n_m=65`） | **5.64** | **0** |
| `τ=6, b=5, P=0.005`（粗网格） | **2.37** | **0** |

⇒ **判据在"能买"一侧错得至少 2.4–5.6×**。缺的那部分正是被上界丢掉的三样：
① 读数的**信念衰减**（`m'=ρm`，`ρ=0.85`，每槽把信息折掉 15%）；
② 每一拍只有 2 个候选用户，**排序翻面的概率**远小于 1（盲选本来就有 50% 蒙对）；
③ `snap` 量化（`n_m=65` 的步长 `0.125` > `σ_csi=0.05`）。

★ **所以这条判据只能**单侧**用**：`(b−1)Δp̂_UB ≤ p̂` ⇒ **可以**下"买不起"（`J-C` 31 格支撑）；
反过来 `(b−1)Δp̂_UB > p̂` ⇒ **不能**下"买得起"（`J-D` 直接反例）。

## 3 对 R3.2 机制叙述的更正（本轮最主要的自我更正）

R3.2 的 §7.1 第 5 条写「`SEND` 弱支配 `HOLD` ⇒ **探测的真实代价是"一个槽"，不是"一个量子"**」。
本轮实测**否定这个说法**：

1. **免量子（`c_probe=0`）时探测确实会被选上**：`(τ=4,b=1,P=0.005)` 首步最优动作是 `PROBE_1`
   （`4.692067e-2` < `SEND_0` 的 `4.696667e-2`），净赚 **4.600e-5**；`(τ=5,b=1,P=0.005)` 净赚 **1.814e-4**。
   ⇒ 若"槽"是唯一致命成本，免量子探测**永远不该赢**。
2. **真正的障碍是量级比**：免量子增益 = `4.6e-5`，而一个量子 = `8.333e-4` ⇒ **5.5%**。
   信息对"这一次发送"的定价上限是 `p̂·ΔV_succ`，而信息只能影响"发给谁"这一件事 ⇒ 差的不是资源种类，是**被买的东西太小**。
3. **槽的作用是二阶的**：`drop_obs` 阴性对照（探了读数但丢掉）实测 `V_noprobe − V_drop = 0.0`（逐位）
   ⇒ 探测动作退化成纯 `HOLD`；而**有读数**时 `4.79e-5 > 0` ⇒ 增益**全部**来自读数，不来自"多一个动作"。

**更正口径**（写进 STATE 与后续引用）：**"探测的代价是一个槽"应改为"探测的代价是一个量子，
而它买到的信息只值 `Δp̂·ΔV_succ ≈ (0.14 / 0.5) × 一个量子 ≈ 28%`（上界）、实测 `5.5%`"。**
R3.2 §7.1 第 5 条保留原文，加更正指针（旧证据不删不改）。

## 5 自伤（本轮 8 条，逐条可复现）

1. **`J-A` 的容差设错方向可用**：首跑把 `τ=6` 主环跑进 `state_cap`（`6.000010e6`）⇒ 一批 `NaN`，
   而 `J-D` 差点被 `THRESHOLD-REFUTED-AT-6` 这条**从缺失数据里编出来的判词**写进交付（已当场收回）。
   ⇒ 固化：**判词函数必须先滤 `NaN` 并报 `n_cells_dropped`**。
2. **`τ=6` 可算性判断错误**：用**单条查询**（3.45e6 状态）推断"面板可算"，
   面板要查 `b=1..6` × 4 个 `P` ⇒ 立刻撞顶。⇒ 固化（第 2 次同族）：**规模要按"面板查询集"估，不按单点估**。
3. **`G1`（AST）假阳性**：把局部变量 `h_true`（先验抽样点）当成"读真值字段" ⇒ 改名 `h_prior`。
   **改名不是放松闸**（闸的白名单一字未动），但必须在这里写明。
4. **`G2` 容差 `1e-4` 不现实**：`max(·)` 拐点使 GH 慢收敛且在 `321` 点仍低 `0.37%`；
   改正为"网格 1601 点为参考 + 报 GH 偏差"，并把 `b*` 的带宽算出来（`4.60606–4.60632`）。
5. **`G6` 两个臂写反**：首版算 `V_free − V_drop` 得 `−4.79e-5` 当"对照失败"，实为 `V_no − V_free` 的增益。
   ⇒ 固化：**阴性对照先问"谁减谁"**（第 2 次：R3.2 的 `J-E` 也是形态错）。
7. **`dphat_grid` 漏了先验标准差 `sd`**（写成 `gp·z`，应为 `gp·sd·z`）⇒ `Δp̂` 与 `v` **无关**
   （`v=0.05` 与 `v=1` 给出同一个 `0.1387`）。是「两法在 `v<0.25` 上差 60%」这条**不合理的一致性**暴露的。
   改正后网格在 `n=401…25601` 上 6 位不变（`0.035879`/`0.007563`），Gauss-Hermite 在 `v=0.05/0.01` 上偏高 15%/109%
   ⇒ **`Δp̂` 一律用网格，GH 只作 `v≥0.25` 的交叉检查**。
8. **手写时间写成未来时刻**（同族第 11 次）：预注册写「06:3x」、交付稿写「06:0x–07:2x」，真实是 `06:13` 与 `06:22`。
   ⇒ 固化：本轮一切时刻只从 `Get-Date` / 文件 `mtime` / `datetime.now()` 取，写完立刻回读核对。
6. **发现 R3.2 引擎的一个辅助函数缺陷**：`build_engine(...).first()` 的 `PROBE` 分支**不认 `drop_obs`**，
   在 `drop_obs` 臂上仍按"有读数"求值（实测 `drop_PROBE_1 == free_PROBE_1`，逐位相同）。
   `V()` **不受影响**（所有判词都走 `V()`）⇒ 只记录、不改被测物。
