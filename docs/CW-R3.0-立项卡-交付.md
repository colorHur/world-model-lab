## §1 结论（按证据等级）

### 1.1 ★★★ 可采纳（硬·J1）：研究基线的**排序误差真实存在且是系统性的"欠花钱"**

在同一信息、同一动作集 `{HOLD, SEND0, SEND1}`、同一抽象 `(P0,P1,b)` 下，把
`plan_ref` 的解析尾部（`tail="paced"`，R1.6.1 起的**默认研究基线**）的 argmin 与
**精确闭环最优**的 argmin 比（`544` 个状态 = 6 个 τ × 2 个 `p̂` × 16 个 `(P0,P1)` × 2–3 档 `b`）：

| 量 | `paced`（基线） | `dp@r173`（更强解析） |
|---|---|---|
| argmin 一致率 | **0.6379**（347/544） | **0.99449**（541/544） |
| 分歧状态数 | **197** | **3** |
| 遗憾 中位 / 均值 | **0.0** / **1.1176%** | 0.0 / **3.66e-6** |
| 遗憾 p90 / 最大 | **4.0116%** / **10.9889%** | 0.0 / **0.0883%** |
| 状态占比 ≥1% / ≥5% | **27.02%** / **5.88%** | **0%** / **0%** |
| 分歧状态内的遗憾中位 | **2.7333%** | 0.0696% |

★ **197 个分歧状态的遗憾全部 > 0**（不是并列被判错）；0 值来自"完全同解"（占 63.8%）。
⇒ 预注册 §2.4 的两条腿把 `paced` 判成 **`IS-BOTTLENECK`**（一致率 0.638 ≤ 0.85）。

### 1.2 ★★★ 可采纳（硬·J2）：缺口 **98.5%+** 由**解析路线自己**关掉

| 口径（跑后定义，见预注册 §7-4） | 值 | 门槛 | 判 |
|---|---|---|---|
| `by_mean = 1 − mean(dp)/mean(paced)` | **0.99967** | ≥0.8 | CLOSABLE |
| `by_agree = 1 − (1−agree_dp)/(1−agree_paced)` | **0.98477** | ≥0.8 | CLOSABLE |
| 取较小者（保守） | **0.98477** | ≥0.8 | **CLOSABLE** |

⇒ 把闭式配速尾部换成 `(P0,P1,b)` 上的**解析后向 DP**（90 结点、`tau_max=32` 只要 **34.67 MiB / 0.324 s**），
排序几乎变成精确。**"排序误差是瓶颈"在研究基线的实现层面成立，但它是一个"换了实现就能修"的
缺陷，不是一个"必须上学习器"的缺口。**

### 1.3 ★★★ 可采纳（硬·J3）：**面板尺度上没有真值**

| τ | 状态数 | 耗时 |
|---|---|---|
| 10 | 40 565 | 0.027 s |
| 12 | 310 508 | 0.224 s |
| 14 | 2 385 506 | 1.882 s（`truncated_after`，主动停） |

实测增长 **每 +2 步 ×7.6–7.7**（≈ 2.77/步；结构上界 3/步 = 每步 3 个分支）。
⇒ 到面板 τ=256：按结构上界 **10^115.5** 倍、按实测增长 **10^107** 倍。
**结论**：真值只在 `τ ≲ 14` 可算（本机 1.9 s / 429 MiB）。τ=256 上的任何"学习更好"
**只能对基线验证，不能对最优验证** —— 这正是 R1.10（打基线缺陷）与 T28（对 `Linear` 赢、
未达联合目标）两次栽过的坑。

## §2 机制诊断（同一份 `panel_j1.json` 的再分解，不新增运行）

### 2.1 秩混淆矩阵（`a* → a_rank`，`paced`）

```
HOLD  → HOLD  200        SEND0 → SEND0  92        SEND1 → SEND1  55
HOLD  → SEND0  12 错     SEND0 → HOLD  86 错     SEND1 → HOLD  57 错
HOLD  → SEND1   7 错     SEND0 → SEND1 22 错     SEND1 → SEND0 13 错
```

汇总：**该送却按住 = 143**（86+57）／**不该送却送 = 19**（12+7）／**送错用户 = 35**（22+13）。
⇒ 偏差是**单向的"欠花钱" 143 : 19 ≈ 7.5 : 1**。方向与 R1.6 的历史记录一致
（旧尾部"再无观测"→过度推迟），但现在**过冲**：闭式配速把"多花一帧"的价格估高了。

### 2.2 分档（`paced` 的均值遗憾）

| 档 | 均值遗憾 |
|---|---|
| τ = 4 / 6 / 8 / 10 / 12 / 14 | 0.06% / 1.26% / 1.34% / 1.36% / 1.17% / 1.16% |
| b = 0 / 2 / 3 / 4 / 5 / 6 / 7 | 0 / 0.53% / 3.46% / 3.27% / 3.25% / 2.92% / 2.90% |
| p̂ = 0.2 / 0.5 | 0.73% / 1.51% |

★★ **不是随 τ 累积的离散化误差**：τ ≥ 6 就饱和（1.16–1.36%），τ=4 几乎全对（96.9%）。
这是**尾部模型的形式偏差**（"均匀配速 + 稳态循环"这个假设），不是"视界越长越错"。
★★ **预算越宽反而更错**（b=2 时 0.53%，b ≥ 3 时 2.9–3.5%）——与直觉相反，值得记：
`b` 大时"多花一帧"的真实机会成本变小，而闭式配速的定价没跟上。
★ `p̂=0.5` 比 `p̂=0.2` 错得多（1.51% vs 0.73%）：信道越好，SEND 的真实价值越高，
而估计没抓住 ⇒ **误差集中在"该送"的那一侧**，与 §2.1 的方向一致。

## §4 自伤（5 条，按发生顺序）

1. **`argmin` 漏筛可行性**（`C6` 首跑 FAIL 抓到）：`_expect_after` 在 `b=0` 时
   `bud_after = max(0−1,0) = 0` ⇒ SEND 显得"免费且刷新" ⇒ 我的 argmin 选了 `SEND0`，
   而生产的 `_pick` 用 `budget_left >= need` 先筛掉。**是判据侧，不是被测物**（`plan_ref` 未动）。
2. **`C7` 门槛拍错**：原写"反向 ≥ 10× 正常"，实测只 3.16× —— 三动作里"取最差"本身就把遗憾
   限制在 `[Q_2nd−V*, Q_worst−V*]`，10× 不可达。改成"≥ 5e-2（=判定门槛）"。
   ★ 当时**已看见** `median_ok=2.14%`（4 个状态的小子集）。
3. ★★ **闭合率口径失效**（预注册 §7-4）：`1 − median(dp)/median(paced)` 的分母恒为 0，
   因为只要排序器在 >50% 状态同解，被测量就是 zero-inflated。**这是形式缺陷，不是效应小。**
   改用均值比 + 同意率补集，双判词落盘（`overall_prereg` / `overall`）。
4. **J3 判词取了 `max τ` 而非预注册写的 τ=10**：把"τ=12 超 2e5"误报成 `TRUTH-BLOWS-UP-BEFORE-TAU10`。
   修回 τ=10 判，另报 max τ 与外推比。
5. **首跑目录作废**：上述 3+4 都在首跑里，已标 `_SUPERSEDED`（不删，留档）。
   ★ 另：**峰值内存未插桩**，只有 τ=14 的单点复测值（429.2 MiB），不是全流程峰值。

## §5 边界与**不许写的话**

1. ★★ **不许写"排序误差是瓶颈，所以要上学习器"**：缺口 98.5% 由解析 DP 关掉（§1.2）。
2. ★★ **不许写"学习无用 / 世界模型无用"**：本轮只证"在 `(P0,P1,b)` 抽象 + 冻结 `p̂` +
   动作集 `{HOLD,SEND_i}` 上、在 τ ≤ 14 的可验证窗口内，学习没有**可验证**的赢面"。
3. ★★ **不许把结论外推到 PROBE / 信道信息定价**（`J0`）：两个参考物的动作集都**不含** `PROBE`
   （闸 `C5` 用 AST 钉住）。信道信息的价值是**抽象外**的量，本轮**一个字都没测**。
4. ★★ **不许把网格占比读成闭环节省**：`27.02%` / `5.88%` 是**网格上的状态占比**，
   不是"闭环能省 5.88%"。要闭环节省必须跑 episode 并加权可达分布（本轮零 episode）。
5. ★ **不许把 `dp@r173` 的"≈精确"当成"抽象正确"**：两者共享同一个抽象、同一个冻结 `p̂`、
   同一动作集，只差插值 ⇒ 它们的一致**不证明抽象本身**。
6. ★ **不许写"τ=256 也这样"**：真值到 τ=14 为止（§1.3）。
7. ★ `dp` 在本轮是"给定真实 τ 建的 `tau_max=τ`"，生产是 `tau_max=256` 读第 τ 层（闸 `C4` 证等价层），
   但生产的 `p̂` 是 episode 起点冻结值，不是逐槽 ⇒ 生产口径本轮**未测**。
