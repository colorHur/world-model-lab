## 1 结论（按证据等级）

### 1.1 ★★★ 可采纳（硬·负）：`J0 = A-FORM-INSUFFICIENT` —— R3.3 §7.2 的 A 支被**否证**

`A(b) ≡ Σ_{k<b} ρ^k Δp̂_k / ((b−1)Δp̂_0)`：

| `b` | `A(b)` | 压缩所需上限 `1/need` | 判定 |
|---|---|---|---|
| 5 | **0.68998** | 0.42194（`need=2.37×`） | 差 **1.64×** |
| 6 | **0.58709** | 0.17730（`need=5.64×`） | 差 **3.31×** |

`Δp̂_k` 阶梯实测 `0.13672 / 0.11072 / 0.09150 / 0.07639 / 0.06415 / 0.05408 / 0.04570`（`k=0..6`）。
⇒ 带上 `ρ^k` 衰减后确实比 `(b−1)Δp̂_UB` 小（`b=5` 只到 69%、`b=6` 只到 59%），
但**远不够**把 `2.37×/5.64×` 的过估压进 `±30%`。
按预注册 §4 的否定条件 ⇒ **写入"上界形态不可修"**。`ρ=0` 变异给出 `A(5)=0.25`（恒等 `1/(b−1)`）且判词翻成
`SUFFICIENT` ⇒ 该判词对 `ρ` 有分辨力（`G5`）。

### 1.2 ★★★ 可采纳（硬）：`J1 = PROBE-COMPETITIVE-SOMEWHERE` —— 43/46 格探测在根状态**被发送支配**

根状态首步动作值（`first()`，公开量）摊开后：`PROBE_i − SEND_best` 在 **43/46** 格为正。
例（`τ=4,b=2,P=0.02,n_m=129`）：`SEND_0=0.150627422`、`PROBE_0=0.155658949`、`PROBE_1=0.155694076`
⇒ 探测比立即发送差 **3.3%**。竞争的 3 格正是 `IV_free>0` 的 3 格（`τ=4,b=1,P=.005` / `τ=5,b=1,P=.005` /
`τ=5,b=2,P=.005`）；其中 **2 格** `probe−send` 与 `−IV_free` 逐位相同（`−4.5996e−5` / `−9.5293e−6`），
第 3 格（`τ=5,b=1`）差 `2.65e−5`（见 §2 `X1`）。

**这更正了 R3.3 `J-D` 的机制段**：R3.3 写"免量子时探测**被选上** ⇒ 阻碍是量子而不是槽"。
`free` 臂**照样吃一个槽**；43 格上它连第一步都不是候选动作。两件事必须分开写：
- `paid` 臂（`probe_cost=1`）的代价 = 一个量子 **+ 一个槽**；
- `free` 臂（`probe_cost=0`）的代价 = **一个槽**。
R3.3 用 `free` 臂的 `IV_free` 去反驳 R3.2 的"代价是槽"，逻辑上**不能**成立。

### 1.3 ★★ 可采纳（硬·但**推翻我自己跑前的假设**）：`J2 = SLOT-COMPARABLE`

预注册的中位比 `π_slot/ΔV_q = 1.000` —— **这个 1.000 是算术巧合，不可引**：
31 个比值里有 3 个**恒等 1.0**（`τ=2,b=1` 三档 `P`，因 `t=1` 塌缩使 `π_slot ≡ ΔV_q`），
n=31 为奇数且中位正好落在这族恒等值上。剔除退化格（`b≥2`、`ΔV_q>0`、`π_slot>0`）后：

- 中位 **1.737**，范围 **[0.199, 5.206]**（跨度 **26×**）
- `π_slot < 0` 的格 **1 个**：`τ=5,b=1,P=0.005`，`π_slot = −2.647e−5`（**等**比**发**便宜）
- 判词按预注册阈值（`>2.0` 才是 `SLOT-DOMINATES`）**不变**：`SLOT-COMPARABLE`

★★ **自我否证**：我在 scratch 里从**单格**（`τ=4,b=2,P=0.02`，`π_slot/ΔV_q=7.6`）推出"槽价比量子价贵 7.6×"，
全面板实测跨度 `0.199–5.206`、中位 `1.74` ⇒ **该推断不成立**。槽与量子**同量级、在本 DP 里不可分离定价**。

### 1.4 ★★ 可采纳（硬·负）：`J3 = CRITERION-STILL-MISCALIBRATED` —— 加槽价**修不好**判据

`F3`（右侧加 `π_slot`）在已入库格上的表现：

| 判的东西 | 分母 | 正确判"买不起" | 比例 |
|---|---|---|---|
| `IV_free ≤ 1e-12` 的格 | 43 | **22** | **0.512** |
| `IV_paid ≤ 1e-12` 的格 | 46 | 41 | 0.891 |
| `IV_free > 0` 的真阳性 | 3 | **3**（全保留） | 1.000 |

⇒ 预注册要求 `≥0.90` 且真阳性全保留 ⇒ **`b=0.512` 未达标**。**不是槽价那一项没加对，是判据的种类错**（见 §1.5）。

### 1.5 ★★★ 可采纳（硬·机制）：`G8` 鞅恒等 `|E[p̂(后验)] − p̂(先验)| = 1.11e−16`

`E_y[ p̂(后验) ] = p̂(先验)`（数值腿，201 点 GH）。因此：

> **信息不能提高"那一次发送"的期望成功率。** 它只能通过**改变动作**兑现。

而 `(b−c_probe)·Δp̂_UB·ΔV_succ` 假设"成功率提升 `Δp̂` × `ΔV_succ` = 成本下降"——
这在这套 POMDP 里**是种类错**：`E[成功率]` 是鞅，不动的量不能当收益。
唯一合法的转换是"换动作带来的价值差"，即 `alloc_gap = |Q(SEND_0) − Q(SEND_1)|`（根状态实测
`1.41e−4` @ `τ=4,b=2,P=0.02`，比 `Δp̂_UB·ΔV_succ` 小 3 个量级）。
⇒ **R3 的判据不是"松"，是"把概率的期权价值当成了成本收益"。**

### 1.6 ★★ 可采纳（硬·活体）：`J4 = SYMMETRY-BREAK-RESTORES-PROBE`

把 `σ_w[1]` 由 `0.03` 改到 `0.30`（**仅诊断，主线不改**）：`τ=4,b=1` 上 `probe−send = −7.504e−2`、
`IV_free = 1.702e−3`（原 plant 同格为 `0`）⇒ "探测被支配"**不是恒真**，它与"两用户是否值得区分"绑定。

## 2 探索性（**跑后构造，不是预注册判据**；下一轮若要它当判据必须**先写卡**）
