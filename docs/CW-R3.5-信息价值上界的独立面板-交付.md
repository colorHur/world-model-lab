## 2. 本轮最值钱的一条

> **用探测去买"当前信道知识"，在这套 DP 上的毛价值上限是 `0.038` 个量子 —— 不是 R3.4 说的 `0.66` 个。**

- 上界定义（有推导，不是拟合）：`UB := A0 − A_free(σ⋆)`，`σ⋆ = 1e−9`。
  `σ⋆` 臂在本网格上 Blackwell-支配任何 `σ` 臂，`probe_cost=0` 的臂支配 `probe_cost=1`
  ⇒ `IV_paid(σ) ≤ IV_free(σ) ≤ UB`。两条不等式**逐格验过**（`C0`，390 条腿 0 违例）。
- `UB/ΔV_q` 在全 150 个有效格上的**最大值** = `0.03818`，出现在唯一非零格
  `(τ=5, b=1, P=0.01)`：`UB = 1.5271e−4`、`ΔV_q = 4.0e−3`。
  其余 **149 格 `UB` 恰为 0**（比特零，不是"小于噪声"）。
- 该非零格的网格收敛（**探索性**，跑后补）：`n_m = 65 → 0.03110`、`129 → 0.03818`、`257 → 0.03818`
  （129 vs 257 相对差 `8e−6`）⇒ `0.038` 不是网格假象。
  ★ 预注册里那条 `grid_refine` 挑中的是 `(σ⋆,P=0.05,τ=4,b∈{2,3})`，**两格全 0**，
  对"0.038 是否网格假象"**没有分辨力** ⇒ 本项是补做的，带"探索性"标签。

## 3. 更正 `CW-R3.4` 的 `X2`（**必须写进交接**）

R3.4 的跑后量 `X2 = π_slot − (V_PROBE − V_SEND)` 被写成"实测上界"，并给出
"信息最多值 **0.66 个量子**"。本轮结果：

- `X2 > UB` 在 **135/150** 格，最大超出 `2.31e−2`；
  例：`(τ=5,b=1,P=0.1)` 上 `X2 = 2.31e−2`（= `0.162` 个量子）而 `UB = 0`。
- 根因（写卡时读实现查出来的）：**混臂**。`π_slot` 与 `V_SEND` 取自 `noprobe` 臂、
  `V_PROBE` 取自 `free` 臂，而 `free` 臂逐点 `V_free ≤ V_noprobe` ⇒ 两项不在同一成本结构下，
  这个差**没有上界推导**。
- ⇒ R3.4「最多值 0.66 个量子」**作废**，替换为 **`0.038` 个量子**。
  方向说明：`X2` 是**高估**，所以 R3.4 的"买不起"结论**没被推翻**，只是数被收紧 **17×**。

## 4. 机制：卡的不是信息质量，是那个槽

同臂（`free(σ⋆)` 臂的 `first()`，不混臂）量 `deficit_free = min_PROBE − min_SEND`：

| 量 | 值 |
|---|---|
| `deficit_free / ΔV_q` 中位 | **0.820** |
| 范围 | **−0.0382 … 4.861** |
| 负值格数 | **5**（全部是 `(τ=5,b=1,P=0.01)` 那一个家族的 5 个 σ 行） |

读法：探测在根状态比发送**差约 0.82 个量子**，而 `σ⋆` 已经把"信息质量"这一侧拉到极限
（完美 CSI、免量子）⇒ **再好的 CSI 也补不上这 0.82**。唯一翻面的条件恰是
"槽极多、量子极少"（`τ=5, b=1`）。

★ 这条把 R3.4 的 `J1`（`PROBE` 被 `SEND` 严格支配，43/46 格）从"那套面板上的现象"
升级成"**上界恰为零**"，并且给出了唯一翻面点。

## 5. 探索性（未预注册，不许当确证引用）

1. **交换率不转移**：`ΔV_q/(p̂·ΔV_succ)` 在本面板中位 **0.836**（0.179–1.028），
   而 R3.3 在另一面板测得 **1.000–1.087**。⇒ `QUANTUM-EQUALS-ONE-SEND` **不是通用恒等式**。
   方向：本面板 `ΔV_q` 偏小 ⇒ `UB/ΔV_q` 偏大 ⇒ 对负结论是**保守**方向（换成 `p̂ΔV_succ` 做分母，
   `0.038` 只会更小）。
2. **`σ` 确实进决策**：`(τ=5,b=1,P=0.01)` 上 `IV_free` 随 `σ` 单调降
   `1.527e−4 (1e−9) → 5.82e−5 (0.5)`。★ 我跑前一度把"`ratio_ub` 跨 σ 相同"误读成
   "读数没进 DP"，其实那是**定义使然**（上界恒取 `σ⋆` 臂）。
3. `b = τ` 的 45 格 `ΔV_q ≡ 0`（预算超过视界即无用）⇒ 判据在这些格上退化，已单列
   `n_cells_degenerate_dVq = 45`，**没有**混进 `C1` 的分母。

## 6. 自伤清单（7 条，被测物未动）

1. ★★ **预注册的 `grid_refine` 挑的格没有分辨力**：两格全 0，对"0.038 是否网格假象"零信息。
   同族第 4 次（R3.1 存在性判据无地板 / R3.2 单点达标 / R3.4 恒等值中位）。
   **规则**：分辨率检查必须挑**非退化格**，且先报"这格能不能为 0"。
2. ★★ **`ZeroDivisionError`**：`spread_rel = (max−min)/max` 在 `max = 0` 时崩。
   比值先算分母的第 4 次。**规则**：凡比值，先写 `if denom <= EPS` 分支再写式子。
3. ★★ **"名字相同就当同一个量"**：`ratio_ub` 跨 σ 相同 → 我第一反应是"σ 没进决策"。
   实际是定义（上界恒取 `σ⋆`）。**规则**：看到"某量对某参数不敏感"，先查它**是否含该参数**。
4. ★★ **R3.4 的 `X2` 混臂，我当时"读名字没读实现"**：`π_slot`/`V_PROBE`/`V_SEND` 三个名字
   看起来同源，实际来自两个臂。固化条目①"读实现不读名字"第 5 次踩。
5. ★ **`C5` 的阈值（0.20 / 0.90）是在冒烟之后写的**：冒烟已看到 `UB = 0`，所以这两个数
   不是纯跑前决定。**诚实边界**：判词的**定性**（上界恰为零）不受影响，
   但"`C5` 的阈值是跑前"这句话**不成立**，不许写。
6. ★ **`G4` 初版是个恒过的占位闸**（`pass=True`）。改成 `first()` 与 `V()` 的根状态一致性后
   才成为真闸（实测 `5.6e−17`）。"空过的闸"同族第 3 次。
7. ★ **两个名字都在用**：`probe_minus_send`（混臂，沿用 R3.4）与 `deficit_free`（同臂）。
   只报前者会把混臂量当机制量。**规则**：混臂量必须在字段名或文档里标 `legacy`。
