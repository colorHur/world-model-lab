## 3 机制定位（三条独立参考，都不信 DP 内部）

1. **穷举**（`3^τ` 条序列直接按期望动力学模拟，τ≤4 可行）→ 真最优。DP 在 4 例上**高于**它（+2.48%）。
2. **低于真最优的那 2 例**（τ=2,b=1）⇒ DP 在 2 步规模上就**作弊**：双线性插值把折点抹平后，
   `min` 可以走到模型之外的值。**这是插值的合法性问题，不是精度问题**：
   插值给出的是"折点连线的值"，它**既不是上界也不是下界**，所以 DP 的结果**不能当值函数用**。
3. **加密不收敛**（`D5`）⇒ 除了插值合法性，**还有第二处结构性不一致**（很可能在预算轴/饱和夹紧
   或续接时序上）。本轮**没有定位到**，如实记为未完成项。

## 5 不许说（写稿/汇报时的红线）

1. 不许说"小状态 DP 不可行" —— 本轮只证明**这一版实现**不满足可采纳性，`D5` 说明它不是分辨率问题。
2. 不许说"探测无价值" —— 面板没跑，待测效应**根本没被观测**。
3. 不许把 `D1b` 大 τ 的 5.4e-5 说成"DP 算错了" —— `b=0` 列是纯仿射，那点差是网格 + 浮点底噪（`D1a` 2.8e-5 同源）。
4. 不许把 `D4` 的 4.59 倍说成"主动测量让代价变差" —— 那是**值函数的错**，不是策略的比较结果。
