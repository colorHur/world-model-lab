## 5. ★★★ 跑后诊断：`g_mono` 为何失败（带时点，**不是预注册项**）

**诊断写于看到主面板读数之后**（`date` 09:1x）。代码入口 `--diag-bias`；证据
`cw_r5_6_grid_l1_diag_bias_20261027T011732`（`n=1`）与 `..._011737`（`n=2`）。

**做法**：从 `A0` 的 DP 里**提取它的最优动作规则** `π_L2(t,P,b)`（`A0` 的最优策略**不看 ACK**），

**结论（三条）**

1. ★★★ **`A0` 报出的数不是它自己策略的真实成本**：诊断 12 格里 **8 格** `V_πL2 > A0`
   （其余 4 格正是 `b=8` 的"1 次发送"格，`V_πL2 == A0` **逐位**，结构使然）。
   机制：`A0` 用 `ph = ps(先验) = 0.5` 常数当"每次发送的成功概率"，这抹掉了
   **"失败 ⇒ 信道差 ⇒ 下次更可能失败"** 与 **"失败 ⇒ `P` 更大"** 的正相关
   ⇒ 它**低估**了 ACK 盲策略的期望成本（偏置随发送次数单调增：0 → 0.43% → 1.03%）。
2. ★★★ **`n=1` 上 `V_πL2 == A0p` 逐位（6/6 格）** ⇒ 在 `n=1` 上"ACK 盲最优策略"与"ACK 感知最优策略"
   的**最优成本完全相同**（不是"差不多"）⇒ **`n=1` 上 ACK 的决策价值精确为零**，
   而 `IV_ack` 的整个负号恰好等于 `A0` 的自偏置。⇒ **R5.5 的 `ADF-BREAKS-MONOTONICITY` 归因错误。**
3. ★★ **`n=2` 上两者不同**：`A0p < V_πL2`（`1.70e-3 > 0` 等）⇒ **ACK 在 `n=2` 上确有正的信息价值**，
   而旧口径因为拿了个偏低的基线，把它读成 0 或负数。

**为什么这是"种类错"而不是"松紧错"**：`g_mono` 断言的是"同一测度下信息更多不能更差"。
`A0`（L2）与 `A0p`（L1）**不是同一测度下的两个值函数**：`A0` 的期望是按一个**误设模型**（ACK 概率恒 0.5）
算的，`A0p` 是按**条件正确的模型**算的。两者不可直接相减 ⇒ 闸的被测物选错了（R5.5 同一族教训的第 5 次）。

**修正后的口径（本轮起生效）**

- `IV_ack`（`A0 − A0p`）**不许再当"ACK 的信息价值"**，也不许再当"基线"。
- 正确的 ACK 信息价值 = **`IV_ack* = V_πL2 − A0p`**（策略评估得到的同测度差），且必须报"`V_πL2 == A0p` 是否逐位"。
- `IV_probe_L1 = A0p − VL1` **仍合法**（两臂同模型、动作集嵌套）；读数见 §2.2。
- `IV_probe_L2 = A0 − VL2` 是**误设模型内部差**，**不许与 `IV_probe_L1` 相减或相除** ⇒
  **`survival` 这个主量本轮撤回**（分母不在同一测度上）。§2.2 里 `survival = 2.12 > 1` 就是这个错配的产物，
  **不是**物理量，也不是接线错。

## 6. 自伤（9 条，最贵的在前）

1. ★★★ **预注册的 `g_mono` 是种类错**：我把"信息单调性"写成了零容差硬闸，而两臂根本不在同一测度上。

   这轮会得出"精确信念下信息仍然有害"——一个**方向相反且不可复现**的结论。
3. ★★★ **`survival` 一开始就被我当主量**（沿用 R5.5），直到 `n=2` 算出 `2.12 > 1` 才回头看分母。

2. **它还没有排除什么 / 不能支持什么**：不能支持"ACK 比探测更值钱"——两者**还没在同一测度下对量**
   （`IV_probe_L2` 是误设模型内部差，`survival` 已撤回）；`n=2` 的读数**依赖 `probe_total=1`**，
   该限制在 `n_w≥129` 上的代价**未测**；`b=24,τ=5` 的探测零是**分辨率零**，不许写成"探测无价值"。
3. **用户可以从中练习哪一个判断**：**"两个数相减之前，先问它们是不是在同一个测度上算出来的"** ——
   本轮全部麻烦都出自这一条：`A0` 与 `A0p` 各自都对，相减却没有意义。

## 8. 下一轮唯一主件（`CW-R5.7`）

**把探测价值也搬到同一个测度上**：实现"`VL2` 策略在真实测度下的评估"（`V_πVL2`），
于是 `IV_probe_L2* = V_πL2 − V_πVL2`，与 `IV_probe_L1 = A0p − VL1` **同测度可比**，
`survival* = IV_probe_L1 / IV_probe_L2*` 才成为可解释的量。**先写卡、先算规模**；
`n=2` 仍需 `probe_total=1`，且要把该限制的代价在能算的最大 `n_w` 上量出来。不许开训。
