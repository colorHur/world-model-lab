## §1 判词（三层，按证据等级）

### 1.1 ★ P1 离线：**`NOT-CONVERGED`**（`H-R2-1` **未过**，不是"否证"）

| 种子 | 离线比中位 | 更好的 ep | 末 20% 相对下降 | 平台？ |
|---|---|---|---|---|
| 7 | 1.0343 | 4/15 | **0.281%** | 是 |
| 17 | 1.0400 | 5/15 | **1.937%** | **否** |
| 27 | 1.0290 | 4/15 | 0.099% | 是 |

- 预注册 §4：**未全部平台 ⇒ 不许宣布 dev 结论**。其中 `seed=17` 在最后 2400 步仍有 1.94% 的相对下降
  （> 1% 阈值），另两个种子已平台（0.28% / 0.099%）。
- 因此 `H-R2-1`（`A_t` 劣化 ≤5%）**未被检验**，不是被否证。判词 = `NOT-CONVERGED`。
- 门的两条腿也都没过：中位比 1.0343 ≤ 1.05（过），但逐 ep 方向 `min 4/15 < 9/15`（不过）。

### 1.2 ★★ 可采纳（硬，与平台判据无关的离线描述）

1. **残差没有复现解析后验，反而加误差 2.9–4.0%**：状态空间 `MSE(learned) / MSE(base)` 中位
   **1.0343**（三种子 1.029 / 1.034 / 1.040），逐 ep 只在 4–5/15 上更好。
   ★ 这与预注册 §2.2 的 headroom 声明**一致**：基线是 MMSE ⇒ 残差的最优解是 `0`，
   训练出的任何非零残差都是**噪声注入**。`max|Δ|` 实测 0.41–0.79（信念量级 ~1）⇒ 注入不小。
2. ★★ **代价空间与状态空间反向**：同三个模型，代价空间比 **0.9816 / 0.9638 / 0.9768**
   （三种子全部 <1 ⇒ 代价看起来"更好"），而状态空间是 1.03–1.04（更差）。
   ⇒ 预注册 §2.1 的裁定（代价口径对符号不敏感）在**真实训练产物上**得到一次实例验证；
   `G6` 的合成对照（只翻符号：状态损失 **0.265 → 1.025**、代价损失 **0.06125 → 0.06125 逐位不变**）给出机制。
   ★ 所以：**"代价变好"不能当"信念变好"的证据**，这是本轮最可复用的一条。

### 1.3 闭环（`EXPLORATORY`，按预注册 §11-A1，**不承载 `H-R2-1`**）

| 训练种子 | `A_t` 中位比 | 更差的 ep | `cost_true` 中位比 | `∃r_i>1` | 动作序列不同 |
|---|---|---|---|---|---|
| 7 | **0.9153**（`EXP-SUSPECT-LEAK-OR-BUG`） | 5/15 | 1.0042 | 16/30 用户 | 15/15 |
| 17 | 0.9682（`EXP-LEARNER-MATCHES-WITHIN-5`） | 6/15 | 1.0005 | 15/30 | 15/15 |
| 27 | 1.0186（`EXP-LEARNER-MATCHES-WITHIN-5`） | 9/15 | 1.0315 | 15/30 | 15/15 |

- **方向随训练种子翻号**（0.915 / 0.968 / 1.019）⇒ 没有可靠方向。
- **逐 ep 摆幅远大于中位移动**：单格 `A_t` 比从 **0.65**（`ep105`/seed17）到 **2.29**（`ep109`/seed7）。
  `n=15` 的面板要判"5% 级效应"，而这个摆幅就是噪声底 —— **面板分辨不了**（与 R2.1–R2.3 同源）。
- `seed=7` 的 0.9153 触发了预注册 §3 的 `SUSPECT-LEAK-OR-BUG` 闸。**本轮不当成果**。
  机制上不属于泄漏：模型只吃公开视图（`G3` AST 三栏全空、`G5b` 15 个特征全为 `visibility=all`），
  输出只是"基线 + 有界残差"，没有任何真值通道；合理解释是**决策层对信念扰动不单调** ——
  扰动改变"发谁/何时发"，`A_t` 可以降而 MSE 同时升（§1.2-2 已证这两把尺子不同向）。
- ★ R17（必报）：三条件下**每个种子都有 15–16/30 个用户成本上升**，最大 **2.56×** ⇒ 只能写"交易"，
  且**不许**用 `A_t` 的中位改善掩盖这些用户。

## §3 机制解读（能写什么、不能写什么）

1. **能写**：在"已知线性高斯 + 精确 ACK"的环境里，把一个小网络接在解析后验上做残差，
   **期望上界是打平**（基线是 MMSE）；本轮实测是 **加 3.4% 状态误差**，
   说明 12k 步 / 70 集 / 1601 参数的容量下，它学到的几乎全是噪声（`max|Δ|` 0.4–0.79）。
2. **能写**：`A_t` 与状态 MSE **不同向**（同一模型：MSE +3.4%，`A_t` −8.5%…+1.9% 随种子变），
   而 `cost_true` 与 `A_t` 也可反向（`ep109`/seed7：`A_t` ×2.29、`cost` ×0.685）
   ⇒ 三个量各测各的东西，**不许拿一个替代另一个**（R1.8/R1.17 的老教训在本轮复现）。
3. **不能写**：`H-R2-1` 成立/不成立（`NOT-CONVERGED`）；"学习模型追平解析基线"（方向随种子翻）；
   "残差改进了代价"（那是符号不敏感造成的假改进）；"世界模型可行/不可行"（本轮只碰一个读出接口、
   一个 plant、一种容量）。
4. ★ **这条负结果不指向"世界模型无用"**：它指向的是**本环境没有学习空间**（参数已知、观测模型已知、
   ACK 精确）。要让学习有意义，必须动"基线为什么需要被学"这一条（参数未知 / 模型失配），
   **而那属于改协议**（v4 §2 要求先给物理或可稳定性依据），不是本轮能顺手做的。

## §4 边界（不许外推的地方）

- 单 plant（`P1`，`sigma_meas=0.20`）；`P2` 未跑 ⇒ 不许写"跨 plant 稳健"。
- 只学**均值**（`P̂` 冻结在解析值）⇒ 方差校准完全未测。
- 训练分布 = **基线策略的 on-policy 分布**；闭环里策略换成学习臂自己 ⇒ 有协变量偏移。
- 3 个训练种子 × 15 dev ep；有效独立单元 = `(plant, ep)` = 15，不是 45。
- 平台判据的曲线分辨率是 **50 步**（每 50 步记一次全量 loss）；未做窗口长度/阈值的敏感性分析。

## §5 自伤（如实记，含"当时已看见什么"）

1. **`G4` 首跑 FAIL（判据侧）**：直接套 `r2_train_spec.assert_capacity(width=, depth=)`，
   而它的 `width/depth` 分支按 `d_out=2` 造形状（R2.6 骨架输出二维）⇒ 算出 1634，与本模型 1601 不符。
   改：用 `r2_7_learn.layer_shapes(d_out=1)` + 三条真守卫（`assert_structure` / `assert_param_budget`）。
   **没有放宽任何上限**。登记于预注册 §11-A2。
2. **`G5b` 首跑 FAIL（判据侧）**：`FIELD_PERMISSION` 的键带前缀（`telemetry.* / prior.* / view.*`），
   我拿裸特征名去查 ⇒ 全部查不到。改 `_perm_key()` 映射。登记于 §11-A3。
   两条都是"先怀疑判据"的老教训（D 组），两次都发生在**碰数据之前**。
3. ★★ **探针污染风险（最该记住的一条）**：我先跑了一个 3 集 / 400 步的探针（离线比 2.2745），
   然后才写 §11-A1"P1 不过也跑一次 EXPLORATORY 闭环"。这在程序上是**看数之后加测量**。
   处置：① 在 §11-A1 里**逐条写清"当时已看见什么"**（探针数字、timing）；② `H-R2-1` 与
   `GATE-OFFLINE` **一字未改**；③ 闭环判词强制加 `EXP-` 前缀、且写明"不得用来救 `H-R2-1`"。
   ⇒ 事后看这条修订**确实改变了本轮能拿到什么**（否则 P1 一 FAIL 就什么都测不到），所以必须留在案上。
4. **采集计时误读**：探针 3 集 31.4 s 里有约 26 s 是**一次性 DP 构建**，我最初读成 10.5 s/集；
   实测 70 集 **251.8 s**（≈3.6 s/集）。预算估计因此一度高估 3×（这是第 4 次同类高估）。
5. **`/tmp` 运行失败**：探针脚本放 `/tmp` 跑，`experiments` 包不可见 ⇒ 改在仓库根跑并**删除**（未进 git）。
6. **平台判据的一次边界值**：`seed=17` 的 1.937% 距阈值 1% 只有 1.9×，`seed=7` 的 0.281% 距阈值 3.6×。
   判词按阈值执行（`NOT-CONVERGED`），但**没有**做"窗口从 80% 挪到 85% 会怎样"的敏感性 ——
   若挪到 85%，`seed=17` 很可能也判平台，这时 `H-R2-1` 就会变成"可判"。这是本轮**最脆的一处**，
   已如实记录，不在下轮之前偷偷改。
7. **交付稿首版把 `G6` 的数字写成了"印象值"**（写 `0.845 → 1.205` / `0.8016`），
   落盘实为 **`0.265 → 1.025` / `0.06125 逐位不变`** ⇒ 已按 `gates.json` 改正。
   与 R1.14 的"编了个体积数字"同型（第 2 次）：**写进交付的每个数字都必须现场读文件**。
