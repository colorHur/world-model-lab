## 1 一句话

**不行。** 把一阶近似的伪观测方差从 `0.63` 换成 `1.000`（Fisher）或 `1.726`（矩匹配），
`p̂` 下限与精确贝叶斯的差距只被吃掉 **5% / 15%**，16 对逐格对照 **0/16 通过** 20% 容差；
两臂的 `p̂` 绝对值差中位 **0.119 / 0.106**（容差 0.05）。
⇒ 决定行为的是**形状**（位置依赖的 Fisher 信息、固定的 `|NACK|/|ACK|=1.5`），不是**尺度**。
**网格（或别的非高斯基数）不可省**，不能写成"按 Fisher 信息重标定一下就行"。

## 2 `Q1`（零 episode）：为什么单标量在**结构上**就不可能全域匹配

精确后验的 Fisher 信息 `I(m)=κ²p(1−p)`（`κ=2, log h*=0`）与一阶近似隐含的**常数** `1/ACK_VAR`：

| 量 | 值 |
|---|---|
| `sup I` | **1.000**，仅 `m=0` 取得 |
| 外生工作域 `m∈[−3,3]` 的 `sup/min` | **101.36** |
| `m∈[−2,2]` / `m∈[−1,1]` | 14.15 / 2.381 |
| **内生**工作域（`0.63` 臂实测 `h_mean` 的 5%–95% 分位 `[−3.072, +4.583]`） | **2394.02** |
| `m*`（使 `I(m*)=1/ACK_VAR`） | `0.63` ⇒ **`NONE`**（隐含 `I=1.587 > sup I`）；`1.000` ⇒ `0.000`；`1.726` ⇒ `±0.7728` |

**读法**：标量族给出的是**一条水平线**，精确族是**一条钟形曲线**。
`1.000` 只在 `m=0` 相切，`1.726` 只在 `|m|=0.773` 相切；`0.63` **一条都不相切**（全域过高自信）。
内生工作域跨 7.65 个 log 单位、信息量差 **2394×** ⇒ 一个常数**不可能**代表它。

### 2.1 ★ 顺手抓到一条比"尺度"更硬的偏差（事后观察，§8.1 追加列）

`v=1` 时精确后验的均值位移（网格）与一阶近似（`g·direction`）：

| `m` | exact ACK | exact NACK | `\|NACK\|/\|ACK\|`（exact） | 标量（比值**恒定 1.5**） |
|---|---|---|---|---|
| −3.0 | **+1.7100** | −0.0246 | 0.014 | ±0.6135 / −0.9202 |
| −1.0 | +1.0000 | −0.2900 | 0.290 | 同上 |
| **0.0** | **+0.6057** | **−0.6057** | **1.000** | 同上 |
| +1.0 | +0.2900 | −1.0000 | 3.448 | 同上 |
| +3.0 | +0.0246 | **−1.7100** | 69.43 | 同上 |

- **在它自己的标定点 `m=0` 上，精确后验是完全对称的**（`±0.6057`，比值 **1.000**），
  而实现是 `+0.6135 / −0.9202` ⇒ **ACK 侧只差 0.0078，NACK 侧差 −0.3145**。
  ⇒ 一阶近似在标定点的主要误差**不是方差尺度，是那个写死的 `−1.5`**（比 ACK 的 `+1.0` 大 50%）。
  ★ 这也解释了 §1：**把 `ACK_VAR` 调大只是把两个方向同时按比例缩小，比值仍是 1.5**
  ⇒ 无论标量取多少，都改不掉这一项结构偏差。
- 全表最大绝对位移误差（`0.63`）**1.0965**（`m=−3` 的 ACK：`+1.7100` vs `+0.6135`）。
- 预注册写的"**符号相反**区间"实测**为空**（`sign_flip_interval_nack = NONE`）⇒ 见 §6-自伤 2。

## 4 判词与它**不能**说什么

`SHAPE-NEEDED`（预注册 §6-4：两臂都不过 `P1` 且 `P2.pmin > 0.50`）。

**能说**：
1. 一阶近似的错误**不是单一尺度错误**；把 `ACK_VAR` 校准到 Fisher（1.000）或矩匹配（1.726）都复现不了精确曲线（0/16）。
2. 结构原因（`Q1`）：精确信息随 `m` 变化 101×（外生 `±3`）到 **2394×**（内生），标量只能提供常数。
3. 在**它自己的标定点 `m=0`**，主要误差来自写死的 `|NACK|/|ACK| = 1.5`（exact 为 1.000）—— 这一项**标量改不掉**。
4. 本面板对**总代价** `cost_true` 的分辨力不足（效应 0.0246 < floor 0.0333）⇒ 代价维度只能说"测不出"。

**不能说**：
- 不能说"精确贝叶斯更好/更差"（`P4` 符号跨集翻转，且 `cost_true` 落在地板以下）；
- 不能说"某个第三档标量也许行"被排除 —— 见 §5 边界；
- 不能把 `1.726` 立成新基线（预注册 §4.2 明禁；且 `aoi` 捕获率 >1）。
- 不能把本轮当"ACK 信息重要/不重要"的证据（没有关 ACK 的臂）。

## 5 边界（引用前必读）

1. **只测了两个标量点**（`1.000` / `1.726`），都来自 R1.12 的**局部**标定（`m=0, v=1`）。
   严格说没有排除"某个第三档在 16 格上更接近"。**没有去扫**是刻意的：扫到过就是"为过闸调参"，
   而且 `Q1` 的结构论据（要求的位置依赖倍数 101×–2394×）与"取哪个点"无关。
2. **有效独立单元 = 2 个 episode**（同 ep 的 4 个 seed 不独立，R1.7.8 `D5b` 已证）⇒ 不报显著性。
3. `p̂` 下限是**轨迹最小值**（极端统计量），对单次决策敏感 ⇒ 所以并列报了 `P3` 绝对口径与 `P2` 捕获率。
4. `exact` 臂的网格支撑 `[−8,8]`、321 点；截断量 `≤3.3e-8`（R1.12 `4n` 已单独报过）。
5. 本轮**没有**动 `±1.0/−1.5`。若下一步要动它，必须**另立卡**（它会让 R1.7.6→R1.13 的全部 32 格换基线）。

## 6 自伤（本轮 5 条，逐条列）

1. **预算方向估错（第 3 次，方向又换了）**：`--probe` 实测单格 `2.72 s` + 首次建表 `23.67 s`，
   我按"4 次建表 + 32 格"估 **≈174 s**，实际 **110.1 s** ⇒ **高估 1.6×**。
   真因：建表并非每臂一次（`p̂` 量化命中缓存）。★ 教训仍在：**单点/首点外推不可靠，正反两向都会错**。
2. **预注册 §4.1-Q1d 的"符号相反区间"是想当然**：它是从 R1.12 交付稿的一句话推来的，
   而那句话本身把三种口径混了（`+0.298` 实为 ACK 侧量级，exact 的 NACK 位移是 `−1.2023`）。
   实测符号翻转**不存在**。⇒ 教训：**引旧结论前先复核它的口径**，二手句子不能直接当预期。
3. **`4r`/`4t` 在"接线是死的"实现下也 PASS**（活体负控实测）—— 若只加 `4r` 就会误以为"接线已验证"。
   已在闸的 `detail` 与 `mutation_control.json` 里写明"分辨力只来自 `4s`"。
4. `config.py` 里写了 `np.isfinite` 但该文件不 import numpy ⇒ 改 `math.isfinite`（小错，未进证据）。
5. `r1_13_scalar.py` 首个版本在 `mutation_control` 的 note 里用了 ASCII 双引号嵌中文 ⇒ `SyntaxError`，跑前 AST 检查抓到（未产生任何证据目录）。

## 7 下一步（STATE §7.2）
