## §1 一句话结论

把逐 ep 机制标签从**份额式**（`share ≥ 0.60`）换成**方向 + 量级式**（`ku/kf` 相对 `κ=0.01`）后：

> **`MECH-USER-SYSTEMATIC-FRAME-UNRESOLVED`** —— 用户通道 10/10 在**有害方向**（`ku<0`）；
> 帧通道 6 负 4 正、无方向。
> 按预注册的自我否证条件，**这不是新发现的机制结构**：`|ku|` 最小也有 **8.3κ**、`|kf|` 最小 **1.4κ**，
> 十个 ep **没有一个**落在 `NEU` ⇒ "激活与否"这一维**没有区分力**，新判据在逐 ep 上退化成
> **符号计数 = R1.17 `Q_dir` 的等价重述**。

本轮真正新增的三件（都不是"新机制"）：

1. **`MIXED` 的病根坐实**：它不是"两种机制并存"，而是**份额口径**在 `|Δr|` 小的 ep 上给出的
   读数；换成方向口径后，**没有任何一个 ep 在"用户通道有害"上分歧**（10/10）。
2. **`ku` 的闭式与量级**：2 用户时 `ku = [G(ρ_0+ρ_1−2ρ_a) + D(ρ_0−ρ_1)] / max(|G|,|D|)`
   = `ku_net + ku_swap`（残差 `1.1e-16`）。**`|ku| ≈ 基线两端用户的送达率差**（比值 `0.488–0.604` × `2|Δρ|`）。
   ★ 这是**代数恒等式**，不是经验规律。
3. **`ep104` 的抵消项定位**（STATE §7.1-9② 的开放项）：用户项仍是负的（`−0.0161`），
   把 `Δr` 拉正的是帧项 `+0.0180` 与 within 项 `+0.0227`。

  ⇒ 这条是我的**判据缺陷**（预注册漏了分层），不是两个判断互相否定。

## §4 闭式（推导 + 验证）

```
n_users = 2:  G = m_0 + m_1,  D = m_0 − m_1,  m_i = Σ_b (ni_e[i,b] − ni_a[i,b])
|m_0| + |m_1| = max(|G|, |D|)
m_0 d_0 + m_1 d_1 = (G/2)(ρ_0+ρ_1−2ρ_a) + (D/2)(ρ_0−ρ_1)
⇒ ku = [G(ρ_0+ρ_1−2ρ_a) + D(ρ_0−ρ_1)] / max(|G|,|D|) = ku_net + ku_swap
```

- 纯平衡交换（`G=0`）⇒ `ku = (ρ_0−ρ_1)·sign(q)`，手算 `+0.8` 与实测**逐位一致**（闸 `4ae`）。
- **量级读数**：`|ku| ≈ |ρ_0−ρ_1|`（比值 0.488–0.604 × `2|Δρ|`）⇒
  **"搬一次尝试的损失 ≈ 两端用户的送达率差"**。这条解释只在 `|D| ≫ |G|` 时成立（9/10 如此）；
  `ep106` 的 `|G|=64 > |D|=58` 是例外，故 `1.21×`。
- ★ **同义反复警告**：以上全部是定义的代数推论 ⇒ 只能当**实现核对**与**单位解释**，
  **不许**写成"发现了 `ku` 的规律"；也不能由它反推"用基线 `Δρ` 预测升级损失"（那是循环）。
