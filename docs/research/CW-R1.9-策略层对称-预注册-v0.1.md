## §1 问题

R1.8 已经把"值表轴错配"排除（`TABLE-SYMMETRIC`，1.2e-15）。但 `dp` 仍**一律**偏 u0，
且该偏好**不跟角色走、只跟下标走**（§0-3）。本轮要回答的是：

> **"偏 u0" 是"值函数认为 u0 更值得服务"（价值层），还是"策略层没按值函数办事"（策略层）？**

三个互斥候选：

- **H1 价值层**：真实 plant（`σ_w=(0.02,0.03)`）下 DP 自身就认为 u0 的边际收益更大 ⇒ 需查目标/近似为何如此。
- **H2 rollout 层**：`__call__` 的 H 步蒙特卡洛续接（`_advance` + `_greedy`）对换用户标号后**不等价**
  ⇒ 根动作值差被实现污染。
- **H3 选择层**：`_pick` 的并列键 / 候选枚举顺序。

## §2 三条判据（写死，不许跑完再改）

### T1 根动作值向量的**置换等变**闸（零 episode）

在**逐用户完全对称**的 plant 上（`bounded_plant(A=(1.0,1.0), sigma_w=(0.025,0.025))`），
构造一个**显式不对称**的公开状态 `S`：

```
P_hat   = (0.030, 0.012)
x_hat   = (0.30, -0.20)
h_mean  = (0.40, -0.30)
h_var   = (0.80, 0.60)
budget_left = 128, t = 8
```

令 `π(S)` 为同一状态交换两用户后的状态。令 `D` 为按 seed 生成的**随机数面板**，
`π(D)` 为把面板的**用户列**交换后的面板（`w / s_h / eps_meas / eps_csi / udeliv / init_x / init_h` 全换）。

判据（逐动作，相对容差 `1e-12`）：

```
V_perm(π(S), π(D))[π(a)]  ==  V(S, D)[a]        对 a ∈ {PROBE0, PROBE1, SEND0, SEND1, HOLD}
其中 π(SEND i)=SEND(1−i), π(PROBE i)=PROBE(1−i), π(HOLD)=HOLD
```

**为什么必须同时换面板**：面板的列是"用户 i 的实现噪声"。只换状态不换面板 ⇒ 比较的不是同一份
随机实现 ⇒ 等变性在抽样层面本来就不该成立。这一条写在此处，防止事后把"面板没换导致的差"当缺陷。

- `max_rel ≤ 1e-12` ⇒ **EQUIVARIANT**：H2/H3 被否，只剩 H1。
- `max_rel > 1e-12` ⇒ **ASYMMETRIC**，并报**逐动作**差表，定位到 `_advance` / `_greedy`。

### T2 价值层的**边际收益**（零 episode，真实 plant）

`cfg_real = bounded_plant()`（`σ_w=(0.02,0.03)`，与 R1.8 面板同）、`p̂=(0.5,0.5)`、
**`grid="r173"`**（与 R1.8 的 `dp16` 臂一致，不用 legacy）、`b_cap=T`。

单帧收益定义为"发这一帧带来的价值下降"（**含**预算 −1 的机会成本，与 DP 的 SEND 分支同式）：

```
d_i(p)   = A_i²(1−g_i)p + σ_w,i²      g_i = p/(p+σ_meas²)      （送达 + 量测更新）
f_i(p)   = A_i²p + σ_w,i²                                        （不刷新）
benefit_i(P, b) = V(P, b) − V( P_i ← d_i(P_i), P_j ← f_j(P_j), b−1 )     j = 1−i
```

在下列 6 个点上算 `benefit_0 / benefit_1` 与符号：

```
(P0,P1,b) ∈ {(0.010,0.010,205), (0.030,0.030,205), (0.060,0.060,205),
             (0.030,0.060,205), (0.060,0.030,205), (0.030,0.060,128)}
```

- **见证闸 T2a**：对称 plant（`σ_w=(0.025,0.025)`）+ `P0=P1` ⇒ `benefit_0 == benefit_1`（≤1e-12）。
  若此闸不过，说明 `benefit` 的算式本身带下标偏差，T2 结论作废。
- `benefit_1 > benefit_0`（6/6 点）⇒ 值函数认为 **u1 更值得服务** ⇒ 与"dp 偏 u0"矛盾 ⇒ 支持 H2/H3。
- `benefit_0 ≥ benefit_1` ⇒ 值函数**自己**就偏 u0 ⇒ 支持 H1（须在交付里写出机制，不许只报数字）。

**写卡时的预测（可被否证）**：`Δp = P²/(P+σ_meas²)`，`σ_meas=0.2 ⇒ σ_meas²=0.04`，
`P=0.06 ⇒ 0.036`，`P=0.03 ⇒ 0.009`（4 倍差）⇒ **预测 `benefit_1 > benefit_0`**。
预测错了也要如实记（这是本轮唯一一条带先验的具体预测）。

### T3 活体负对照（有分辨力的证明）

把 T1 的被测策略换成 `dp_axis_mode="legacy_swap"`（R1.7.1 的旧缺陷，逐位复现），
**必须使 T1 FAIL**。若它居然 PASS ⇒ `GATE-NO-RESOLUTION`，本轮全部结论作废（#39/#100 同族）。

（证明面板置换是必要动作，而不是"随便怎么测都相等"的空过）。

### T4 接线读数（只记录，不判 PASS/FAIL）

`_advance(SEND(0))` 一步后，未送用户 u1 的 `P_hat` 是否变化、是否等于 `A²P+σ_w²`。
（§0-5 的源码事实要用运行值确认；这一条**不**作为判据，因为"未送用户不老化"是**已明写的建模近似**，
不是缺陷，但它与"用户噪声大小"有交互，必须记录。）

### §7 修订 3（03:2x，T6 结果出来之后；**写于任何 T7 计算之前**）

T6 实测（`dev/100/seed=2001`，`tail=dp`）：`n_send0=115`、`n_send1=13`，
而 `P0−P1` 的**最大值是 0.0**（`frac_P0_gt_P1 = 0.0`，中位 `−0.0446`）——
即**策略一直在服务 `P` 更低的那一个**。rollout 在 242/256 槽偏好 u0，中位 `|Δ| = 0.0218`
（不是 3–6% 的小倾斜，是 0.02 量级的稳定偏好）。

这与 T2（值表：`P` 更高者收益更大）**方向相反**，而 T1 又证明 rollout **对称**。
⇒ 新假设 **H2'（写在这里，尚未被 T7 检验）**：

> `PlanRef._advance` 在 SEND 分支**不推进未送用户**（T4 实测 `user1_frozen=True`），
> 而 `world.step` 会推进所有人。在 H 步 rollout 里，选 `SEND(i)` 相当于给 `j=1−i`
> **免掉一次 `+σ_w,j²`**。于是偏差 ∝ `Δσ_w² × ∂V/∂P`，方向**恒为"发给 σ_w 小的那个"**。
> `σ_w=(0.02,0.03)` ⇒ 恒偏 u0。这是一个**角色驱动**（不是下标驱动）的偏差。

**T7（post-hoc，report-only，1 个 episode）**：把 plant 换成 `σ_w=(0.03,0.02)`（只换这一项），
其余完全同 T6，重跑一次。
- 若 `n_send1 ≫ n_send0` ⇒ **H2' 成立**，且 R1.8b 的 `LABEL-DRIVEN` 判词**要撤回/更正**
  （那是本轮的**更正**，旧证据不删）。
- 若仍 `n_send0 ≫ n_send1` ⇒ H2' 被否，偏差另有来源（届时要查 `_greedy` 的复合冻结）。

**T7 不判 PASS/FAIL**；它的唯一用途是决定下一轮修哪一处。

### §7 修订 5（03:2x，**T8 结果之后、T8b 之前**）

T8 实测（对称 plant + 对称状态）：`dp` 在 `P=0.06` 上 **8/8 偏 u0**（`median Δ = +0.063`）、

**T8b（post-hoc，report-only，零 episode）—— 自我否证**：
对称状态 `P=(0.03,0.03)`、`tail ∈ {paced, dp}`，用 **40 个 seed**（2001–2040）：

1. 报 `mean(Δ)`、`median(Δ)`、正负计数、`mean(Δ)/sd(Δ)`；
2. **配对恒等式检验**：对每个 seed 再跑一次**面板列置换**（`_PermPanel`，状态不变，因为状态本来就对称），
   要求 `Δ_swapped == −Δ` 逐位（容差 1e-12）。这是等变性的**逐 seed** 版本。
   - 若 40/40 成立 ⇒ 等变成立；那么 T8 的偏斜只能来自 8 个 seed 的抽样偶然，
     必须写"**T8 的 8/8 不可引用**"（n=8 的老问题，见 MEMORY 里 `≥7/8` 那条）；
   - 若有 seed 不成立 ⇒ 找到**能复现的最小反例**，本轮判 `ROLLOUT-ASYMMETRIC-MINIMAL`。
