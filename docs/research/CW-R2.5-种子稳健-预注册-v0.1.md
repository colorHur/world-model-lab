## §1 为什么必须要这一轮（不是我给自己找活）

R2.4 的零控（`floor`）定义为 `|A(strong,2001) − A(strong,3102)|`，即**同模型、同 episode、只换规划器采样种子**。
`Δ` 则是**同种子、换模型**。两者零分布不同 —— 这一点 R2.4 §7.1-4 已自己指出（`N1` 只能诊断种子方向性）。

后果：R2.4 的 `30/30` 全部是在 `plan_seed=2001` 上数出来的。若效应本身依赖 `2001` 这一次采样的
具体随机数，则 `AOI-SEPARATES` 是**种子特定**的，不能写进论文当结论。本轮就是去证伪它。

★ **必须说清的一条语义**（读实现，不读名字）：`plan_seed` 只进 `_RecAct(seed=plan_seed)`
（`r2_1_sep._factory`），世界由 `episode` 决定（`streams.make_episode_rngs`）。
⇒ 本轮检验的是**规划器采样噪声**下的稳健性，**不是**"换世界"的稳健性；后者已由 `n=30` 个 episode 覆盖。
这两件事不许混为一谈。

## §3 量定义（写死，跑后不许改）

对每个单元 `u = (plant, ep)`，记

```
S2 = A_t(belief_readout, 2001)    S3 = A_t(belief_readout, 3102)
W2 = A_t(prior_only,    2001)     W3 = A_t(prior_only,    3102)     ← W3 本轮新产生
Δ2 = W2 − S2                      Δ3 = W3 − S3
```

`A_t` = **非删除型**全时隙均值（R2.4 口径：未送达时隙按槽号填补，不剔用户、不缩窗口）。
同报 `A_T`（整期惩罚填补）作变体一致性。

方向判据只用**有符号** `Δ3`。★ **禁止**用 `|Δ3|` 当符号（R2.4 `N1` 的错，`p0≡1.0` 恒真）。

## §4 判据（★ 零分布**先算**，再跑）

### §4.1 主判（**唯一**一条进判词的）：`C-SIGN-3`

```
n_pos3 = #{u : Δ3 > 0}          （>0 才算，=0 不算）
判据：  n_pos3 ≥ 21            ← n=30, 精确 Bin(30, 1/2), 单侧 p<0.025
```

`k_need(n=30)`：`α=0.05→20`、`α=0.025→21`、`α=0.01→22`（`mech3.k_need_table()` 现算，不手抄）。
**α=0.025 的理由**：指标族 = `A_t` + `A_T` 两条 ⇒ Bonferroni 半分。三条 `α` 全部同报。

零分布**可证**：H0 = "`Δ3` 的符号与 `2001` 那次无关" ⇒ 符号对称 ⇒ `n_pos3 ~ Bin(30, 1/2)`。
不需要 MC，不存在"分层后失去 1/2"的问题（本轮**不做任何分层**）。

### §4.2 ★ 符号一致性 ≠ 第二个检验（防重复计证）

`Δ2` 在 R2.4 是 **30/30 全正**。因此在 `sign(Δ2)` 恒为 `+1` 的前提下，

```
#{u : sign(Δ2)=sign(Δ3)} ≡ #{u : Δ3>0} = n_pos3
```

⇒ "一致性检验"与"`Δ3` 符号检验"是**同一个统计量**，`p` 值逐位相同。
**本轮只报一次**，不把两条当两份证据（这是 R2.4 之后最容易犯的新错）。

### §4.3 幅度：只描述，**不作判词**（附为什么）

我会报：`median|Δ3|`、`median|Δ3|/median(f_S)`、`median|Δ3|/median|Δ2|`、`f_W`（`= |W2−W3|`，弱臂自己的换种子地板）。

★ **但不出幅度判词**，理由是**零分布在本设计内构造不出有功效的形式**，逐条说明：

1. 用 R2.4 的 `f_S = |S2−S3|` 当尺度 ⇒ 在 H0（"只有幅度、符号随机"）下 `#{|Δ3|>f_S}` 的期望
   **等于 R2.4 观测到的 `30/30`**（因为 `|Δ2|` 比 `f_S` 大 23 倍）⇒ 该判据**无功效**，永远通过。
2. ~~用 `f_W = |W2−W3|` 当尺度 ⇒ 见 §10 跑前修订 1：本条**被我自己的 MC 推翻**，作废。~~
   正确理由见 §4.3-2'。
3. sign-flip 型 MC（拿 `±|Δ2|` 重抽）⇒ `|Δ3*| = |Δ2|` 被固定，幅度腿**退化为常数**，同样无功效。

### §4.3-2' 真正的理由：幅度腿**没有分辨率**（不是零分布错）

记 `r` = "最小能让 `beat` 掉到 `k_need` 以下的幅度缩放因子"，即
`r = min{s : #{|Δ2_u|·s > f_S,u} < 21}`。若 `r` 很小（例如 0.05），则这条腿
**只有在效应相对 `Δ2` 崩塌 20 倍时才可能 FAIL**，它对"同量级 / 弱一点"完全无分辨力 ——
发一个 `p` 值只会暗示一个不存在的分辨率。

`r` 的数值由 `S4b` 用 R2.4 已落盘数据**在跑面板前**算出并写进交付，作为拒发幅度判词的定量依据。
★ `S4a`（MC）另证：两种 floor 在 iid 噪声零假设下逐对 `beat` 率**都是 `1/2`**（即零分布本身合法）
⇒ 拒发幅度判词的唯一理由是**功效**，与 `1/2` 是否成立无关。

⇒ 结论：**本轮幅度的任何显著性说法都不可靠，一律标"描述"。**
若数值上 `median|Δ3|` 与 `median|Δ2|` 同量级，只能说"**未见量级崩塌**"，
**不许**写"幅度复现"或"量级稳健"。

### 跑前修订 1（12:5x，`run_episode` 仍为 **0**，面板**未跑**）

**被推翻的原话**（本卡 §4.3-2 初稿）：
> 用 `f_W = |W2−W3|` 当尺度 ⇒ `f_W` 与 `Δ3` 共享 `W3` ⇒ 逐对 `beat` 的 `1/2` 零分布**不成立**。

**推翻它的数据**：`S4` 按该假设做了 4000 次 MC（`W2,W3,S3 ~ iid N(0,1)`）：
H0 下逐对 `beat` 率 = **0.5002 ± 0.0910** ⇒ 与 `1/2` **一致**。

**为什么我原来错**（代数）：`(W2−W3)` 与 `(W3−S3)` 虽共享 `W3`，但在
`W2,W3,S3` **iid** 下，交换 `W2↔S3` 把联合分布映到 `(−B,−A)`；联合律在该交换下不变
⇒ `P(|A|>|B|) = P(|B|>|A|) = 1/2`。**共享分量本身不破坏 1/2**，破坏 1/2 的是
"两边不同分布"或"条件在某个共享量上"（R2.2 `D3` 的错属于后者，与此不同类）。

**处理**：§4.3-2 划掉并加指针；改由 §4.3-2'（**分辨率**论证，`S4b` 定量）承担拒发幅度判词的理由；
`S4a` 的通过条件改为"两种 floor 的 H0 beat 率都 ≈ 1/2"（这是**零分布合法**的正面证据，
不是我原来那条反向假设）。★ **主判 `C-SIGN-3` 一字未改**，不受本条影响。
