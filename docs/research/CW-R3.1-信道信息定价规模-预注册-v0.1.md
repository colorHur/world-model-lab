## 1 问题（为什么本轮是这个）

`CW-R3.0` 收口时的判词是 `NO-WINNABLE-OPPONENT-BY-RANKING`：排序误差真实存在（一致率 0.6379），
但换 `DPTail@r173` 一步关掉 **98.48%** ⇒ 「排序误差是瓶颈」在**实现层**成立、在**学习层**不成立。

R3.0 的 `J0`（闸 `C5` 用 AST 钉住）同时声明了它**不覆盖**的东西：
两个参考物的动作集都是 `{HOLD, SEND_i}`，**不含 `PROBE`**。原因是结构性的 ——
`plan_dp` 把 `p̂_i` 在槽初**冻结**，于是 `PROBE` 在 DP 里恒被 `HOLD` 支配（`plan_dp.py` 注释 1/2）。
一旦 `p̂` 内生，值函数的状态必须把**信道信念**带上：`(P0, P1, m_h, v_h, b)`。

所以 R3 剩下的唯一候选问题是一个**可算性**问题，不是"要不要学"的问题：

> **Q**：CW-POMDP-v1.1 的面板（τ=256、2 用户、`c_probe=c_data=1`、预算 128/204）上，
> 「信道信息定价」的值函数能不能**算出来**？算到哪一层为止？

本轮**只做规模与前提**，不做定价结论。三件事：

- `A` 规模外推：把 `(P0,P1,b)` 的实测增长律乘上 `(m,v)` 的因子，给出 `N(256)` 的量级。
- `B` 一个必须先答的**前提**：以 `(m,v)` 做状态，在 `ack_mode="exact"`（研究基线）下**是否合法**？
  即 `(m,v)` 是不是信道信念的充分统计量。
- `C` 若 B 成立/不成立，把 `m` 量化到 `n_m` 格后，**要多少格才能分辨一次探测的信息价值（IV）**。

**已知（R3.0 实测，直接引用，不重测）**：精确 `(P0,P1,b)` 闭环 DP 的状态数
τ=10 **40 565** / τ=12 **310 508** / τ=14 **2 385 506**，增长 ≈ **2.77/步**，⇒ τ=256 是 **10^107–10^115.5**。

## 2 判据（**看数前写定**；`judge()` 只按表取，不许人工改判词）

### 2.1 `J-A` 规模

`N(256) = N_A(256) × n_m²`（`N_A` = `(P0,P1,b)` 实测外推；`n_m` 取 §2.3 的 `n_m*`；
`v` 不计因子 —— 由面板 `B3` 实测确认 `v` 不随观测值分支）。

| 判词 | 条件 |
|---|---|
| `SCALE-TRACTABLE` | `N(256) ≤ 1e7` **且** 外推内存 ≤ 4 GiB **且** 外推耗时 ≤ 600 s |
| `SCALE-MARGINAL` | `1e7 < N(256) ≤ 1e9` |
| `SCALE-EXPLODES` | `N(256) > 1e9` |

★ 内存/耗时用**实测**的 `字节/状态` 与 `状态/秒`（在 τ=8/10/12 三点插桩测）外推，不用猜。

### 2.2 `J-B` 矩闭合（`exact` 基线下 `(m,v)` 是否充分）

构造两个 `GridBelief` 后验，**矩相同**（`max|Δm|, max|Δv| ≤ 1e-12`）、**形状不同**
（单峰 vs 对称双峰，双峰质量 ≥ 30%），各施加**同一条** ACK，比较更新后的 `(m', v')`。

| 判词 | 条件 |
|---|---|
| `MOMENT-CLOSURE-FAILS` | `max|Δm'| > 1e-6` **或** `max|Δv'| > 1e-6` |
| `MOMENT-CLOSURE-HOLDS` | 两者都 ≤ 1e-6 |

★ 阈值 1e-6 的理由：闸 `B2` 的**活体对照**（同一后验复制两份）给出严格的 0.0，
所以 1e-6 是"比数值噪声高 6 个量级、比物理效应低 3 个量级"的中线；不许跑完再调。

### 2.3 `J-C` IV 的分辨率

1 用户**简化实例**（声明见 §5-④），`τ ∈ {1,2,3}`（= 预测窗口长度），
`V_ref` = 矩闭合模型内**连续 `y` 精确积分**（41 点 Gauss–Hermite），
`V_grid(n_m)` = `m'` 量化到 `[-4,4]` 上 `n_m` 格（质量按正态区间概率合并），
`IV = V_ref(允许 PROBE) − V_ref(禁止 PROBE)`。

`n_m*` = 使 `|V_grid(n_m) − V_ref| ≤ 0.10 × IV` 的**最小** `n_m`（`n_m ∈ {9,17,33,65,129,257}`）。

| 判词 | 条件 |
|---|---|
| `IV-RESOLVABLE` | `τ=2` 与 `τ=3` 都存在 `n_m*` 且 `n_m* ≤ 257` |
| `IV-BELOW-GRID-FLOOR` | 任一 τ 上 257 格仍 > 10% ⇒ 网格定价本身不可信 |

### 2.4 闸（跑数前定，全绿才出判词）

| 闸 | 内容 | 否 |
|---|---|---|
| `G1` | 我写的扩展 DP 在**禁止 PROBE** 时与 `dp_audit.ExactClosedLoop.value` 逐位相等（2 用户） | 实现错 |
| `G2` | `IV ≥ -1e-12`（允许 PROBE 是动作超集，不可能有害） | 实现错 |
| `G3` | `IV` 对 `σ_csi ∈ {0.05, 0.5, 2.0}` **单调不增** | 实现错 |
| `G4` | `σ_csi = 50` 时 `IV ≤ 1e-3 × IV(0.05)`（探测无信息 ⇒ 价值→0） | 实现错 |
| `G5` | 网格细化：`|V_grid−V_ref|` 在 `n_m=9→257` 上**不增**（允许 1 次平台） | 实现错 |
| `G6` | `B2` 活体对照（同后验复制）更新后 `Δ = 0.0`（严格） | 判据无分辨力 |
| `G7` | AST：本文件不读真值字段（`_log_h_true` / `_x_true` / `cost_true` / `z_meas`） | 信息越界 |

★ `G5` 的"不增"是**弱**形态（细化不一定单调下降）；真正的分辨力在 `G6`。

## 4 否定条件（**我可能错在哪**）

1. ★ **若 `N_A(256)` 实际远小于外推**（例如 `b` 饱和使状态数提前收敛，`N(256) < 1e4`）⇒
   `SCALE-TRACTABLE` ⇒ **R3 的"解析拿不到"前提被驳倒**，下一轮必须直接做全局精确 PROBE 定价，
   不许再写"不可算"。这是本轮的自我否证口。
2. **若 `MOMENT-CLOSURE-HOLDS`** ⇒ `(m,v)` 作为状态合法，`J-C` 的网格误差就是唯一障碍，
   路线变成"加密网格"而不是"换表述"。
3. **若 `IV` 在 `σ_csi=0.05` 下本身就 < 数值地板**（比如 `IV < 1e-9 × q·P`）⇒
   「探测值不值」这个问题在面板参数下**没有可测内容**，R3 该收口而不是继续。

## 5 边界与"不许写的话"

1. **不许**把 `J-A` 的外推写成"实测"；外推必须带拟合区间与 `γ` 的原始三点。
2. **不许**把 `J-C` 的 `IV` 从 1 用户简化实例外推到 2 用户面板（预算耦合会改符号/量级）。
3. **不许**写"学习无用 / 世界模型无用"；本轮根本没训练。
4. **①** `J-C` 的 `V_ref` 是**矩闭合模型内部**的精确值，不是 POMDP 的真最优 —— 若 `J-B` 判 `FAILS`，
   那 `V_ref` 连"这个模型的最优"都只是"这个投影的最优"，必须在交付稿里写明层级。
5. **②** `IV ≥ 0` 只在"PROBE 与 SEND 共用同一预算且动作集是超集"时成立；
   `c_probe ≠ c_data` 时不再自动成立 —— 本轮只跑 `(1,1)`。
6. **③** 本轮**不**产生任何新的闭环成本数字，**不**与 R1/R2 的任何主表并列。
7. **④** 1 用户简化实例是**子问题**，不是面板；理由：`J-C` 问的是 `m` 的量化分辨率，
   它按用户可分离（共享预算只在"谁先花"上耦合）。该理由本身**未经检验**，写进交付稿的边界节。
8. **⑤** 不重跑 P3、不改 plant/`ACK_VAR`/`k_need`、不训练、不升 A/噪声追 PASS。

## 7 跑后修订（**只追加，不改上面的判据**）

### 7-A 跑前修订（`01:2x`，**面板一格未跑**，只在 `--ctrl-only` 上跑过闸）

- **§7-A1（差向符号，实质修订）**：§2.3 把 `IV` 写成 `V(允许)−V(禁止)`，而 §2.4 `G2` 要求
  `IV ≥ 0` —— 两者**自相矛盾**。成本口径下动作集越大值越小 ⇒ 那个差恒 `≤ 0`。
  以 `G2` 的**意图**为准，改为 **`IV = V(禁止 PROBE) − V(允许 PROBE) ≥ 0`**。
  ⇒ 影响：`J-C` 的 `rel_err` 分母改用新 `IV`（同一量、符号取正，数值不变），`G3/G4` 的比较仍成立。
- **§7-A2（判据腿，实质修订）**：`τ=2` 上 `IV` **恒为 0**，且这是**可解析证明**的，不是实测：
  `τ=2`（预算 `b0=2` 不紧）时唯一有效的是一次 SEND 的增益 `q·g·P`，它对 `p` **线性**，
  于是 `E_y[max_p(...)] = max_p[E_y(...)]` ⇒ 探测不增值；`τ=1` 同理（探测后无槽可用）。
  ⇒ `J-C` 的判据腿从 `{τ=2, τ=3}` 改为 **`{τ=3, τ=4}`**，`τ=1/2` 降为**零控**（闸 `G2b`），
  面板 `τ` 网格扩到 `1..4`。★ 这不是"看数后改判据"：改的依据是上面这条**代数**论证。
- **§7-A3（新增闸，收紧）**：预注册 §2.4 的 `G1` 原本写成"我写的扩展 DP 禁探测 == `ExactClosedLoop`"，
  但实现时发现两者**用户数不同**（`ExactClosedLoop` 硬编码 2 用户），拿来做身份闸是**假闸**。
  拆成两条：
  - `G1a` `ExactQ == ExactClosedLoop`（确认被引用的基线本身没坏，照抄 R3.0 的做法）；
  - `G1b` 本文件 1 用户引擎（禁探测 + `p̂` 冻结）== **暴力枚举**（`2^τ` 条动作序列 ×
    每条 `2^{#SEND}` 棵结果树，**不复用** DP 递归）。这才是对**我这份实现**的独立对账。
  另加 `G2c`：求积权重归一（`Σw = √(2π)`，容差 `1e-12`）+ 后验均值鞅性 `E[m'] = m`（`1e-12`）。

### 7-B 跑后修订（`01:3x–02:0x`，面板跑过之后；**每条都记了"为什么必须改"**）

- **§7-A4（闸容差，判据错）**：`G1b` 原要求"逐位相等"，实测差 **4.44e-16**（两条路径的浮点求和
  顺序不同：DP 沿树先累代价再取 `min`，暴力沿序列先算概率权再加权）⇒ 改容差 `1e-12`，
  **实测值照实报**，不放宽被测物。
- **§7-A5（C 面板预算，设计错）**：首跑取 `b0 = τ`（每槽都能发）⇒ `SEND` **弱支配** `HOLD`
  （失败态与 `HOLD` 逐位同态、成功态严格更小，唯一代价是一个量子），于是"发不发"与 `p̂` 无关
  ⇒ `IV ≡ 0`。这**不是**"信息无价值"的发现，而是**我没造出权衡**。改 `b0 = floor(0.5·τ)`
  （＝面板的 0.5 预算档）。
- **§7-A6（`P0` 单点 → 扫描，选点错）**：首跑 `P0 = prior_var = 1.0`。那是 **t=0** 的初值，
  而面板稳态 `P` 在 `0.005–0.05`（R3.0 的 `PS` 网格）。在 `P0=1.0` 上"一次发送"值 ≈ **1.0**，
  探测根本不可能竞争 ⇒ 结论由初值决定。改扫 `P0 ∈ {0.005,0.02,0.05,0.2,1.0}`（扫，不是挑）。
- **§7-A7（净/毛未分，口径错）**：把"探测要花 1 量子"与"信息值多少"混成一个 `IV`，
  会把"买不起"说成"没用"。拆成三个量并列报：
  `IV_net`（净，原定义）、`IV_free`（毛，探测免费）、`price`（一个量子的价格）。
  分辨率问题**只问 `IV_free`**。
- **§7-A8（噪声地板 + 第三判词，判据不完备）**：`IV_free` 在 20 个 (τ,P0) 单元上
  **19 个逐位 0.0、1 个 5.551e-17**（= 2⁻⁵⁴）。若按字面"`IV>0` 就有对象"，`n_m*` 会建立在
  浮点残差上（首版就是这样得到 `n_m*=9`，**作废**）。加地板 `IV_NOISE = 1e-12`；
  并补第三判词 **`NO-ABOVE-NOISE-IV-IN-1U-REDUCTION`** —— 预注册的
  `IV-RESOLVABLE` / `IV-BELOW-GRID-FLOOR` 两档都假定"毛价值 > 0"，**两档都不适用**。
  `G4` 相应改为"无对象可检时 `n_cell=0` 且标注空过"，不许把空过记成通过。
