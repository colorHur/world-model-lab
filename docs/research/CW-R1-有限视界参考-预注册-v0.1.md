## 1 问题（一句话）

**在"预算有限、信道未知、状态未知"的同一信息集下，"现在花一帧预算去测信道"能不能换来
更低的后续任务成本？** 这是"用同一个规划器、同一个信息集、已知生成参数"的对照，
不是新方法，也不是上界证明。

## 2 参考实现要满足的硬条件（缺一条就不算"参考"）

1. **同信息**：只吃 `SchedulerView`（`prior` / `telemetry` / `history` 白名单）；
   不许读 `_x_true` / `_log_h_true` / `w_realized` / 未来随机数。违反即作废。
2. **已知生成参数**：`A, B, σ_w, σ_meas, ρ, κ, log h*, σ_csi, q, r` 全部来自 `config`，即
   "上帝知道参数、但不知道当前实现"。这**不等于**读真状态。
3. **条件信念采样**：从当前**后验**（`x̂, P̂`；`m_h, v_h`）采样，而不是从先验重采样。
4. **动作集**：`PROBE(i) / SEND(i) / HOLD`，含**剩余预算**约束（`budget_left`）。
5. **续接**：用掉这次测量之后，后续动作**可以根据新信息变化** —— 这正是"测量的价值"的来源，
   因此**不许**把探测价值限制在"本槽 argmax 用户改变"上（验收 §3 P0-C 明确禁止这个写法）。
6. **不称上界**：这是有限视界 + Monte-Carlo 的**参考**，不是最优策略、不是全局上界。

## 3 计划实现（结构，不是结果）

| 部件 | 做法 |
|---|---|
| 信念 | 两个标量 Kalman：任务 `(x̂, P̂)`（已由 `pred_gates` 验到逐位）；信道 `(m_h, v_h)`（高斯近似，ACK 与 CSI 都进） |
| 前瞻 | 视界 `H ∈ {1, 5, 20}` 槽；每个动作后用**条件信念采样**估期望累计代价 |
| 动作评估 | 5 个动作 × `M` 条采样（`M ∈ {32, 128}`）；预算不足时动作不可选（不是"退化为 HOLD"） |
| 续接 | 每个采样分支用**同一规划器的 1 步贪心**做尾部（防止"只看当前槽"把探测判成负价值） |
| 终止值 | `H` 步后给一个保守的**尾部代价估计**（无观测时的稳态 `P` 上沿 × `q`），并**明写它是估计** |
| 计算量 | 纯 Python + numpy，CPU；目标 ≤ 3 min/格（`T=256`、`B/T=0.5`、`ρ=0.85`） |

## 4 多时隙（`c > 1`）的修法设计（本卡只设计，不在本轮实现）

验收要求：**按固定物理时间结束、逐子步计成本、动作完成才揭示测量**。落法：

1. `run_episode` 的时钟改成**物理步**：`while t < T_phys`，一次主动动作占 `c` 个物理步；
2. 每个物理子步都用**同一个** `u_t` 推进动力学，**逐子步**累加代价（而不是在推进前把 `c` 份成本
   一次性加在同一状态上 —— 那是旧实现的做法，会把成本算错）；
3. 测量只在**动作完成**（第 `c` 个子步末）才进估计器，时间戳记 `t + c`；
4. `packet`/`meas`/`csi` 的配对下标改成 `(t, user)`（`slot` 口径天然支持）；
5. 只有 1–4 全部通过新反例（含"c=1 时与现行逐位相同"的回归），才允许 `c=2` 进任何比较表。

★ 在那之前 `v11_validate()` 继续**拒绝** `(c_probe, c_data) != (1,1)`。

## 5 指标 / 效应 / 预算 / 否定条件

**指标**（看数前定义，不按结果调）：

* 主指标：`cost_est_per_step`（先验下任务成本；所有策略同口径）与其**绝对**值；
* 必报伴生量（R17 / P3-1 纪律）：`J` 的绝对值、`n_probe / n_attempted / n_delivered`、
  `budget_wasted`、逐用户 `r_i`、`mean_task_aoi`、`mean_csi_aoi`；
* 统计单位：**完整 episode**（`dev` 100–139，40 集），按 episode 聚类给 bootstrap 区间；
* 比较：`ratio = candidate / baseline`（CW-EVAL-v1.1 方向），配对差 `baseline − candidate`。

**预算**：只跑 `dev`、`ρ ∈ {0.85, 0.98}` × `B/T ∈ {0.5, 0.8}` 四格；`c=1`；
`event_pairing="slot"`；不训练任何模型。

**否定条件（命中就写否定，不改口径追 PASS）**：

* **N1**：参考规划的 `ratio ≥ 0.95` 对**全部**基线（含 `periodic4`）⇒ "在同信息下，主动测量
  换不到可测的任务成本改善" —— 只对**本 plant / 本面板 / 本视界**成立，**不推**"测量无价值"。
* **N2**：`H` 从 5 加到 20 的改善 < 2% ⇒ 视界不是瓶颈（与 P3 线 H3 同型结论，但**必须重测**，
  不许引用旧结论）。
* **N3**：参考规划的探测次数 `n_probe = 0` 且成本与"禁探测版"逐位相同 ⇒ 说明我的价值函数里
  探测项没有接线（**这是实现缺陷，不是科学结论**，必须先修再判）。
* **N4**：若"给更多真信息反而更差"再次出现（T29/`no_x` 同型），**先查规划器**,不许写成"信息无用"。
