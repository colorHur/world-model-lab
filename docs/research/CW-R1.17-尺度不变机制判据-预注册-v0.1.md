## §1 问题（一句话）

R1.16 的机制判词建立在 `share = E_term / Δr` 上，而该量**随 `|Δr|` 变化**（`Spearman = −0.73`），
使"机制归因"这一问在 `|Δr|` 小的 ep 上不可读。本卡把**一个含混的问题拆成三个不同的问题**，
各自用尺度合适的量回答：

| 编号 | 问题 | 量 | 尺度性质 |
|---|---|---|---|
| **Q_dir** | `exact` 的重分配是否**系统性地**搬向更差处？ | 逐 ep 符号 + 符号计数 | **尺度不变**（对单调变换不变） |
| **Q_mag** | 每单位"被搬运的尝试"，平均损失多少送达率？ | `ku = E_user/Mu`、`kf = E_frame/Mf` | **尺度不变**（证明见 §4.2 `S6`） |
| **Q_share** | 机制**解释**了缺口的多少？ | `E_term/Δr` | **本质依赖 `Δr`** ⇒ 降级为**描述**，限子集 |

**核心主张（可证伪）**：R1.16 的 `MIXED-MECHANISM-AT-N10` 是 **Q_share** 的答案；它脆弱**不是**因为机制不存在，
而是因为 `Q_share` 在 `|Δr|` 小的格子上没有分辨力。`Q_dir` 与 `Q_mag` 有分辨率，且**不需要 `Δr` 作分母**。

## §2 为什么必须换掉分母（而不是"再调一个阈值"）

`share = E_term/Δr` 的两处结构性问题：

1. **恒等式约束**：`E_user + E_frame + E_within ≡ Δr`（`decompose` 的残差 1e-17 量级已验）。
   三项份额**和为 1**，所以"份额高"不是独立信息 —— 任一项高必然挤掉其他项。
   当 `Δr → 0`，三个份额同时被 `1/Δr` 放大，任何一项的微小数值差都被放大成"主导机制"。
2. **`Δr` 不是机制强度，是净效应**。它可以是两个大机制**互相抵消**之后的残差。
   `ep103` 就是现场：`E_frame=+0.0143` 与 `E_within=−0.0211` 在 `Δr=−0.0147` 里相互抵消，
   份额随之给出 `−0.97` 这种"看起来极强"的读数。

⇒ 用 `Δr` 做分母等于把"机制有多强"和"净效应有多小"混在一个数里。**必须换分母。**

## §3 新量的定义（写于看数之前）

沿用 R1.15 `decompose` 的中间量（`ni_e/nd_e/ni_a/nd_a` 为 `n_users × n_bins` 计数矩阵，
`N^E = Σ ni_e`、`ρ_i` 为 approx 臂逐用户送达率、`ρ_ib` 为逐格送达率、`ρ_a = Σnd_a/N^A`）：

### §3.1 搬运强度（分母，**只依赖分配，不依赖 `nd_e`**）

```
m_i  = Σ_b (ni_e[i,b] − ni_a[i,b])           # 逐用户尝试数差（整数和差）
Mu   = Σ_i |m_i| / (2 · N^E)                  # 用户级重分配的总变差（TVD）比例
Mf   = Σ_i Σ_b |ni_e[i,b] − ni_a[i,b]| / (2 · N^E)   # 帧级 TVD 比例
```

- 除 `2`：TVS 标准形式（"搬出去的总量"= 搬进来的总量 = TVD）。
- 除 `N^E`：归一为"占 exact 臂总尝试的比例"，与 `Δr` 无关。
- **`Mu`、`Mf` 完全不看 `nd_*`** ⇒ 构造上就与送达数/`Δr` 解耦。
- 边界：`Mu = 0`（两臂分配完全相同）⇒ 用户机制未发生，`ku` 记 `NaN`、不进符号计数；
  `Mf = 0` 同理。**不把 `NaN` 当 0。**

### §3.2 机制损伤率（**主量**，尺度不变）

```
ku = E_user  / Mu          # 单位：送达率（无量纲，0..1 量级）
kf = E_frame / Mf
```

物理意义：**把一次尝试从 approx 的落点搬走，它落到的新落点上平均送达率变化多少。**
`ku = 0` ⇒ 搬运与信道质量无关（无偏）；`ku < 0` ⇒ 系统性搬向差处（损伤）；
`ku > 0` ⇒ 搬向好处理（改善）。`kf` 同理，量的是"同一用户内换帧"的平均率变化。

★ 与 `share` 的分工写死：**`ku` 回答"搬运本身多有害"，不回答"解释了缺口的多少"。**
`ku` 与 `share` 只有在 `E_frame=E_within=0` 时才相等（此时 `Mu=|Δr|/…` 不成立，二者仍不同）。
不许把 `ku` 当解释度，也不许把 `share` 当机制强度。

### §3.3 描述性份额（降级，**不参与判词**）

只在子集 `S_desc = { ep : |Δr_ep| ≥ 0.02 }` 上报 `share`，并**必须**同报：
该子集的 `n`、`Spearman(|Δr|, max|share|)`（全 10 点与子集各算一次）、以及"全 10 点上同一统计量"。
**0.02 是描述门槛，不是判据门槛**；写进卡是为了让"挑了哪些点"可核对。

## §4 判据（看数之前定义）

### §4.1 `Q_dir` —— 方向判词（主判）

逐 ep：`s_u(ep) = sign(ku)`（`Mu=0` 记 `NONE`），`n_neg_u` / `n_pos_u`；
`n_neu_u = #{|ku| < KAPPA_MIN}` 单列（**不是**把接近 0 的当 0）。

精确二项双侧检验（`H0: p=0.5`），`n` = 有效判点数（`Mu>0` 的 ep 数）：

| 条件 | 判词 |
|---|---|
| `n_neg_u ≥ 9` 且 `|median(ku)| ≥ KAPPA_MIN` | `DIRECTION-CONFIRMED:USER-ALLOCATION` |
| `n_pos_u ≥ 9` 且 `|median(ku)| ≥ KAPPA_MIN` | `DIRECTION-CONFIRMED:USER-ALLOCATION-POSITIVE` |
| 两向均 `< 9` | `DIRECTION-UNRESOLVED` |

`kf` 同表独立判 `:FRAME-SELECTION`。两向都确认 ⇒ `DIRECTION-CONFIRMED:BOTH`。

**★ 零假设的偏置（必须报）**：`E_user+E_frame+E_within ≡ Δr` ⇒ 三项中至少一项与 `Δr` 同号，
所以"某项与 `Δr` 同号"的先验概率**不是** 0.5。三项份额在与 Δr 同号/异号上的**最大熵分布**给
`P(指定项与 Δr 同号) ∈ [1/3, 1/2]`。**主判用 `p=0.5`（保守端）**，并同报 `p=1/3` 端；
两端的 `p` 同时满足 `≤0.05` 才写"确认"。引用时必须写"用的是哪一端"。

**预注册阈值**：`KAPPA_MIN = 0.01`（1 个百分点的送达率变化）。
选择理由（量纲，不看真值）：`ku` 的上界是 1；数值地板 `1/N^E`（一次送达）量级约 `0.003`；
`0.01` 约为地板的 3 倍，且与"送达率分辨率"议题里用惯的 1 个百分点同阶。
**阈值敏感性表必报**（§6 `S8`）：`KAPPA_MIN ∈ {0.005, 0.01, 0.02}` × `S_desc 门槛 ∈ {0.01, 0.02, 0.05}`，看判词是否翻转。

### §4.2 `Q_mag` —— 量级

对每个被判方向确认的机制，报 `ku`（或 `kf`）的：
`mean` / `median` / 配对 bootstrap 95% CI（**重采样单位 = episode，`n=10`，10⁴ 次，seed=20261024**）/
逐 ep 值全表 / `min` / `max`。

**不用 `|ku| ≥ x` 做判词**（量级不是二元事实），只报数与区间。

### §4.3 `Q_share` —— 描述（不判）

按 §3.3 报。**旧判词 `MIXED-MECHANISM-AT-N10` / `MIXED-WEAK` 保留在 R1.16 证据里，不改写**；
本轮新增一句：`MIXED` 是 `Q_share` 的答案，在 `Q_dir`/`Q_mag` 口径下机制**不随 ep 分岔**（若 §4.1 判 `CONFIRMED` 且
符号计数一致）。两个判词**同时有效、答不同问题**，不许互相替代。

### §4.4 `M6'` —— 预测因子重问（**因变量换了，必须披露**）

R1.16 的 `|Δp_bad| → sh_user` 的因变量被 §2 的缺陷污染 ⇒ 作废。
本轮问：`|Δp_bad| → ku`（尺度不变），样本 = **10 个 `Mu>0` 的 ep**（**不再用 `DR_MIN` 筛点** —— `ku` 不需要 `Δr` 当门槛）。

- 统计量：`Spearman` + 双侧置换 `p`（10⁵ 次，seed=20261024）
- 门槛沿用 R1.16 一字不改：`|ρ|<0.40` ⇒ `REJECTED`；`ρ≥0.60` 且 `p<0.05` ⇒ `SUPPORTED`；其余 `INCONCLUSIVE`
- **必报**：错位一位对照 `ρ_shift`、`n_points`
- ★ **对称汇报**：同一批点上同时给 `|Δp_bad| → sh_user`（旧因变量）与 `→ ku`（新因变量）两个 `ρ`，
  让"换因变量带来的变化"可核对，避免"换到能过为止"。
- ★ 若 `|ρ_shift| ≥ |ρ|` ⇒ 必须写 `NO-PREDICTIVE-INFORMATION`（错位对照不比真配对弱 ⇒ 相关性不可信）。

### §8-1（21:1x，**R1.17 首条自伤**）§0.1 首版数值是**手写未核**

- **发生了什么**：本节首版（21:06 写卡时）的 §0.1 表里，我把 10 个 ep 的 `Δr` / `E_user` / `E_frame` / `E_within`
  凭 STATE 的摘要**手写推算**出来，而未打开 `decomp.json`。全部数值错误（例：`ep100` 我写 `Δr=−0.2033`、实测 **−0.13562**；
  `E_user` 我写 −0.0393、实测 **−0.02646**）。
- **为什么是错的**：我把 `Δr` 的均值 `−4.96 pp` 与个别份额的极值混着外推，等于**编造了 10 个 ep 的"已见"清单**。
  这在预注册卡里是最坏的错误类型 —— 披露区造假会使后面所有"我没见过 X"的声明失去意义。
- **怎么发现**：写卡后立即打开 `decomp.json` 做对账（`E_* = share_* × Δr`），发现 `ep100` 的 `share_user×dr` 与手写值不符。
- **更正**：§0.1 已替换为实测值（含 5 箱与 10 箱的 `E_user` 逐位相同这一结构性事实）。
- **教训（追加到自伤清单）**：**"已见清单"只能从证据文件抄，不能从记忆/摘要推**。凡写"我见过 X"必须先 `grep`/`json.load` 一次。
- **影响面**：无新计算发生在此之前；`Mu/Mf/ku/kf` 从未被算过 ⇒ 判据设计未被污染。

### §8-2（21:1x，**看数前**，为定分母门槛而先验分母量级）

- **触发**：§3.2 的 `ku = E_user/Mu` 若 `Mu` 极小会像 `share` 一样爆 ⇒ 必须给分母一个下限，否则"换判据"只是把同一个病换个位置。
- **做了什么**：只算分母（`Mu`/`Mf`）与 `N^E`，**`ku`/`kf` 的任何数值此时仍未计算**（探针脚本只输出分母）。
- **实测（10 个 ep，10 箱）**：`N^E ∈ [494, 507]`、`Mu ∈ [0.04609, 0.20817]`、`Mf ∈ [0.08617, 0.23008]`。
- **新增常量**：`MU_MIN = 0.01`。依据：数值地板 `1/N^E ≈ 0.0020`，`0.01` 约 5 倍地板，
  折算为"约 5 次净搬动"（`0.01×500/2`），是"机制发生了"的最低可信量级。
- ★ **如实写**：**该门槛在本面板上不起筛选作用** —— 10 个 ep 的 `Mu` 与 `Mf` 全部 `> 0.046`。
  ⇒ 判词**不依赖**这个门槛；它的作用只是"若未来面板出现 `Mu≈0` 的格，不许把它当机制成立"。
- **未改变**：§4.1 的 `KAPPA_MIN = 0.01` 保持不变（那是 `ku` 的量级门槛，与 `MU_MIN` 是两件事：
  一个管分母够不够大，一个管效应够不够大）。

### §8-3（21:1x，**判据自伤 2 条**，发生在看 10 个 ep 的 `ku` 之前）

  与 R1.15 的"份额判据里两者都 ≥x 常算术不可能"同族错误，**又犯了一次**。
  改为可操作、不依赖拍的阈值：**符号翻转 + ≥10× + `ku` 逐位不变**。

### §8-4（21:2x，**口径更正**，非修订判据）

### §8-5（21:2x，**判据自伤 3：上界公式漏 1/2**）

预注册 §3.2 与本卡正文写"`|ku| ≤ max_i|ρ_i − ρ_a|`"。构造 `S3` 给出 `ku = −0.6`，
而该构造的 `max|ρ_i − ρ_a| = 0.4` ⇒ **当场矛盾**。

正确推导：`ku = Σ_i (2m_i/Σ|m|)(ρ_i − ρ_a)`，权重绝对值之和为 **2**
⇒ `|ku| ≤ 2·max_i|ρ_i − ρ_a| ≤ 2`（`0.6 ≤ 0.8` ✓）。
根因：`Mu = Σ|m|/(2N)` 里的 `2` 在化简时被我丢了 ⇒ **又一次 2× 手算错**（与 R1.14 的 `v*` 同类）。
已写进 `mech.py` 的 `ku_bound` 与闸 `4ab`（用 `ku_bound` 做断言，不再是说明性字段）。

### §8-6（21:2x，**判据自伤 4：第四条"阈值不可达"**）

闸 `4aa` 首版用"`+8` 个送达"（`dr=+0.02`）与"`−1` 个送达"（`dr=−0.0025`）配对，
断言 `|share_C| > 10|share_A|`。实际比值只有 **8×**（`0.02/0.0025`）⇒ FAIL。
`|dr|` 只能取 `1/N^E` 的整数倍，**8× 是该构造的物理上限**。
改为"把送达加满"（`Σnd_e = Σni_e` ⇒ `dr=+0.5`）后比值为 **200×**，与 `S1` 的 208× 同阶。

★ 一轮内"阈值不可达"复发 **两次**（§8-3 的 `1e3`、§8-6 的 `10×`）⇒ 已列为硬约束：
**写任何"≥ x 倍"之前，先用构造算出该量的可达范围。**

### §8-7（披露：`S1`/`S6` 造成了**单点** `ku` 泄露）

`S1`/`S6` 要证明"只改 `nd_e` 时 `ku` 不动"，必须用**真实**计数矩阵（合成矩阵说服力弱）。

- **留下的事实**：`ku` 的**量级**（0.30）是本轮新读到的，且它是 10 个点里 `|ku|` 第 4 小。
