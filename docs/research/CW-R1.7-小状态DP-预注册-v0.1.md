## 0 一句话

R1.5/R1.6/R1.6.1 的尾部是**解析估计**（均匀配速 + 稳态循环均值），它把"多花一帧"的价格估到
**0.0225**，而一帧的收益上界只有 **0.006**（3.8×，R1.6.1 实测）⇒ 规划器**推迟花帧**
（`send_profile` 前松后紧、`G8a` FAIL）。本轮把尾部换成 **`(P_0,P_1,b)` 网格上的精确后向 DP**，
判据是"DP 算术正确 + 配速形对 + MC 稳定 + 变异抓得住"；**只有全过才允许读 `N1`/`N2`**。

## 1 问题、基线与信息

| 项 | 内容 |
|---|---|
| 问题 | 尾部（`H` 步之后）的**期望任务代价**怎么算才对？它决定"现在这一帧值不值" |
| 基线 | ① 解析尾部 `_paced_sumP`（R1.6.1，`m` 实数）；② `pacing=False`（R1.5 的"再无观测"外推）；③ `HOLD` |
| 信息 | **不变**：只吃 `SchedulerView`（`prior`/`telemetry`/`history`/`budget_left`/`t`）。已知生成参数（`A,B,σ_w,σ_meas,ρ,κ,log h*,q,r`）不算读真值 |
| 参照性质 | DP 解是**有限视界、给定当前信道信念下**的条件最优 ⇒ 仍是 **planning reference，不是全局上界**；`kind` 延续 `PLANNING-REFERENCE-NOT-UPPER-BOUND` |

## 2 方法（近似逐条写清，不许事后补）

DP 的值只算**任务侧**代价 `q·Σ_i P_i,k`（`k=1..τ`）；`q·x̂²` 与 `r·u²` 两项按名义 `α=A−BK` 解析外推
（与 `_terminal` 现有分解一致，理由见 `plan_ref._terminal` 的 docstring）。

```
V_0(p0,p1,b) = 0
V_τ(p0,p1,b) = q(p0+p1) + min{
   HOLD :           V_{τ-1}(f0(p0), f1(p1), b)
   SEND i (b≥1):    p̂_i·V_{τ-1}(d_i(p_i), f_j(p_j), b−1)
                  + (1−p̂_i)·V_{τ-1}(f_i(p_i), f_j(p_j), b−1)
}
f_i(p) = A_i²p + σ_w,i²                    （不刷新）
d_i(p) = A_i²(1−g_i)p + σ_w,i², g_i=p/(p+σ_meas²)   （送达 + 量测更新）
```

明写的**四个近似**（任一被推翻则本轮结论作废）：

1. **信道信念冻结**：`p̂_i` 在整条尾部取**槽初**值。⇒ DP **不内生化 PROBE**（探测的价值只能经由
   外层 rollout 的 H 步条件信念采样体现）。这是本轮最硬的近似，也是"DP 不能替代探测评估"的原因。
2. **`PROBE` 在 DP 里没有动作**：它只花一帧、不动任务估计 ⇒ 在 DP 内恒被 `HOLD` 支配。
   外层 rollout 仍保留 `PROBE`（同一代码路径），是否被选是**实测量**，不是设计断言。
3. **`b ≥ 2τ` 饱和**：超出"每槽每用户各一帧"的预算没有额外价值 ⇒ `V_τ(·,b)=V_τ(·,2τ)`。
4. **网格 + 分段线性插值**：`p` 轴用**分段非均匀结点**（细段覆盖 0–0.06 的实际工作区、粗段到 1.6
   以覆盖 `t=0` 的 `P=1.0` 先验）。出界一律夹到端点并计数（不许静默）。

## 3 判据（看数前写死；顺序不可跳）

| 闸 | 判据 | 什么错误能让它 FAIL |
|---|---|---|
| **D1** | `b=0` 时 DP 逐值与解析"再无观测"外推一致（`‖Δ‖/‖·‖ ≤ 1e-9`，`τ∈{1,4,16,64,128,256}`、两用户、3 个 `p0`） | 网格/插值/递推写错；`f_i` 少了 `σ_w²` |
| **D2** | `V_τ` 对 `b` **单调不增**（`V(b+1) ≤ V(b)+1e-12`，全网格全 τ 抽样） | 预算方向写反、`b−1` 写成 `b+1`、插值越界夹错 |
| **D3** | `V_τ(p,b) ≤ ` 解析配速尾部 `_paced_sumP`（同一 `(p,b,τ)`，允许 `−2%` 数值松弛；**解析尾部是一条可行策略的代价，不能低于最优**） | DP 少算成本（漏掉某用户/某步）；解析尾部严重低估 |
| **D3b** | 阴性对照：把解析尾部换成 `pacing=False`（无视预算）⇒ 同一对账**必须**出现「解析 < DP」≥ 10 个点（否则 D3 无分辨力） | 对照物与判据同源（自证） |
| **D4** | 饱和档：`b = 2τ` 时 DP 每步均代价 ≈ 每槽都两用户各测一次的稳态（闭式 `P_post`），相对差 ≤ 2% | 送达概率/量测更新写错（`g=P/(P+σ²)` 写成别的） |
| **D5** | **单帧价格**：`τ=32、b∈{8,16,32}` 上 `V(b)−V(b−1)` 随 `τ` 收缩（`τ=8` 的同一价格 ≤ `τ=64` 的 1.5 倍），且量级落进 `[0.001, 0.05]` | 价格与剩余步数**无关**（那正是 R1.6.1 的病）；或量级错一个数量级 |

## 7 事后修改（跑完再填，不改上文）

**A. 跑闸之前的更正（写在这里是为了可追溯，不是事后放宽）**

1. §2 近似 3：原写"`b ≥ 2τ` 饱和"。**错**。动作空间是每槽**至多一个**资源动作
   （`PROBE i / SEND i / HOLD` 三选一），所以饱和点是 **`b ≥ τ`**。已在 `plan_dp.py` 按 `τ` 实现。
2. §3 `D1`：原写"`≤1e-9` 单一阈值"。写闸前用探针量到 `b=0` 列在 `τ≥128` 有 1e-8..1e-5 的
   **插值/浮点底噪**（`b=0` 时值函数关于 `p` 精确仿射，故那不是算术错）⇒ 拆成
   `D1a`（相对 ≤1e-4）+ `D1b`（**斜率**：`τ≤16` 逐位 1e-12、大 τ 1e-4）。实测 `τ≤16` 斜率**逐位相等**。
