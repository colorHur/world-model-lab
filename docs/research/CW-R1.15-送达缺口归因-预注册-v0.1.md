## 1. 问题与两个互斥假设

R1.14 观测：exact 的**尝试数几乎相同**（1001 vs 994），送达却少 18.4%，且 **8/8 格同向**。
在 `event_pairing="slot"` 下，同一 `(t,i)` 上的 `p_true`（由外生 `log h` 决定）与丢包均匀数 `u_packet`
**与策略无关** ⇒ 送达率之差**只能**来自"两臂在哪些 `(t,i)` 上发了"。

- **H-a「选错帧」**：exact 的 SEND 落在 `p_true` **更低**的槽（信念更校准 ⇒ 阈值筛出的帧变了）。
- **H-b「选错用户」**：两臂的尝试**分配**不同（`[546,448]` → `[489,512]`），而 u1 的基础成功率更低
  ⇒ "更均衡"本身降低送达率。

两者都可能同时成立（不是互斥的物理过程，而是互斥的**解释**）。

## 3. 判据（先定义，逐条可证伪）

### 3.1 主量

对每个 `ep ∈ {100,101}`：把该 ep 的 4 个 seed 的**计数矩阵逐格相加**（不是对率取平均），得
`N^E_{i,b}, K^E_{i,b}`（exact）与 `N^A_{i,b}, K^A_{i,b}`（approx）。记
`N^a = Σ N^a_{i,b}`，`K^a = Σ K^a_{i,b}`，`r^a = K^a/N^a`，**`Δr = r^E − r^A`**。

### 3.2 精确可加分解（三项，和为 `Δr`）

令 `m_{i,b} = N^E_{i,b} − N^A_{i,b}`（尝试数差），`m_i = Σ_b m_{i,b}`；
参考率 `ρ^A_{i,b} = K^A_{i,b}/N^A_{i,b}`，**空组回退规则（预先声明）**：`N^A_{i,b}=0` 时取 `ρ^A_i`，
若 `N^A_i=0` 再取 `ρ^A`。回退只改**归因标签**，不改总和的精确性（下面恒等式对任意参考率成立）。

```
E_user  = Σ_i  m_i · (ρ^A_i − ρ^A)            / N^E      ← H-b：跨用户重新分配
E_frame = Σ_i Σ_b m_{i,b} · (ρ^A_{i,b} − ρ^A_i) / N^E    ← H-a：用户内跨 p 箱重新分配
E_within= Σ_i Σ_b [ (K^E_{i,b} − K^A_{i,b}) − ρ^A_{i,b}·m_{i,b} ] / N^E
Δr      = E_user + E_frame + E_within                     （恒等，容差 1e-12）
```

`E_within` 是**箱内选择 + 硬币运气**，**不许**被当成第三个机制解释；它的占比就是"分箱分辨率解释不了的部分"。

### 3.3 判词（主分辨率 = **10 箱**；5 箱只作敏感性）

先过前置条件：`|Δr| ≥ 0.010`（1 个百分点），否则 `GAP-TOO-SMALL`，不判机制。
份额 `sh_X = E_X/Δr`（三项和 ≡ 1）。**某机制在某 ep 成立** ⟺ `sh ≥ 0.60` **且** `sign(E_X)=sign(Δr)`。

| 情形（两 ep 一致时） | 判词 |
|---|---|
| `E_frame` 与 `E_user` 都成立 | `BOTH-MECHANISMS` |
| 只有 `E_frame` | `H-A-FRAME-SELECTION` |
| 只有 `E_user` | `H-B-USER-ALLOCATION` |
| 都不成立（`sh_X<0.60` 或异号） | `DELIVERY-GAP-UNEXPLAINED` ⇒ **停在这条**，不许换第三个候选去凑解释 |
| 两 ep 结论不同 | `EP-DEPENDENT` |
| 10 箱与 5 箱判词不同 | `RESOLUTION-SENSITIVE`（结论降级为"仅 10 箱粒度"） |

### 3.4 描述量（**不作判据**，但必须与判据同报）

`attempt_p_true_mean` 与 5 个分位，逐 ep、逐用户、逐臂。若 H-a 成立，exact 的该均值应**更低**；
若两者矛盾（分解说 H-a、分布说 exact 不低），**以分布为准并把分解标 `CONTRADICTS-DISTRIBUTION`**。

### 3.5 否定条件（命中即该结论作废，不许事后放宽）

1. 身份闸不过（16/16 不是全逐位相同）⇒ **本轮全部结论作废**（纯记录改了数字 ⇒ 记录不纯）。
2. 分解恒等式残差 > 1e-12 ⇒ 分解实现有错，结论作废。
3. 合成已知答案对照不过（§4）⇒ 判据无分辨力，结论作废（`#39`：先问什么错误能让它 FAIL）。
4. `E_within` 份额 > 0.40 且判词指向单一机制 ⇒ 降级为 `PARTIAL`（机制只解释不到六成，不许说"就是它"）。

### §8-1 「两机制都成立」的阈值逻辑（2026-10-24 16:5x，**只看过 C1–C6 合成对照，未看任何面板数字**）

原文 §3.3 写"`E_frame` 与 `E_user` 都成立 ⇔ 各自 `sh ≥ 0.60`"。**这在算术上不可能成立**：
三项份额**和为 1** ⇒ 两个份额同时 ≥0.6 需要和 ≥1.2。
`C4`（设计成 0.5/0.5 的联合情形）当场把它暴露成 `DELIVERY-GAP-UNEXPLAINED`。

修订：**单机制** `sh ≥ 0.60`；**联合**区间 双方 `sh ≥ 0.40`（且符号同 `Δr`）。
`0.60` / `0.40` / `Δr ≥ 0.010` / `E_within > 0.40 降级` 四个数**一个未动**，只修"两个条件怎么组合"。
`C1–C6` 在修订后 6/6 通过，`C5` 的符号翻转检查也通过。

### §8-2 `C5` 的比较对象是**绝对项**不是份额（同上时点）

"符号必须跟着翻"不能比份额：份额 = `E/Δr`，`E` 与 `Δr` 同时翻号 ⇒ 份额不变（恒 +1）。
改为比 `E_frame` 的**绝对项**（C3 = −0.12、C5 = +0.12，乘积 < 0）。

### §8-3 `C4` 的构造本身错过一版（同上时点，属**对照设计**修正，不动判据）

第一版 `C4` 的四个矩阵恰好凑出 `Δr = 0`（写卡时手算没做），于是它既不能测"联合"，也无法当活动对照。
改成"C2 的一半 + C3 的一半落在同一基座"（5 次粒度），`Δr = +0.010×10`，份额 0.5/0.5。
