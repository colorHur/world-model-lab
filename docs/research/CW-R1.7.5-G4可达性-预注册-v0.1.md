## 1. 前提检查（先查错，再动手）

### 1.1 §7.2 的推理有一处跳跃

§7.2 写：「`M=16` 的 Monte-Carlo 相对标准误本身就在 `1/√16 ≈ 25%` 量级 ⇒ 这条线可能结构性不可达」。

- `1/√16` 是**值函数估计**的相对标准误，**不是**成本漂移。
- 成本漂移 = 决策翻转 × 翻转带来的成本差。若多数时点候选项之间的价值差**远大于**噪声，
  翻转率可以很低，成本漂移就可以远小于 25%。
- ⇒ **"25% ⇒ 不可达"是逻辑跳跃，本轮用实测回答，不用这个推论定判。**

### 1.2 `G4` 的 `diff` 只能由"动作不同"引起

`cost_true` 是真实过程下的成本，与规划器的采样无关。⇒ 两条轨迹若动作逐槽相同，`cost` **必须逐位相同**。
所以 `|c32−c16|` 完全由决策分叉驱动。这是一条**可证伪的不变式**，写进 `P0d`。

### 1.3 `P2`（斜率 ≈ `c/√M`）如果不写清"跨什么取样"，就是恒等式

- 若"样本标准差"指**内层 M 个样本均值**的标准差：按构造它就是 `c/√M`，斜率 −0.5 是**恒等式**，
  任何缺陷都能过（教训 #39：先问"什么错误能让它 FAIL"）。
- ⇒ 本卡把 `P2` 定义为：**同一 `(episode, seed 组)` 下，跨 `R` 个独立 seed 的 `cost_true` 标准差随 `M` 变化**。
  这个量不是恒等式：若决策在 `M` 增大后阶梯式稳定，斜率会**比 −0.5 更陡**；若有未播种随机源，斜率会**接近 0**。

### 1.4 `G4` 的 `n=2` median

`np.median` of 2 = mean，且**没有不确定度**。本轮**不改** `G4`（不改判据），只量出这个量的分布宽度。

## 2. 判据（写死，跑之前定）

### P0 结构性检查（秒级）

| 闸 | 判据 | 预期 |
|---|---|---|
| `P0a` | `_Draws(rng(777), 5, 16, 2)` 与 `_Draws(rng(777), 5, 32, 2)[:, :16, :]` 的 7 个数组**全部不等** | `True` ⇒ `CRN-NESTED-NOT-AVAILABLE` 是结构事实 |
| `P0b` | **活体阴性对照**：手工按 `pool_M=32` 造 `_Draws` 再切前 16 ⇒ 必须与 `M=16, pool_M=32` **逐位相同** | `True`（证明"嵌套可判定"，不是检查没分辨力） |
| `P0c` | `_Draws(..., pool_M=None)` 与改动前的构造**逐位相同**（用 `0426fcb` 的构造公式在本进程内重算比对） | `True`（改被测物不改默认路径） |
| `P0d` | 同 `(seed, ep, M)` 下 `agree==1.0` 的 episode，其 `c16` 与 `c32` 必须**逐位相同** | `True`（§1.2 不变式） |

### P1 独立样本分布（`nested=False`，即现状口径）

- 格：`ep ∈ {100,101,102,103}` × `seed ∈ 2001..2008`（8 个）× `M ∈ {16,32}`。
- 量：`rel_indep = |c32 − c16| / max(c16, ε)`，`agree`。
- 统计：`rel` 的**中位**、`p90`、`>0.10` 的比例；`agree` 的中位。
- **判据**：`rel_indep` 中位 **> 0.10** ⇒ 现状口径下 `G4` 的 10% 线不可达。

### P3 嵌套边际（`nested=True`，与 P1 同 `seed/ep`，只改采样是否嵌套）

- `pool_M = 32` ⇒ `M=16` 看到的是 `M=32` 的**前 16 条**，差只来自"新增的 16 条"。
- 量：`rel_nested`、`agree_nested`。
- **判据**：`rel_nested` 中位 **> 0.10** ⇒ 连"仅新增路径"都超线 ⇒ 结构性不可达。

### P2 方差收敛速率

- `M ∈ {16,32,64}`，`ep ∈ {100..103}`，`seed ∈ 2001..2008`。
- 量：对每个 `(ep, M)`，跨 8 个 seed 的 `cost_true` 的**样本标准差** `s(M)`。
- 拟合 `log s` 对 `log M` 的斜率（最小二乘，逐 episode 各一条）。
- **判据**：斜率 ∈ `[−0.65, −0.35]` ⇒ 符合 `c/√M`；`> −0.35` ⇒ `VARIANCE-FLOOR`（有偏或未播种源）；
  `< −0.65` ⇒ `VARIANCE-STEP`（决策阶梯化，不是缺陷，但要记）。

## 3. 判词映射（先写死，不许事后调）

| 条件 | 判词 | 含义 |
|---|---|---|
| `P0c` 失败 | `HARNESS-MISMATCH` | 改坏了默认路径，整轮作废 |
| `P0b` 失败 | `NO-POWER` | "嵌套"这个概念在本环境不可判定，检查无分辨力 |
| `P0d` 失败 | `CONTRACT-VIOLATION` | §1.2 不变式被破 ⇒ 有隐藏随机源，先查它 |
| `rel_nested` 中位 ≤ 0.10 且 `rel_indep` 中位 > 0.10 | **`G4-CONFOUNDED-BY-DECORRELATED-DRAWS`** | `G4` 的崩不是"M 不够"，是**两次抽样不配对**；修法是让采样嵌套，不是加大 `M` |
| `rel_nested` 中位 > 0.10 | **`G4-UNREACHABLE-AT-M16`** | 连新增 16 条路径的边际都超 10% ⇒ 线本身在 `M=16` 不可达，须改判据（另立卡） |
| 两者都 ≤ 0.10 且 `agree ≥ 0.90` | `G4-PASSES-UNDER-REPEAT` | 原 FAIL 是单点采样，扩重复数即可 |
| `P2` 斜率 | 见 §2 | 与上面正交，单独报 |

**否定条件（预注册就写）：** 若 `rel_indep` 与 `rel_nested` 的**中位差 < 0.01**，
则"配对/不配对"这条解释**不成立**，不许把它写成主因。

## 4. 参数与预算（写死）

```python
EPS      = (100, 101, 102, 103)
SEEDS    = tuple(range(2001, 2009))          # 8 个
M_LIST   = (16, 32)                          # P1/P3
M_VAR    = (16, 32, 64)                      # P2
RHO      = 0.98      # = plan_gates.RHO_DEFAULT
RATIO    = 0.5       # = G4 用的 cfg.protocol.budget(0.5)
H_PLAN   = 5         # = G4 用的 h_plan
ARM      = "probe"
PACING   = True      # 默认尾部 = "paced"（不混 dp）
```

- 预算估计：单次 `run_episode` 实测 4.1–4.6 s（`ρ=0.98`）⇒
  `P1` 64 次 + `P3` 64 次 + `P2` 新增 32 次（`M=64`）≈ **660 s**，加装配与落盘开销预计 **12–16 min**。
- 超预算处理：若实测 > 25 min，**砍 `SEEDS` 到 6 个并如实记**，不许砍格。
