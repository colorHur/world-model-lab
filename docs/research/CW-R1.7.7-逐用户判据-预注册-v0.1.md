## §1 问题

上一轮拿到的是**聚合**结论：`Δcost_est` 的符号 3 正 5 负、CI 含 0 ⇒ 定不出方向。
本轮问：这个"定不出方向"是哪一种？

- **A** 两个用户方向相反、各自很稳 ⇒ 聚合把它们抵消掉了；
- **B** 两个用户各自也没方向 ⇒ 8 对本来就不够；
- **C** 一个用户稳、一个不稳；
- **D** 两个用户同向且稳 ⇒ 上一轮的符号翻转是"聚合噪声"，方向其实存在。

这四种对下一轮的处置**完全不同**（改面板比什么量 / 做 power 卡 / 先补样本 / 直接进面板）。

## §4 判据（写死；先算后判，不算完再改）

**记号**（`p` 遍历 8 个配对，`u ∈ {0,1}`）：

- `Δ_u(p) = cost_est_by_user_u(dp16,p) − cost_est_by_user_u(paced16,p)`
- `s_u(p) = sign(Δ_u(p))`；`Δ==0` 记 `TIE`，**单独计数**，不进 `#pos/#neg`
- **一致率** `c_u = max(#pos, #neg) / 8` —— **分母恒为 8**（`TIE` 照样占分母 ⇒ 保守）
- **逐用户比值** `R_u = median_p( dp_u / paced_u )`；**同报** `median_p(dp_u) / median_p(paced_u)` 作交叉核对。
  两者符号相反 ⇒ 标 `RATIO-UNSTABLE`，**`R_u` 不引用**（教训 #102：分母子集未钉死不许报比值）
- **地板** `f_u` = 该用户 `cost_est_by_user` 的**跨种子**相对差中位（同 `ep`、不同 seed 两两配对，`6` 对/`ep`），
  对 `paced16` 与 `dp16` **各算一套**，**取较大者**报（保守）

**判词（互斥，按序命中即停）**：

| # | 条件 | 判词 |
|---|---|---|
| 1 | `c_0 ≥ 7/8` 且 `c_1 ≥ 7/8` 且 `s_0·s_1 < 0` | **`AGGREGATE-CANCELS`** |
| 2 | `c_0 ≥ 7/8` 且 `c_1 ≥ 7/8` 且 `s_0·s_1 > 0` | **`SAME-DIRECTION`** |
| 3 | 恰有一个 `c_u ≥ 7/8` | **`ONE-SIDED-AT-8`** ← **本卡补充的第 4 分支**（STATE §7.2 只写了 3 条，缺口在此补，且补在算之前） |
| 4 | 两个 `c_u` 都 `< 7/8` | **`NO-DIRECTION-AT-8`** |

★ **同时必报精确符号检验 `p`**（`n=8`，剔除 `TIE` 后二项两侧）：
**`7/8` 的两侧 `p = 2·(C(8,0)+C(8,1))/2⁸ = 0.0703 > 0.05`** ⇒ 若判词落在 `7/8` 而非 `8/8`，
必须同写"**未过 0.05，方向未在统计上定住**"，**不许**称"方向已定"。
★ 若 `TIE` 出现，`n` 变小，`p` 按实际 `n` 重算并同报。
