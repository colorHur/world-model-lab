## §1 问题

`plan_ref` 里 `p̂ = P(success | m, v)` 的**唯一**在线信息源就是 `_ack_bump`（PROBE 是另一条，但要花预算）。
`_ack_bump` 的幅度是**手写常量**：把一次二值结果折算成"方差 0.63 个 log 单位"的伪观测；`world.py` 注释自承
"这不是精确贝叶斯"。归属缺陷（R1.10→R1.11）修好后，第一次可以干净地问两个问题：

- **Q1（信息模型）**：与精确贝叶斯后验相比，这条伪更新的**等效量测方差**是多少？方向是偏"过度自信"还是"过度保守"？
- **Q2（是否影响任务）**：把更新换成精确贝叶斯，`cost_true` / 逐用户送达 / `aoi` 会不会变？变多少，是否超过地板？

## §2 解析（写卡时手算；Q1 的**先验答案**，必须用数值积分复核）

似然 `p(m) = sigmoid(κ(m−m*))`，`κ=2`、`m*=0`、先验 `m ~ N(m̂, v)`。

**一次二值观测的 Fisher 信息**（对 `m`）：

```
I(m) = (∂log p/∂m)² / (p(1−p)) = κ² · p(1−p)          ⇒  R_eff(m) = 1 / (κ² p(1−p))
```

- 在 `m = 0`（信息最大点）：`p = 0.5`，`R_eff = 1/(4·0.25) = **1.00**` ⇒ 是 `ACK_VAR = 0.63` 的 **1.587 倍**。
- `|m|` 增大 ⇒ `p(1−p)` 减小 ⇒ `R_eff` 增大（`|m|=2` 时 `κ²p(1−p)=4·sigmoid(4)(1−sigmoid(4))≈4·0.0713=0.285` ⇒ `R_eff≈3.5`）
  ⇒ 语义正确：**信道已经很差/很好时，再成功一次几乎不含信息**。
- 结论（待数值复核）：现状 `ACK_VAR=0.63` 在所有 `m` 上都**小于**精确等效方差 ⇒ **过度自信**（后验方差收缩过快）。

**Laplace（在先验均值处展开，一阶高斯近似）**：

```
Δm = v·κ(a − p) / (1 + v·κ²·p(1−p))          v_post = v / (1 + v·κ²·p(1−p))
```

`m̂=0, v=1, a=1`（ACK）：`Δm = 0.5`，`v_post = 0.5`。
现状实现：`g = v/(v+0.63) = 0.6135` ⇒ `Δm = 0.6135`（**大 23%**）、`v_post = 0.3865`（**多收缩 23%**）。

**可证伪的结构性差异**：精确版的位移幅度依赖 `(m, v)`，现状只在 `v` 上依赖 ⇒
同一个 `v` 下，`|m|` 越大，精确版的位移越小、现状几乎不变。这条差异**只在 `m` 偏离 0 时有分辨力**，
所以 §4-P2 必须取"已经历过若干 ACK/NACK 的用户"，不能取 `t=0` 的对称初态。

## §3 被测物与不变量

1. **新开关** `ChannelConfig.ack_mode ∈ {"approx", "exact"}`，**默认 `"approx"`** ⇒ 旧 16 格必须**逐位不变**（闸 4q）。
2. **exact 模式**实现：对每个用户在**固定一维网格** `m ∈ [−8, 8]`（Δ=0.05，321 点）上维护后验密度；
   - AR 传播：高斯核转移矩阵 `T[k,j] ∝ φ((x_k − ρx_j)/s)`，`s = sqrt(1−ρ²)`，逐列归一（边界质量靠列归一化回收）；
   - ACK/NACK：乘伯努利似然 `p(m)` 或 `1−p(m)` 后归一；
   - PROBE：乘高斯似然 `N(y; m, σ_csi²)` 后归一（**必须**这样，否则 exact 臂的 PROBE 信息会被网格覆盖掉 ⇒ 变成"不仅换了 ACK，还废了 PROBE"的双变量混淆）；
   - `_m_h[i] / _v_h[i]` 改为**后验矩的导出量**（每步末由网格算），不再是独立状态；`plan_ref` 消费面不变。
3. **不改** `plan_ref`、`runner` 的默认行为；不改 `ACK_VAR`、`±1.0/−1.5` 常量（要改另立卡）。
4. 信息边界不动：网格只由"公开动作 + 收到的 ACK/NACK + PROBE 读数"更新，不读 `_log_h_true`。

## §4 判据（看数前写死）

**Q1（零 episode）**
- 报 `R_eff(m)` 表：`m ∈ {−3,−2,−1,0,1,2,3}` × `v ∈ {1.0, 0.5}`，列 `R_eff`、`R_eff/0.63`。
- 报精确后验（数值积分，2001 点）与 Laplace 的 `sd` 差、`Δm` 差 ⇒ Laplace 自身的误差必须同报（不得只说"精确"）。
- 判词 `ACK-VAR-OVERCONFIDENT`：`R_eff(0)/0.63 ≥ 1.2` **且** 6 个 `m≠0` 点同向（全部 >1）。
  否则判 `ACK-VAR-SCALE-OK`（若 6 点方向不一致）或 `ACK-VAR-UNDERCONFIDENT`（全部 <1）。

**Q2（面板，16 格 = 2 ep × 2 mode × 4 seed）**
- 主量：逐 episode 的 median `cost_true_per_step`，配对数 `Δ = exact − approx`（同 seed 同 ep ⇒ CRN 配对；
  ★ 配对合法性**必须先验**：`pairing="slot"` 下 packet/meas/csi 按 `(t,i)` 预生成，plant/channel 噪声每步一抽 ⇒
  同 seed 下两个 mode 消耗的随机数**位置相同、数量相同**。这一条由闸 4p 用"approx 模式重跑 1 格 = R1.11 入库值逐位相同"来背书）。
- **地板**（§5）：`floor = 0.0333`（四组 MAD 的最大值）。若两集 **都** `|Δ| < floor` ⇒ 判 `PANEL-CANNOT-RESOLVE`，
  **不许**写"精确版更好/更差"，也**不许**写"因此 ACK 不重要"（后者是"测不出"滑成"无效应"，台账 SOUL 明令禁止）。
- 副量（必报，不许挑）：`aoi_tavg_by_user`、逐用户 `n_attempted`/`n_delivered`、`n_probe`、`n_never_served`、
  `phat_diff_median`、以及**逐用户 `r_i`**（任一 >1 ⇒ 只能写"交易"，R17）。
- 机制预测（**可证伪**）：exact 臂对"被 NACK 多次的用户"的 `p̂` 下压更浅（方差收缩慢）⇒ 该用户的 `n_attempted` 应**高于** approx 臂。
  若反向，记录并作废这条预测，不得反改卡。
