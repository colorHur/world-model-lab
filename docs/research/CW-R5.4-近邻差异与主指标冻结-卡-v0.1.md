## §3 主指标冻结（`v1.0`）

### 3.1 三个主量

| 代号 | 定义 | 单位 | 必须同报 |
|---|---|---|---|
| **M1 `IV(X)`** | `A0 − V(X)`，`A0 = V(noprobe)`，**同实例/同网格/同 GH/同 `n_m`** | **发送量子**（1 量子 = 8 刻度 = 1 次整包发送） | `A0` 与 `IV/A0`（%） |
| **M2 前沿** | `(τ−1, b)` 上的 `IV` **四分类** | 时隙 / 量子 | 每格 `n_m`、分辨率、是否撞顶 |
| **M3 价格** | `c_p = 8p ∈ {0,1,2,4,8}` 刻度 ⇒ `n_sends_left = floor((b−c_p)/8)` | 刻度 / 次 | `n_sends_left` 实际值 |

**符号**：`IV > 0` 表示"允许该动作的那一臂成本更低"。

### 3.2 误差口径（**本线没有统计抽样**）

对象是**确定性 DP 解**（零 episode、零训练）⇒ **不存在抽样分布**。
允许报的只有三类**数值**不确定性：

1. **网格**：`n_m` **三点起**（17/33/65 或 65/129/257），报 `spread_rel` 与"最细格是否自证"（两点只能报"有偏置"）。
2. **积分**：GH 节点 21 vs 41，报相对差。
3. **截断**：`STATE_CAP=6e6` 是否 binding（binding ⇒ `unmeasured`，**不写 0**）。

**禁止**：`mean ± std`、`p` 值、置信区间、"误差棒 = 置信区间"。
若将来引入 episode 才有抽样，那时**另立卡**。

### 3.3 零的四分类（R4.2/R5.2/R5.3 血的教训）

| 类 | 判据 | 允许的表述 |
|---|---|---|
| `structural` | 动作在可行性上就不存在（如 `τ=2` 只有 1 个动作时隙） | "结构上不可能" |
| `substantive` | 可行，但 `|IV|` < 分辨率 | "分辨不出正价值" |
| `positive` | `IV >` 分辨率 | 报数值 + 分辨率 |
| `unmeasured` | 撞 `STATE_CAP` / 未扫 | "**未测**"，永不作 0 |

### 3.4 永不作主指标的量（冻结）

1. `IV_free/ΔV_q` —— **参考折算**，不是 WTP，不是价格上界（R5.0 §1.1）。
2. 受限窗口 DP 的 `IV` 绝对值当"控制成本降幅"（对象不同，见 §3.5）。
3. goodput 类比 —— 本文协议下**没测过** goodput。
4. 单点 `n_m ∈ {17,33}` 的读数 —— 只作分辨率证据，不作结论值。
5. 学习模型的"预测更准" —— 与任务成本是两件事（R2 全线）。

### 3.5 对象三层（**合法性**，本轮最硬的冻结）

| 层 | 对象 | ACK 是否更新信道信念 | 可作什么 |
|---|---|---|---|
| **L1** | 完整主环境（`world.py` `ack_mode="exact"`，321 点网格后验） | **是** | **唯一可作主图的对象** |
| **L2** | 受限窗口 DP（`r4_0_boundary.py:102`，`(m,v)` 充分性的前提就是"ACK 不进信道信念"） | **否** | 只能作**诊断图**，且必须标注"策略类受限；其 `IV` 与 L1 的 `IV` **方向未知**" |
| **L3** | 代理目标（只 `q·ΣP`，`r_cost` 不进 DP） | 否 | 只能作机制图，**不得与 L1 数值并列** |

⇒ **直接后果**：R4.0–R5.3 的全部数值都在 **L2/L3**。按本节口径，**三张主图目前一张都没有合法数据**。
这不是"再跑一格"能补的，是**换对象**才能补的（见 §5）。

### 3.7 强基线清单（冻结，缺一不可）

1. `noprobe`（`A0`）：永不探测 —— 所有 `IV` 的分母。
2. **周期探测**：每 `k` 槽探一次，`k ∈ {2,3,4}`（对应近邻 N1 的 periodic policy）。
3. **零探测 + 内生估计**：不探测，用数据侧/控制侧残差估信道（对应近邻 N2 的 pilot-free 机制）。
   ★ **本文协议目前没有这一臂，登记为缺口 R5.5 只做 `n=1` 版本的对照，不做完整实现**。
4. **真值辅助贪心**（`OracleKnown`）：只叫**诊断**，**不是上界**（R1 已定）。
5. **免费探测 `p=0`**：极限参照，不是可执行策略；若 `p=0` 也不买 ⇒ 不是价格问题。
