## 1 问题（一句话）

R3.2 判「探测拿不到价值」，并把机制写成**「探测的代价是一个槽，不是一个量子」**。
本轮只问两件事：

1. **那句话对不对？** 「槽」与「量子」各值多少，能不能测出来（而不是叙述）？
2. **什么窗口/预算下探测才买得起？** 给一条**可算的、能被数据推翻的**判据，并把阈值算出来。

## 2 已跑的探针（★ 先披露，不当事后诸葛）

写下本预注册**之前**已跑过两段一次性探针（未落 `results/`、未入库），结论只用来定面板参数：

- `P1` `price_b` 的**符号**：`V(b) − V(b−1) < 0`（V 是**成本**）⇒ 「量子价」必须定义成
  `ΔV_q = V(b−1) − V(b) > 0`。若照 `STATE` 里 R3.2 的 `price` 写法直接取差，符号会反。
- `P2` 在 `(τ=4, b=1, P=0.005)` 上**把量子设为免费**（`probe_cost=0`）时，最优首步动作**是** `PROBE_1`
  （`4.692680e-2` < `SEND_0` 的 `4.696667e-2`），净赚 **3.99e-5**。
  ⇒ **「探测的代价是槽」这句话至少在 1/15 格上不成立**（若槽是唯一致命成本，免费量子也不该赢）。
- `P3` `Δp̂`（探一个用户、对**一次**发送的有效成功率提升）量级：`v=1` 时 **0.1366**、`v=0.05` 时 0.0408。
- `P4` `ΔV_q / (p̂·ΔV_succ) = 1.04 / 1.05 / 1.01`（`b=1`，三个 `P` 档）⇒ **一个量子 ≈ 一次发送的期望收益**。

据此把量定死（下表）。★ 这些**只定参数，不定判词**；判词见 §4，写死在跑之前。

## 3 量（每个都要能指到表里某格）

| 记号 | 定义 | 来源 |
|---|---|---|
| `ΔV_q` | `V(b−1) − V(b)`：**一个量子**（多一次发送）值多少成本 | R3.2 引擎实测 |
| `ΔV_succ` | `V(P_f) − V(P_s)`：**一次成功**（而非失败）值多少成本 | R3.2 引擎实测 |
| `p̂` | `p_succ_expected(m=0, v)`；`v=1` 时 `=0.5`（对称） | `posterior.py` |
| `Δp̂_UB(v,σ)` | `E[max(p̂(读后), p̂(先验))] − p̂`：**探一个用户**对一次发送的**上界**提升 | 求积（零 DP） |
| `IV_free` | `V_noprobe − V_probe(c_probe=0)`：**免量子**时的实测净增益 | R3.2 引擎实测 |
| `IV_paid` | `V_noprobe − V_probe(c_probe=1)`：**付量子**时的实测净增益 | R3.2 引擎实测 |
| `UB_free` | `b·Δp̂_UB·ΔV_succ`：免量子臂的**解析上界** | 公式 |
| `UB_paid` | `(b−1)·Δp̂_UB·ΔV_succ`：付量子臂的**解析上界**（探完只剩 `b−1` 次发送） | 公式 |
| `b*` | 付量子臂刚好买得起的预算：`(b−1)Δp̂_UB = p̂` ⇒ `b* = 1 + p̂/Δp̂_UB` | 公式 |
| `b*_free` | 免量子臂刚好买得起的预算：`b·Δp̂_UB = 0` ⇒ 解析上界说**恒买得起** | 公式 |

**判据的推导（本轮要写进交付稿的那段）**：DP 在每次发送处对 `p̂` 是**线性**的
（`S + p̂·V_s + (1−p̂)·V_f`），故"知道得更多"的收益 = `Δp̂ × ΔV_succ × (受影响的发送次数)`。
探一次最多影响探完剩下的全部发送 ⇒ 增益 ≤ `(b−c_probe)·Δp̂_UB·ΔV_succ`。
代价 = 一个量子 = `ΔV_q ≈ p̂·ΔV_succ`（`P4` 实测）。
两边除 `ΔV_succ`：**买得起 ⇔ `(b−c_probe)·Δp̂_UB > p̂`**。
⇒ 这就是 `STATE` §7.2 里 `(b−1)·Δp̂_gain > p̂_mean` 的来历，**且它把「槽」显式排除在外**
（槽不进这条判据；槽的影响表现在 `UB` 与实测的差距里，见 `J-E`）。

## 4 判词与**否定条件**（跑前写死，不许跑后改）

| 编号 | 判据 | 判词 |
|---|---|---|
| `J-A` | 所有 `b=1` 格 `\|ΔV_q/(p̂·ΔV_succ) − 1\| ≤ 0.10` | `QUANTUM-EQUALS-ONE-SEND`（否则 `QUANTUM-NOT-ONE-SEND`，那 `p̂` 归一化就不能用） |
| `J-B` | 所有格 `UB_free ≥ IV_free` 且 `UB_paid ≥ IV_paid`（容差 `−1e-15`） | `BOUND-VALID`；**任一格破 ⇒ `BOUND-VIOLATED`，本轮全部判词作废** |
| `J-C` | 在 `UB_paid < ΔV_q` 的每一格上实测 `IV_paid ≤ 1e-12` | `NO-PAID-PROBE-CERTIFIED`；**存在一格反例 ⇒ `CERTIFICATE-FAILED`** |
| `J-D` | 面板外推：`b* = 1 + p̂/Δp̂_UB(v,σ_csi)`，`b*≤4` 即"面板内买得起" | `PANEL-BELOW-THRESHOLD`（`b*>4`，面板全在最有利先验 `v=1` 上）／`THRESHOLD-INSIDE-PANEL` |
| `J-E` | `IV_free/UB_free` 的**上界紧度**：中位 slack 比 | `BOUND-TIGHT`（≤10×）／`BOUND-TOO-LOOSE`（>10×，此时 `J-C` 的证书只当必要条件说，不当充分论证） |

**否定条件汇总**（写在这里是为了防止跑完再找理由）：
- `J-B` 只要破一格，**不许**说"探测买不起"，只能说"我的界错了"。
- `J-C` 只要有一格 `IV_paid > 1e-12` 而 `UB_paid < ΔV_q`，**不许**说"面板内无探测价值"。
- `J-E` 若是 `TOO-LOOSE`，**不许**把 `J-C` 的"买不起"写成定理，只能写成"在最宽松的上界下仍买不起"。
- 面板只到 `τ≤4, b≤4`：**任何 `τ≥8` 的数字都是公式外推，不是实测**，必须逐处标注。

## 5 面板（写死）

- `τ ∈ {2,3,4}`、`b ∈ {1..τ}`、`P ∈ {0.005, 0.02, 0.05, 1.0}`、`(m0,v0)=(m1,v1)=(0,1)`、`σ_csi=0.05`、`n_m ∈ {33,65,129}`。
- 判据只用 `P ≤ 0.05`（稳态档，沿用 R3.2 `P_JUDGE_MAX`）；`P=1.0` 冷启动只作描述。
- `Δp̂` 的敏感性：`v ∈ {1, 0.25, 0.05, 0.01}` × `σ_csi ∈ {1e-3, 0.05, 0.2, 0.5}`（`1e-3` = 物理不可能的完美 CSI，只作上界）。
- `J-B/J-C` 只用 `n_m=65`（成本与 R3.2 判据单元一致）；`n_m=129` 只对**判据单元**复核 `IV_free` 与 R3.2 的 `4.600e-5` 是否同量级。

## 7 跑前修订（追加式，不删上文）

- `§7-A1` **「槽价」没有独立可识别量**：所有动作都吃一个槽，槽数由视界固定、成本每槽都记
  ⇒ `V(τ)−V(τ−1)` 混了"多一槽的持有成本"，**不是**槽的边际价值（`P1` 已实测：它在 `P=0.005` 上是 `1.36e-2`，
  比量子价 `8.33e-4` 大 16 倍，显然不是同一件事）。因此本轮**不定义 `price_t`**，
  改为用 **`UB` 与实测的差**（`J-E` 的 slack）与 `IV_free − IV_paid` 两处来看槽的作用。这是本轮的口径边界。
- `§7-A2` `IV_free − IV_paid` **不是**槽价（前者免量子、后者付量子，两者都占槽）⇒ 该差 = 量子价
  （若探测在被用），只能当"量子价的实测"，不能叫槽价。
