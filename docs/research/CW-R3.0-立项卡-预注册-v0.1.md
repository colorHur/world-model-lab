## §1 本轮唯一问题

> **Q**：在**同信息、同动作集、真值可算**的条件下，「**尾部近似 ⇒ 动作排序错 ⇒ 多花钱**」这条路
> 到底值多少？（R3 的全部机制都只在**这条路是瓶颈**时才有意义。）

拆成三个可判分支：

- **J1 排序误差是否存在且有多大**：把 `_expect_after` 的解析排序与**精确最优排序**对比，
  测单步遗憾。这是"排序误差"的**唯一可核口径**（有真值）。
- **J2 解析路线能否自己关掉这个缺口**：同一比对换更强的解析尾部（`DPTail`，grid=`r173`）
  再做一次。若解析继续逼近到遗憾≈0，则"学习"没有可赢的对手。
- **J3 真值能算到多大**：`ExactClosedLoop` 的状态数/耗时随 τ 的**实测**增长。这是"我们能不能
  在面板尺度（τ=256）上验证任何学习声明"的前置条件。

★★ **结构闸 `J0`（写卡时已确定，不可事后放宽）**：`ExactClosedLoop` 与 `DPTail` 的动作集
**都不含 `PROBE`**。因此 J1/J2 只能就「`HOLD` vs `SEND_i` 的排序」发言，
**不得**据此宣称"信道信息（探测）的定价也没问题"。任何把 J1 结论扩到 PROBE 的写法作废。

## §2 判据定义（跑数前写定）

状态 `s = (τ, P0, P1, b, p̂)`；`p̂` 在两用户上相同、**冻结**（与 `DPTail` 同一近似），
`p̂ ∈ {0.5, 0.2}`（0.5 = 先验，0.2 ≈ R1.12 的精确贝叶斯下界区间 0.10–0.16 的保守上沿）。

1. **精确量**：`Q*_exact(s,a) = q(P0+P1) + [a=HOLD: V*(τ−1, f(P0), f(P1), b);
   a=SEND i: p̂·V*(τ−1, d(P_i), f(P_j), b−1) + (1−p̂)·V*(τ−1, f(P_i), f(P_j), b−1)]`，
   `V*(s) = min_a Q*_exact(s,a)`。`f(p)=p+σ_w²`、`d(p)=(1−g)p+σ_w²`、`g=p/(p+σ_meas²)`。
2. **排序器**（两个，都**只吃公开信息与公开常量**）：
   - `paced`：`PlanRef(tail="paced", pacing=True, cont_m=True)._expect_after(st, a, τ−1)`
     —— **研究基线**，R1.6.1 起的默认尾部。
   - `dp@r173`：同一函数、`tail="dp"`、`self._dp = DPTail(..., grid="r173", tau_max=τ)`。
   - `PROBE` 不进比对（`J0`）；但**描述性**记录"含 PROBE 的 5 动作集里 PROBE 是否被选"。
3. **两个指标**（逐状态，然后按 τ 聚合）：
   - `agree(s)`：`argmin_{HOLD,SEND0,SEND1} Q_rank(s,·) == argmin Q*_exact(s,·)`（并列按
     `HOLD < SEND0 < SEND1` 固定序，与 `_pick` 的 tie-break 同向）。
   - `regret_rel(s) = (Q*_exact(s, a_rank) − V*(s)) / V*(s)`（`V*>0` 恒成立：`q=1`、`P>0`）。
4. **阈值（跑数前钉死，依据见 §2.1）**：
   - `RANKING-NOT-BOTTLENECK`：`median regret_rel ≤ 5e-3` **且** `agree ≥ 0.95`
   - `RANKING-IS-BOTTLENECK`：`median regret_rel ≥ 5e-2` **或** `agree ≤ 0.85`
   - 其余 ⇒ `INCONCLUSIVE-BY-MARGIN`
   - 关闭率 `1 − median(regret_dp)/median(regret_paced)`：仅在 `median(regret_paced) ≥ 5e-3` 时定义，
     `≥0.8` ⇒ `CLOSABLE`，`<0.5` ⇒ `PERSISTS`，中间 `PARTIAL`。

### §2.1 阈值为什么是这两个数（**先验量级**，不是结果驱动）

- `5e-2`：R1 面板上"值得追"的效应是 `−7.36%`（R1.16，n=10）到 `−18.4%`（R1.14，2 ep）。
  一个**声称是瓶颈**的量，其单步遗憾必须与待追效应同量级 ⇒ 取最保守的下沿 `5%` 的一半作为门槛。
- `5e-3`：`DPTail` 网格自身对 `V` 的绝对误差实测 **0.104%**（R1.7.3，n=90 结点、全工作集）。
  低于该量级 5× 的遗憾在该网格上**没有分辨力** ⇒ 判"不是瓶颈"时要求 `≤0.5%`。
- `agree 0.95 / 0.85`：分别是"每 20 个决策错 1 个"与"每 7 个错 1 个"。

## §3 三个判定（做法，零 episode、零训练）

### J1（主件）排序遗憾 vs 精确最优
- 网格：`τ ∈ {4,6,8,10}`（`ExactClosedLoop` 可达上界由 J3 实测决定，见下）；
  `P0,P1 ∈ {0.005,0.010,0.020,0.050}` 全 16 组合（**必须含 `P0≠P1`**：R1.7.1 证对角点上轴错配只露 0.44%）；
  `b ∈ {0, 2, 5}`（`5 = ⌊0.5·10⌋` 即面板代表预算比，另两档是敏感性）；
  `p̂ ∈ {0.5, 0.2}`。
- 每个 τ **只建一次** `ExactClosedLoop` 缓存，所有 (P0,P1,b) 根共用（`V` 与根无关）。
- 输出：逐状态 `agree / regret_rel / Q*_exact 三值 / 两排序器各自 argmin`。

### J2 解析路线能否自查缺口
- 同一状态集，换 `dp@r173` 排序器，报关闭率（§2.4）。
- **不可达性说明（先写死）**：若 `median(regret_paced) < 5e-3`，关闭率**不定义**（分母太小，
  比值的比值会放大噪声 —— R1.17 的 `share` 构造反例，208×）。

### J3 真值与近似求解器的规模
- 实测 `ExactClosedLoop` 在 `τ ∈ {4,6,8,10}`、`b=⌊τ/2⌋` 的 `n_states` 与耗时；
  给相邻档的增长倍率，并对 τ=256 给**结构外推**（分支因子 3、预算轴 `b+1`），**明确标注"外推、非实测"**。
- 实测 `DPTail(tau_max ∈ {10,32}, grid ∈ {legacy,r173})` 的 `mem_mib` 与构建耗时（多项式 vs 指数）。
- 判据：若 `ExactClosedLoop` 在 τ=10 已超 `2e5` 状态或 >120 s，则**声明 τ=256 无可信真值**。

### §7-1 `argmin` 漏筛可行性（跑前自伤，闸 `C6` 首跑 FAIL 抓到）

`_expect_after` 在 `b=0` 时取 `bud_after = max(0−1, 0) = 0`，于是 SEND 看起来"免费且刷新" ⇒
我的 `argmin3` 在 `b=0` 上选 `SEND0`，而生产的 `_pick` 用 `budget_left >= need` 先筛掉不可行动作。
**修**：`argmin3(vals, budget)` 先筛可行性。**当时已看见**：`C6` 的 3 例里 1 例不一致（`b=0`）。
**实质阈值未动**；`C6` 从 FAIL 转 PASS，`n=3` 不变。

### §7-2 变异门槛（`C7`）写法不当（跑前自伤）

原写"反向排序的遗憾 ≥ 10× 正常排序"。实测 `median_reversed / median_ok = 3.16×` ——
三动作里"取最差"本身就把遗憾限制在 `[Q_2nd − V*, Q_worst − V*]` 区间，
10× 是个拍出来的数，不可达。**改为**：`median(reversed) ≥ 5e-2`（= `IS-BOTTLENECK` 门槛）
⇒ "指标能到达该量级"才是分辨力的正确表述。**当时已看见** `median_ok=2.14%`、
`median_reversed=6.77%`（仅 4 个状态的小子集）。**§2.4 的实质阈值一字未改。**

### §7-3 面板 τ 从 `{4,6,8,10}` 扩到 `{4,6,8,10,12,14}`（**顺序如实记**）

**当时已看见**：① 首跑（τ≤10，352 行）的 `paced agree=0.673`、`median(regret)=0`；
② 之后才测 τ=12/14 的**成本**（310 508 状态 / 0.224 s；2 385 506 / 1.882 s）。
⇒ 扩 τ 是"看到 τ≤10 结果之后"决定的，**不是盲扩**。影响：只增加样本量，不改变 τ≤10 子集的数字
（终跑 τ≤10 部分 `n=352` 与首跑逐格可对）。

### §7-4 ★ 闭合率口径失效（**形式缺陷**，这是本节最重要的一条）

预注册写的闭合率 = `1 − median(regret_dp)/median(regret_paced)`，前提 `median(paced) ≥ 5e-3`。
实测 `median(paced) = 0.0` ⇒ 口径 **`UNDEFINED`**。

**这不是"效应小"，是变量形态**：只要排序器在 **>50% 的状态上与最优同解**，被测量就是
**zero-inflated** 的，中位数恒为 0、分母恒为 0。诊断已核：`paced` 的 197 个分歧状态**全部**有
`regret > 0`（没有一次是"并列被判错"）⇒ 0 值来自"完全同解"，不来自并列。
与 R2.4「只用中位」、R2.5「零分布合法≠有分辨率」同族。

**修（跑后定义，两个口径都报，取较小者为保守值）**：
- `by_mean = 1 − mean(regret_dp)/mean(regret_paced)`
- `by_agree = 1 − (1−agree_dp)/(1−agree_paced)`（"被关掉的误排序占比"）

⇒ 双判词落盘：`overall_prereg`（按 §4 原样，得 `INCONCLUSIVE-BY-MARGIN`）与
`overall`（按修订口径，对外只用这一条）。**与 R2.8「预注册映射与卡 §7-3 冲突 ⇒ 双标签」同一手法。**

### §7-5 J3 判词取了 `max τ` 而不是预注册写的 τ=10（**跑前自伤**）

§3-J3 原文判在 τ=10；`judge()` 首版取 `max(exact, key=tau)`（= τ=12），于是把
"τ=12 超 2e5" 误报成 `TRUTH-BLOWS-UP-BEFORE-TAU10`。**修**：判在 τ=10（`40 565` 状态 / `0.027 s`，
在限内），另报 `max_tau_computed`、其状态数与"到面板 τ=256 的比值"（结构外推，非实测）。

### §7-6 未做 / 未验证（如实列）

1. **PROBE 不在任何参考物的动作集里**（§1-J0）⇒ 本轮判词**不覆盖**"探测/信道信息的定价"。
2. 状态集是**网格**（`P∈{0.005,0.01,0.02,0.05}` × `b∈{0,2,⌊τ/2⌋}`），**不是可达分布** ⇒
   所有"占比"是**网格上的占比**，不能直接读成"闭环节省 X%"。
3. `p̂` 只取 `{0.5,0.2}` 两档且**冻结**（与 `DPTail` 同一近似）。
4. τ=256 无真值（`10^107`–`10^115` 状态量级）。
