## 0. 为什么不照抄 `X2` 的形态（跑前必须说明的偏离）

`STATE §7.2` 原话是"把 `F4` 写成预注册判据再跑独立面板"。`F4` 的来源是 R3.4 的**跑后**构造：

```
X2 形态：VoI_ub = π_slot − (V_PROBE − V_SEND)
```

写卡时核对代码（`r3_4_slotprice.py: cell()`）发现这个形态**混了臂**：

| 项 | 取自哪个臂 |
|---|---|
| `π_slot = first_no["HOLD"] − min first_no["SEND_*"]` | `noprobe` 臂 |
| `V_PROBE` | `free` 臂（`probe_cost=0`） |
| `V_SEND` | `noprobe` 臂 |

`free` 臂在任意状态上**动作集更大** ⇒ 逐点 `V_free ≤ V_noprobe`。所以
`π_slot − (V_free[PROBE] − V_noprobe[SEND])` 里的两个被减项**不在同一成本结构下**，
它**没有**"上界"的推导，只是两个数之差。R3.4 自己也把 `X2` 标了"探索性、未预注册"。

⇒ 本轮**不**把这个形态升格成判据。改为一个**有推导**、可在同一网格上验证的上界（§2）。
旧形态**并列照跑**（`X2_legacy`），用来回答一个具体问题：**它会不会超过真上界**（§4 `C4`）。
若会，则"上界"这个称呼本身被证伪，必须写进交付。

## 1. 问题

> 在这套 DP 里，**信道信息最多值几个量子**？这个"最多"能不能在一个

## 2. 量的定义（跑前写死）

在同一根状态 `s = (τ, P0=P1=P, m=0, v=1, b)` 上建四条臂：

| 符号 | 臂 | 语义 |
|---|---|---|
| `A0` | `probe_enabled=False` | 完全没有探测动作 |
| `A_free(σ)` | `probe_cost=0`, `σ_csi=σ` | 探测免量子，**仍占一个槽** |
| `A_paid(σ)` | `probe_cost=1`, `σ_csi=σ` | 探测付一个量子 |
| `A_free(σ⋆)` | `probe_cost=0`, `σ⋆ = 1e-9` | **网格内完美** CSI |

**信息毛价值**：`IV_free(σ) = A0 − A_free(σ)`，`IV_paid(σ) = A0 − A_paid(σ)`。

**量子价格**：`ΔV_q = A0(b) − A0(b−1)`（同 `τ, P`）。

★★ **上界（本轮主件）**

```
UB := IV_free(σ⋆)        σ⋆ = 1e-9
```

**为什么它是上界（推导，非实测）**：

1. 三条臂的**唯一**差别是"探测读数的噪声 `σ`"与"是否付一个量子"；
   `A0` 是动作集的子集 ⇒ `IV_* ≥ 0`。
2. 同一 `n_m` 下，`snap` 把读数映到**同一张网格**。读数 `y = m + σ·ε`，
   `σ⋆ → 0` 时后验均值 `g_p·y` 退化为 `m` 本身 ⇒ 对**任何** `σ`，`σ=σ⋆` 的读数
   在 Blackwell 意义下**最信息化**（`σ⋆` 臂可以自己加噪模拟任何 `σ` 臂）
   ⇒ `A_free(σ⋆) ≤ A_free(σ)` ⇒ `IV_free(σ⋆) ≥ IV_free(σ)`。
3. `probe_cost=0` 的动作集包含 `probe_cost=1` ⇒ `A_free ≤ A_paid` ⇒ `IV_free ≥ IV_paid`。

⇒ **`IV_paid(σ) ≤ UB` 对所有 `σ` 成立**（网格一致性由 2 保证；这也是 `C0` 要逐格验的）。

★ 两条**已知的保守性**（对上界方向有利，但必须一起报）：

- `snap` 量化让 `σ⋆` 臂的"完美"退化为"步长 `8/(n_m−1)` 的量化知识" ⇒ `UB` 是
  **真·完美信息**上界的**下估计**；因此 `UB < ΔV_q` 的结论比字面更强。
- `UB` 只覆盖"**当前槽**的信道知识值多少"。它**不**定价 ACK/NACK 通道
  （R3.1 `J-B` 已证 `(m,v)` 在 `exact` 下非充分），也不许外推到 256 槽。

## 4. 判据（先写，跑后只按表取）

★ 两个**同臂**补充量（不是判据，但必须一起报；见 §0 的混臂教训）：

`IV_paid(σ) ≤ 0` 对任何 `σ` 成立 ⇒ 「信道信息买不起」从"上界 < 1 个量子"升级成

在这套 DP 上绑定约束不是量子而是**槽**。两者必须一起报，不许只报前者。


## 5. 否定条件与"什么数据能让我 FAIL"

- `C1` 不过 ⇒ 上界不是"普遍买不起"，只能写"面板特定"。
- `C2` 开枪 ⇒ `R3` 的负结论**必须收窄**：不是"信道信息没用"，而是"**含噪** CSI 在这个
  精度/预算档下买不起"。这是本轮唯一可能翻转主线的出口，必须如实报。
- `C0` 不过 ⇒ 先怀疑我的实现（网格/积分/`snap`），**不许**把违规当场宣布成"上界不成立"。

  不许写成证书。这是"存在性判据必须带地板"的现场版。
