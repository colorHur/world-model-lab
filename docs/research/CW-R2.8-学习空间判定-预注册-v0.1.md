## §2 定义（先写死，再实现）

### 2.1 重建器 `R`（独立实现，只读公开历史 + 协议常量）

**递归式**（与 `world.py` 的更新链**同式但独立编码**；`t` = 槽开始时的槽号）：

```
槽开始: (x̂_t[i], P̂_t[i])  for i in 0..n-1
u_t     = −K·x̂_t
x̂'      = A·x̂_t + B·u_t
P̂'      = A²·P̂_t + σ_w²
if rec.data_delivered == 1:
    i  = rec.user
    g  = P̂_t[i] / (P̂_t[i] + σ_meas²)
    xc = x̂_t[i] + g·(rec.y_t − x̂_t[i])
    Pc = (1 − g)·P̂_t[i]
    x̂'[i] = A·xc + B·u_t[i]
    P̂'[i] = A²·Pc + σ_w²
比较对象: 下一槽视图的 telemetry[i].x_hat / P_hat
```

- **常量来源**：`mainline_config()` 的 `A / B / σ_w / σ_meas / prior_var`，以及 `K = nominal_gain(i)`。
  依据：协议 v1.1 的信息合同是"**已知生成参数**"（v4.1 §"然后回到研究"），这些量对**所有可部署方法**
  公开，不是特权信息。
- **硬约束（闸 `S6`）**：重建器只允许读 `PUBLIC_HISTORY_FIELDS` 里的键 + 上述常量；
  **不许**读 `telemetry.x_hat/P_hat`（否则是自指）、不许读任何 `TRUTH_FIELDS` / `_z_*`。
  实现上：重建器签名只收 `(records, constants)`，`records` 由世界侧显式按白名单投影后再传入。

### 2.2 A 支面板（3 档动作脚本 × 2 个 episode；**不用规划器**）

| 档 | 脚本 | 意图 |
|---|---|---|
| `dense` | 每槽 `SEND user=(t%2)` | 送达密集 ⇒ 校正频繁 |
| `sparse` | 仅 `t%8==0` 时 `SEND user=(t%2)` | 长空档 ⇒ 靠 `α` 递推 |
| `mixed` | `t%3==0`→`PROBE user=(t%2)`；`t%3==1`→`SEND user=((t//3)%2)`；否则 `HOLD` | 三种动作都出现 |

- episode `100 / 101`（`split="dev"`），`horizon=256`，`budget_total=256`，`rho = rho_panel[0]`。
- 每跑完一槽记录**该槽视图的 telemetry**（作为比对目标）与**槽末追加的公开记录**。
- ★ 直接驱动 `CWWorld.step`，**不经过 `run_episode`**（闸 `S9` 钉 `run_episode` 调用数 = 0）。

### 2.3 B 支定义：参数未知下的头部空间（合成标量 AR，无世界、无规划器）

- 真过程：`x_{t+1} = A·x_t + B·u_t + w_t`，`w ~ N(0, σ_w²)`，`x_0 ~ N(0, prior_var)`；
  `u_t = −K_nom·x̂_t`（控制律由**名义**参数设计，三臂相同 ⇒ 只比估计器）。
- 观测：每槽以概率 `p_deliver` 收到 `y_t = x_t + N(0, σ_meas²)`（外生、独立于 x；这是**抽象**，
  不是信道模型 —— 本支只问"参数不确定性值多少"，不问调度）。
- **`A` 未知**（唯一未知量；`B/σ_w/σ_meas/prior_var` 仍已知）：
  - 真值抽样：`A_true ~ U(0.90, 1.10)`（**连续**）
  - 滤波器先验：`A ∈ {0.90, 0.95, 1.00, 1.05, 1.10}` 等权（**离散** ⇒ 离散化误差照实计入，不掩盖）
- 三臂：

| 臂 | 定义 |
|---|---|
| `plug` | 卡尔曼，`A = 1.00`（先验均值 = 名义参数） |
| `mmkf` | 5 个 `A` 上的**精确混合卡尔曼**（离散 θ 时联合后验就是高斯混合，权重按预测似然更新） |
| `oracle` | 卡尔曼，`A = A_true`（诊断用，**不是**学习目标） |

- 量：`MSE = mean_t (x̂_t − x_t)²`，逐 episode 配对（同一 `(x 初值, w, y 噪声)` 三臂共用）。
- `h_B = 1 − MSE_mmkf / MSE_plug`（>0 表示"知道 θ 有分布"比"用名义 θ"更好 ⇒ 参数自适应有空间）。
- **敏感性网格（预注册，全表照报，不挑格）**：`p_deliver ∈ {0.5, 0.1, 0.02}` × `σ_w ∈ {0.02, 0.2}`，6 格。
- 规模：每格 `1000` 条 episode × `T = 64`。

## §7 边界与已知风险（诚实版）

1. **Q-A 的"精确"是数值的**：`1e-12` 是浮点容差，不是数学证明。但它比"看起来差不多"强：
   负控（`S2–S4`）会证明这个容差**有分辨力**。逻辑链是"实现层逐位可重建 ⇒ 信息层无缺口"，
   不是反过来。
2. **Q-B 的抽象很粗**：`p_deliver` 外生、`A` 是唯一未知量、θ 先验离散。若结论是"头部空间可忽略"，
   它只在**这个**抽象下成立，不许外推成"参数未知一定没有价值"。
3. **Q-B 若判 PRESENT**，也只说明"参数自适应估计器优于名义参数估计器"；
   **学习模型能否拿到这个收益**是下一轮的事（它还要与 MMKF 这个**可计算的**解析对手比）。
   本轮不预设它能赢。
4. **`oracle` 臂不给判词**：它知道 `A_true`，是诊断；把它当"上界"就是 R1.1 已撤回的那个错误。

## §9 跑前修订（**全部写于正式面板之前**；逐条写明"当时已看见什么"）

### A1（19:5x–20:2x）B 支的设计被三次 dry run 推翻，最终定为「开环 + 窄不确定性剂量表」

**卡 §2.3 原文**写 `u_t = −K_nom·x̂_t`、`A_true ~ U(0.90,1.10)`。实现时先改成 `u ≡ 0`（写码时，**未跑任何 B 支数字**），
理由是"各臂控制不同 ⇒ 真值轨迹不同 ⇒ 估计差与闭环差混在一个 MSE 里"。

随后三次 dry run（都在仓库外的 `outputs/`，都是**小样本**，都**不进证据**）：

| # | 设计 | 当时看见 | 处置 |
|---|---|---|---|
| 1 | `u≡0`，`A∈[0.90,1.10]`，200 ep | `MSE_plug` **154–467**（`prior_var=1` 量级下 x 已放大两个数量级）；`h_B` 0.94–0.98，`p=0.02` 格为负 | 判**退化**：`A>1` 且无控制 ⇒ 指数发散，测的是发散不是估计质量 |
| 2 | 闭环、三臂**共用**控制 `u=−K_nom·x̂_plug`，`A∈[0.90,1.10]`，300 ep | `p=0.02` 格 `MSE` 仍 **298**（估计→0 ⇒ `u≈0` ⇒ 不稳定 plant 照样发散）；同滤波器双流的 `floor_rel` 达 **15%**（重尾） | 判**仍未解决**：发散与重尾污染 `h_B` |
| 3 | `u≡0` + **剂量表**：`w_A∈{0.005,0.02}`（`A=1±w_A`）× `p∈{0.5,0.1,0.02}`，300 ep；每格报 `max|x|` | `max|x| ≤ 10.7`（无发散）；`h_B`：`w=0.005` 时 0.03%–0.81%，`w=0.02` 时 2.0%–50.6% | **采用** |

**为什么不取更宽的 `w_A`**：开环 `u≡0` 下 `|x_T| ~ A^T`，`T=64` 时 `A=1.02` 已放大 3.5×（实测 `max|x|=7.4`），
再宽就让 MSE 被"轨迹尺度"而不是"估计质量"主导 —— 这正是 dry run #1 的病。

**这条修订的方向对 B 有利还是不利**：`w_A` 从 10% 收到 2% 是**收紧**（更不利于"头部空间大"），
而取消闭环是把"控制差异"这一混淆项移除。两者都不为追 PASS 服务；`w=0.02` 那一档仍给出 50.6% 的头部空间。

### A2（20:2x）`S10` 的判据写错了：它是**诊断**门槛，不是"每格都必须有可分辨效应"

卡 §4 原写 `S10`：地板 `≤ h_B/5`（每格）。实现后发现它与 §3 的判词条件（`h_B > 5×floor`）**重复**，
而且会把"这一格效应本来就小"误判成程序缺陷（dry run #3 里 `w=0.005,p=0.1` 的 `floor_rel=2.0%` 远大于 `h_B=0.13%`，
那是**真实的不可分辨**，不是 bug）。
**改为**：`S10` = 全部 6 格 `floor_rel < 5%`（MC 噪声不得吞掉 5% 以上的尺度）；
"被判定为 PRESENT 的格必须 `h_B > 5×floor`" 仍留在 `judge()` 里，作为**判词条件**而不是闸。

### A3（20:2x）合并判词的标签与本卡 §7-3 冲突，**改用更窄的措辞**

原表把 `A=EXACT ∧ B=PRESENT` 映射成 `LEARNING-SPACE-AT-UNKNOWN-PARAMS`。
但本卡 §7-3 自己写明："`PRESENT` 也只说明'参数自适应估计器优于名义参数估计器'"，
而 `mmkf` 在**离散** `θ` 下是**精确**贝叶斯 ⇒ 学习模型相对它的期望上界是**打平**，不是超越。
⇒ 判词改为两条并列：`A-RECONSTRUCT-EXACT` 与 `B-HEADROOM-PRESENT`（并注 `ANALYTIC-COMPUTABLE`），
合并结论只保留 `R2-BELIEF-CLOSED-FORM`（A 成立即成立，与 B 取值无关）。代码里两个标签都落盘
（`overall_prereg` / `overall_corrected`），不覆盖。

### A4（20:3x）正式面板规模

`--b-ep 1000`（dry run 用 200/300）。种子**相同** ⇒ dry run 与正式面板同分布、不同样本量；
dry run 的 `h_B` 与正式值会有小差异，**以正式面板为准**，dry run 目录不进证据（在仓库外）。
