## §1 问题与要修的三条

R2.1 卡住的不是"两模型无差别"（有格 `|Δ|` 达本格地板 17–440×），而是**判据形态**。三条缺陷：

1. **阈值未随 n 缩放**：`N_POS_SEP=18 / N_POS_WEAK_LO=15` 是对 `n=20` 定的；分档（`n=10`）套用时
   `≥15` **算术不可能** ⇒ 判词结构性偏向 `CANNOT-SEPARATE-BY-SIGN`。
   R2.1 的结论**碰巧**与精确二项一致，但**推导是错的**（STATE §7.5-1）。
2. **主判用两个分布的中位之比**（`median|Δ| / median(floor)` = 2.06×），而**不是配对比较**
   ⇒ 逐对胜出只有 14/20，被中位比掩盖（STATE §7.5-2）。
3. **两档不能合并**：`P1` 与 `P2` 的 `floor_R2` 不同（0.0222 vs 0.0245），且地板是**乘性**的
   （`Spearman(floor, cost)=+0.782`，跨度 1900×）⇒ 绝对地板跨格不可比，必须分层。

## §2 判据 v2（写死；实现见 `mech2.py`）

单位 `u = (plant, ep)`，`n = |u|`（P1/P2 各 10，ALL 20）。所有量由 R2.1 的 `cells.json` / `null.json` 零成本重算。

```
Δ_u   = cost_true(prior_only) − cost_true(belief_readout)        # >0 ⇒ 弱基线更贵 ⇒ 强基线更好
floor_u = |cost_true(belief, seed 2001) − cost_true(belief, seed 3102)|   # 与 R2.1 同定义
sign_u  = 1[Δ_u > 0]
beat_u  = 1[|Δ_u| > floor_u]
```

- **H_sign**（配对符号检验）：`p_sign = P(X ≥ n_pos | n, 1/2)` 精确二项（单侧），`n_pos = Σ sign_u`。
- **H_beat**（配对幅度检验）：`p_beat = P(X ≥ n_beat | n, 1/2)` 精确二项（单侧），`n_beat = Σ beat_u`。
  零假设下 `Δ` 与 `floor` 同分布 ⇒ `P(|Δ|>floor) = 1/2`（这是**用零控自身当参照**，不借历史阈值）。
- **α = 0.05 单侧**（写死）。显著性**只由精确二项 p 决定**，不写任何计数阈值 ⇒ 天然随 `n` 缩放。

判词映射（**互斥、覆盖**）：

| 条件 | 判词 |
|---|---|
| `H_sign` ∧ `H_beat` | `PANEL-SEPARATES` |
| `H_neg` ∧ `H_beat` | `PANEL-SEPARATES-REVERSED`（**强基线更贵**，见 §2.1） |
| `H_sign` ∧ ¬`H_beat` | `SIGN-ONLY-NO-MAGNITUDE`（方向一致但压不过本格地板） |
| `H_neg` ∧ ¬`H_beat` | `SIGN-ONLY-REVERSED` |
| ¬`H_sign` ∧ ¬`H_neg` ∧ `H_beat` | `MAGNITUDE-ONLY-NO-SIGN`（旧 `SEPARATES-MAGNITUDE-ONLY` 的严格版） |
| 其余 | `CANNOT-SEPARATE` |
| 任一 `Δ_u` 非有限 | `UNDEFINED`（并列出格名） |
| 单位数 ≠ 预期 | `INCOMPLETE-PANEL`（**拒绝判词**，不静默降级） |

**中位比 `median|Δ| / median(floor)` 降级为纯描述**，不进判词。

### §2.1 写卡后、**跑数前**的修订（05:59，尚未算任何新判词）

原表只有 4 个判词。推 `C2`（反向构造）时发现缺口：`Δ` 全负且 `|Δ|` 全过地板时，
原表落在 `MAGNITUDE-ONLY-NO-SIGN`，读起来像"方向掷硬币"，**而事实是"方向显著相反"**
⇒ 会把"强基线更差"说轻（R1.18 教训 #73 同族：判词映射不能把"等价"和"更差"并成一格）。

因此新增 `H_neg = binom_p_ge(n_neg, n) < α` 与两个**显式反向**判词。这条修订：

- 是**加格**，不是挪阈值；`α`、`beat` 定义、分层规则都不变；
- **不能**被用来"救"任何正向结论（反向判词永远不是 `PANEL-SEPARATES`）；
- 修订时我只见过 §0 表里那些数，**没见过** `n_beat`/分层的任何值。

## §3 分层（预注册，先于看数）

- 阈值 `F* = median({floor_u : u ∈ ALL})`（**只用 `null.json` 算**，不看 `Δ`）。
- `LOW = {u : floor_u ≤ F*}`（判效应）、`HIGH = {u : floor_u > F*}`（**不出效应判词**）。
- `HIGH` 层只报计数与描述量，判词写 `NO-CLAIM-HIGH-FLOOR`；若 v2 规则在该层给出某判词，
  只能以 `descriptive_v2` 字段并列，**不得**进主结论。
- 必报 `Spearman(floor_u, cost_belief_u)`（乘性地板的证据）。

  全样本 `beat` 腿仍然合法（0.5013≈0.5）。**判据与数都不改**，只改"哪条腿有资格进判词"。
