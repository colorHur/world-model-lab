## §1 问题（一句话）

`R1.7.3` 已把 DP 尾部的价格偏差压到 τ=8 的 1.5% 与全工作集的 0.1%；
**在这么小的价格差下，`paced` 与 `dp` 两种尾部会不会让面板判据翻向？**

- 若**不翻**（三臂同过或同不过）⇒ 尾部价格偏差**不是**面板判据的解释项，`G8a`/`G4` 的 FAIL 可归因到别处（配速形状、近并列路径依赖），继续抠网格没有意义。
- 若**翻**（三臂方向不一致）⇒ 结论是"尾部形状改变行为"⇒ 必须先解决尾部，**不许**进面板、**不许**读 `N1/N2`。

## §2 判据（看数前写死；否定条件同样写死）

### T-A 复刻恒等闸（**前置，不过即整轮作废**）

`paced` 臂在本轮框架下复刻的 `G8a` / `G8a2` / `G4` 的 observed 值，
必须与 `plan_gates.run_all()` 中同名检查的 observed 值**逐位相同**（相对差 ≤ 1e-12）。

- 理由：三臂框架是我新写的包装，如果 `paced` 臂算不出链上的原值，那三臂比较的就不是同一个判据。
- FAIL ⇒ 判词 `HARNESS-MISMATCH`，**不出任何三臂结论**，只报差异定位。

### T-B 三臂方向一致（主判据）

三臂 `tail ∈ {paced, dp@legacy, dp@r173}`，逐项判：

| 判据 | 阈值（**不改**） | 来源 |
|---|---|---|
| `G8a` | `send_profile` 8 窗 CV **< 0.30** | `plan_gates.g8_pacing` 原样 |
| `G8a2` | `mean_task_aoi` **≤ 20** | 同上 |
| `G4` | 动作一致率 **≥ 0.90** 且成本相对差中位 **≤ 0.10** | `plan_gates.g4_m_stability` 原样 |

PASS 条件：三项中**每一项**在三臂上"同过或同不过"。
FAIL 条件（任一即 FAIL）：出现至少一项"某臂过、另一臂不过"。

### T-C 阳性对照（活体，**证明判据有分辨力**）

`nopace` 臂 = `pacing=False`、其余与 `paced` 全同（即 `G8b` 的口径）。
判据：它在 `G8a` 上**必须 FAIL**（CV > 0.30）。

- 若它 PASS ⇒ 说明本轮的 `G8a` 测法对"已知会毁掉配速"的改动都不敏感 ⇒ 判据无分辨力 ⇒
  判词 `NO-POWER`，**整轮作废（VOID）**，不得用"三臂一致"下任何结论。
- 依据：台账 #39「检查跑过了 ≠ 有分辨力 —— 先问什么错误能让它 FAIL」。

### T-D 关掉 ACK 更新？**不做**

本轮不改任何信息通道（`send_other_advance` 保持 `"fixed"`、ACK 更新保持开启）。
理由：那是 R1.7.2 已修的 bug，不是本轮的变量；改它会让三臂差异的来源不可归因。

### T-C2 dp 支路自己的阳性对照（**看数前追加**，因读实现发现 `G8b` 覆盖不到 dp 臂）

读实现发现（台账 #31：读实现不读名字）：`plan_ref._terminal()` 在 `tail == "dp"` 时
直接 `task_P = self._dp_value(...)` 并返回，**整个分支不出现 `self.pacing`**。

⇒ `G8b` 的阴性对照（`pacing=False`）**只覆盖 `paced` 支路**，对 dp 臂恒等无效。
⇒ 必须给 dp 支路单独造一个"已知会毁掉配速"的活体对照：

`dp@r173` + `dp_b_cap=8`（预算轴截到 8，而 `horizon=256`）。
依据：饱和律是 `b ≥ τ ⇒ V_τ(·,b)=V_τ(·,τ)`，`b_cap < horizon` 会让 `b∈(8,256)` 被
**静默压平**（`R1.7.2` 条目已记过这个机制，`W8` 的对照就是 `b_cap=64`）。
判据：该臂 `G8a` 的 CV **必须 > 0.30**。

- 若它仍 PASS（CV ≤ 0.30）⇒ dp 支路的判据无分辨力 ⇒ 判词 `NO-POWER`，整轮作废。
- 这条与 T-C 并列，**两条都过**才算"判据有分辨力"。

## §4 ★ 与 STATE §7.2 的一处**偏离声明**（必须先说）

`STATE.md` §7.2 写的三臂参数是「`h_plan=1`、`m_samples=16`」。**这个参数无法用于本轮判据**：

- `h_plan=1` 时 `PROBE` 与 `HOLD` 在值函数上同值（`G3b` 已钉为结构事实：`H=1` 整集 `n_probe == 0`）；
- ⇒ 三臂都会退化成同一个非探测策略，`G8a` 的 CV 与 `G4` 的一致率测的就不再是尾部形状的影响。

**处置**：三臂改用**判据自身的参数**（§3 表），不采用 `h_plan=1`。
这条偏离写在这里，不写进 STATE 的"本轮结论"，因为它是我对 STATE 的更正，而不是实验发现。

★ 顺带记一条纪律：`h_plan` 与 `m_samples` 是**判据的一部分**，不是可以随手统一的"其余全同"项。
