## 2 改了什么（实现层，逐条可复算）

1. **`G` 的分母**：`G = σ_w²·(A^{2(m-1)}−1)/(A²−1)`。旧版写 `/(1−A²)` ⇒ `A>1` 时 `G<0`
   （噪声和恒正）⇒ 循环水位低估 40–67%。
2. **暖入段**：正确为 `P·Y + σ_w²·(Y−w)/(A²−1)`，`Y = Σ_{k=1..w} A^{2k}`；
   旧版把 `Y` 写成 `X = −Y` ⇒ `A>1` 时暖入代价为**负**。
3. **循环均值**：`P̄ = (1/m)Σ_{k=0}^{m−1}P_k`（逐相位），`A=1` 时等于 `(P_post+P_b)/2`，
   `A>1` 时**不等于**（几何增长是凸的）。
4. **`m` 连续化**：`m = clip(steps·n/b, n, steps)` 取实数，不再 `round`；
   新增开关 `cont_m`（`False` = 旧口径，**只**供 `G8d2` 阴性对照，不进结果表）。
   暖入步数 `w` 也去掉了 `ceil`（几何和公式对实数 `w` 成立）。
5. 新增 `_geo_sum(a2, w) = (A^{2w}−1)/(A²−1)`（实数 `w`，`expm1` 保精度，`A²≈1` 取极限 `w`）。

**没有改的**：`q/r/σ_w/σ_meas/B/κ`、`c_probe=c_data=1`、`event_pairing="slot"`、
`horizon`、`episode 100–107`、`H_PLAN=5`、`M_SAMPLES=32`、`G4` 的 0.90/10%、
`G8a/G8b/G8a2` 的阈值、`ρ` 面板、`T5` 的 ≤1.00。**一个都没动。**

## 3 新闸与判据（看数前写定）

| 闸 | 判据 | 否定条件（什么错误能让它 FAIL） |
|---|---|---|
| `G8c2` | `A=(1.01,1.03)`、`m∈{2,4}`：闭式 vs 长程模拟相对差 **≤1%** | `G` 的分母符号、暖入几何和、循环均值三处任一写错 ⇒ 差 40–67% |
| `G8d` | （不变）`steps=128`、`b∈[0,128]`：平坦比例 **≤10%**、上升 **0 对** | `m` 取整（旧口径 78.1%） |
| `G8d2` | 同上但 `cont_m=False` ⇒ 平坦比例 **>30%** | 若取整后仍平不下去，说明 `G8d` 的 ≤10% 无分辨力 |
| `G8c` | （不变）`A=1` 稳态循环均值 ≤1% | 闭式算错 |
| `M1` | 变异"探测不学任何东西但照扣钱"⇒ `n_probe == 0` | 预算无价格 ⇒ 探测免费 ⇒ `n_probe>0`（v1.6 实测 18） |
| `G4` | （不变）`M` 16→32 动作一致率 ≥0.90 且成本相对差 ≤10% | 值函数在预算维度不平 ⇒ 平区里动作由 1e-16 噪声决定 |

**验收顺序（不可跳）**：`G8d` ≤10% → `G8d2` >30% → `G8c2` ≤1% → `M1` 被抓 → `G4` 复跑 PASS
→ **才允许**读 `N1`/`N2` 与 `plan_probe` vs `plan_noprobe` 的配对差。
