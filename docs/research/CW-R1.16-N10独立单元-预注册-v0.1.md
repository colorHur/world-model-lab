## §1 问题（一句话）

R1.15 在 **2 个 episode** 上得到"送达率缺口机制按 episode 分岔"（`ep100` 帧选择 / `ep101` 用户分配）。
本卡要回答两个可证伪的问题：

- **Q1（量级与稳定性）**：`exact` 相对 `approx` 的送达率差 `Δr`，在 **10 个独立 episode** 上是否稳定为负？区间多宽？
- **Q2（可预测性）**：机制分岔（`sh_user` 高 / 低）能否由一个**在跑 `exact` 臂之前就能算出来**的量预测？

Q2 的候选预测因子（**唯一预注册的那个**）：
`Δp_bad_ep = p̄_u0(approx) − p̄_u1(approx)`，取 `|Δp_bad|`。
含义：**在对照臂的行为下**，两个用户的平均真信道质量差多远。差得越远，"把尝试搬到差用户"的代价越大 ⇒ 机制越可能走用户分配而不是帧选择。

**池化口径（写于看 `ep102–109` 之前，且与 §0-① 已披露的两个点同口径）**：
`p̄_ui(approx) = mean_{4 seeds} attempt_p_true_mean_by_user[i]`（**先逐 seed 取该用户均值，再对 4 个 seed 取算术平均**，
与 R1.15 `distribution.p_mean_by_user` 完全同一算法），然后 `Δp_bad = p̄_u0 − p̄_u1`。
★ 不用按尝试数加权：加权会引入"哪个 seed 发得多"的权重，而 4 个 seed 在本协议里不是独立单元。

## §4 指标（看数之前定义）

### §4.1 主量 M1 —— 逐 episode 送达率差

对 `ep ∈ {100..109}`、`seed ∈ {2001..2004}`：
`rate = Σ n_delivered_in_bin_by_user / Σ n_attempt_in_bin_by_user`（**机械量，不经 `x̂`**）；
`Δr_{ep,s} = rate_exact − rate_approx`（**逐 seed 配对**，同 `(ep,seed)` 共用同一串外生子流）；
`Δr_ep = mean_{s} Δr_{ep,s}`（4 个 seed 的均值；**不把 seed 当独立单元**）。

### §4.2 分母与区间 M3（按 R1.7.8 钉死的形式）

**配对差 bootstrap 95% CI**：对 10 个 `Δr_ep` 有放回重采样 `10⁴` 次（`numpy` 固定种子 `20261024`），
取 2.5% / 97.5% 分位。**不**用臂内地板、**不**用 MAD、**不**用 `Δr_{ep,s}` 的 40 个值（那会把 seed 当样本）。
附报（描述，不作判据）：`n` 个 `Δr_ep` 的中位数、逐 ep 的 4-seed 极差。

### §4.3 判词 M4（送达率）

| 条件 | 判词 |
|---|---|
| CI 上界 < 0 | `DELIVERY-GAP-CONFIRMED-AT-N10`（`exact` 显著更低） |
| CI 下界 > 0 | `DELIVERY-GAP-REVERSED-AT-N10`（`exact` 显著更高） |
| 跨 0 | **`UNRESOLVED-AT-N10`** ⇒ **停在这条，不许换分母/加判据凑**（STATE §7.2-4） |

### §4.4 机制 M5（复用 R1.15 的 `decompose` + `classify`，阈值一字不改）

每 ep 用 4 个 seed **合并计数矩阵**（R1.15 同法）判机制：`H-A-FRAME-SELECTION` / `H-B-USER-ALLOCATION` /
`DELIVERY-GAP-UNEXPLAINED` / `GAP-TOO-SMALL`（`|Δr_ep| < 0.010`）。10 箱为主、5 箱嵌套复核。

判词（**先写死**）：

| 条件 | 判词 |
|---|---|
| 两个机制各 ≥3 个 ep（`H-A`、`H-B` 都 ≥3） | **`MIXED-MECHANISM-AT-N10`**（分岔不是 2 个 ep 的偶然） |
| 单一机制 ≥8/10 | `MECHANISM-DOMINANT:<名>` |
| `GAP-TOO-SMALL` + `UNEXPLAINED` ≥4 | `MECHANISM-UNRESOLVED-AT-N10` |
| 其余 | `MIXED-WEAK`（如实记计数，不给机制名） |

### §4.5 预测因子 M6（`Sp(user)`）

样本 = `|Δr_ep| ≥ 0.010` 的 ep（**看数前不知道有几个**；若 <6 个 ⇒ 直接 `NOT-ENOUGH-POINTS`，
**不许为了凑点放宽 `DR_MIN`**）。统计量：

`ρ = Spearman(|Δp_bad_ep| , sh_user_ep)`，`sh_user_ep` 取 10 箱主口径的 `shares["user"]`。

| 条件 | 判词 |
|---|---|
| `ρ ≥ 0.60` | `PREDICTOR-SUPPORTED`（**方向**；显著性另报，见下） |
| `\|ρ\| < 0.40` | `PREDICTOR-REJECTED` |
| 其余 | `PREDICTOR-INCONCLUSIVE` |

★ **显著性单列一条，不许混**：附 `10⁵` 次随机置换的 `p`（固定种子 `20261024`）。
`ρ≥0.60` 且 `p≥0.05` ⇒ 只能写 **"方向一致，n=10 不足以显著"**（`n=10` 时 `ρ=0.60 ⇒ p≈0.07`，
与「`≥7/8` 不是显著性阈值」同一条纪律）。`ρ≥0.60` 且 `p<0.05` 才允许写"显著"。

### §4.6 必报（R17：不许用平均藏住受损用户）

逐 ep、逐用户：`aoi_tavg_by_user`（`r_i = exact/approx`，有一个 >1 就写"交易"）、`n_never_served`、
`n_attempted_by_user` / `n_delivered_by_user`、`n_probe`、`cost_est_per_step` 与 `cost_true_per_step`
的**相对与绝对**配对差（**只报不比** —— 地板 `0.0333` 已证高于效应）。

## §7 纯净性与反例（本轮新增的只有判据，判据必须先自证）

- 被测物零改动（§0 已声明）；新增文件只有 `experiments/cw_v1/r1_16_n10.py` 与本文档。
- **新判据的自证对照**（零 episode，**看面板之前**跑）：
  - `S1` bootstrap：`Δr_ep ≡ +0.10`（零方差）⇒ CI 不含 0 且宽度 0；`±0.10` 交替 ⇒ CI 含 0；
    `Δr_ep ≡ 0` ⇒ CI 恰为 `[0,0]` 且判 `UNRESOLVED`（不是 `CONFIRMED`）。
  - `S2` Spearman：完全单调 ⇒ `ρ=+1`；完全反单调 ⇒ `ρ=−1`；含并列 ⇒ 与手算秩相关一致（容差 `1e-12`）；
    与"打乱"对照 ⇒ `|ρ|` 必须掉到 `<0.4`。
  - `S3` 置换 `p`：`ρ=+1` 且 `n=10` ⇒ `p ≤ 1/10!·k` 的量级（报实测值）；`ρ≈0` ⇒ `p>0.4`。
  - `S4` 机制计数：喂 5 个"已知 `H-A`" + 5 个"已知 `H-B`"的合成分解 ⇒ 必须判 `MIXED-MECHANISM-AT-N10`；
    喂 10 个 `H-A` ⇒ `MECHANISM-DOMINANT:H-A-FRAME-SELECTION`。
  - `S5` **活体负控**：把 `sh_user` 与 `|Δp_bad|` 的配对**故意错开一位**（循环移位），
    同一 `ρ` 计算必须掉到 `<0.4`（证明"高 ρ 不是算术必然"）。
- **重复性**：`ep105/seed2001/approx` 连跑两次，`n_attempted/delivered/cost_true/policy_trace_hash` 必须逐位相同。

> 全部 3 条都发生在 **`ep102–109` 一格未跑、面板未看** 的阶段（只见过 §0 已披露的 `ep100/101`）。

- **§8-2（2026-10-24 18:53，`S5` 负控形态）**：首版写"`sh_user` 与 `|Δp_bad|` 的配对**循环移位一位**后 `|ρ|<0.4`"。
