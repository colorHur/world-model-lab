## §1 为什么必须是「整数刻度」，而不是「把 1 改成 0.25」

现实现 `r3_2_iv2u.py` / `r4_0_boundary.py` 里预算是**整数量子**，探测价入口是

```
pc = int(probe_cost)        # r4_0_boundary.py:125；r3_2_iv2u.py 同型
b >= pc …  V(..., b - pc)   # 预算按整数累减
```

把 `probe_cost` 从 `1` 改成 `0.25`，`int()` 会把它截成 **0** ⇒ 探测**免费**，
但**发送仍收 1**。结果不是"探测变便宜"，而是"探测不要钱"，与 `p=0` 极限混成同一个对象。
这是**记账单位错**，不是数值近似。

⇒ 本卡把单位换成**刻度（tick）**：

| 量 | 刻度值 | 说明 |
|---|---|---|
| 1 量子 | `8` 刻度 | 取 8 是因为最小价 `1/8` 需要 1 个整刻度 |
| 一次 `SEND_i` | `8` 刻度 | 发送不可分（整包） |
| 一次 `PROBE_i` | `8p` 刻度 | `p∈{1,1/2,1/4,1/8,0}` ⇒ `{8,4,2,1,0}` 全整数 |
| 预算 `b` 量子 | `8b` 刻度 | 非整数预算（如 `1.25` 量子 = `10` 刻度）**只作明示新条件** |

核验点（写进闸）：`8p` 必须**先是整数**再进 DP；`p=1/8` 必须是 `1` 刻度不是 `0`；
`p=1` 时 `8p == SEND` ⇒ 必须**逐位**复现旧整数引擎。

## §4 可证伪预测（**方向先从数学推一遍再写** —— R5.0 教训：我上轮把方向写反）

> 记号：`IV_paid(p) = A0 − V_paid(p)`，`A0 = V_noprobe`（同预算）。

**P-1（价格单调）** 固定 `(alpha,P,τ,b_tick)`，令 `p↓`。可用动作集
`{HOLD} ∪ {SEND_i : b≥8} ∪ {PROBE_i : b≥8p}` 随 `p↓` **单调扩大**（阈值 `8p` 下降）
⇒ `V` **不增** ⇒ `IV_paid` **不减**。即

```
IV_paid(1) ≤ IV_paid(1/2) ≤ IV_paid(1/4) ≤ IV_paid(1/8) ≤ IV_paid(0)
```

**推翻条件**：任一相邻差不小于 `-1e-12`（即出现 `IV(p_hi) − IV(p_lo) > 1e-12`）⇒ 判**实现错**，不是现象。

**P-2（`p=1` 回归）** 刻度引擎 `(send=8, probe=8, b=8q)` 必须与旧引擎
`build_engine_n(probe_cost=1)` 在 `b=q` 上 **逐位相同**（`max_rel == 0.0`，容差 `0`）。
**推翻条件**：任一格非逐位 ⇒ 刻度记账引入漂移，全卡读数作废。

**P-3（`p=0` 极限）** `probe=0` 必须与旧 `probe_cost=0`（`free` 臂）**逐位相同**；同时与刻度引擎
`(send=1, probe=0, b=q)` 逐位相同（同构缩放）。

**P-4（`b=1` 量子且 `p>0` ⇒ 结构性零）** `8q=8`、`8p≥1` ⇒ 探测后余 `8−8p ≤ 7 < 8`，**再也发不出去**
⇒ `IV_paid ≡ 0`（容差 `1e-15` 绝对，R4.0 `B0` 同口径）。这条**只**解释 `b=1`，**不**外推到 `b≥2`
（R5.0 §7.3）。**推翻条件**：任一 `b=8` 格 `|IV_paid| > 1e-15`。

**P-5（整包发送粒度：**降探测价仍丢一整次发送**）** 设 `0<p≤1`、预算 `8q` 刻度。
探测后可用整次发送数 = `floor((8q − 8p)/8) = q − 1`（因 `1 ≤ 8p ≤ 8`）
⇒ **探测恒吃掉整整一次发送，与价格在 `(0,1]` 内的取值无关**。
`p=1/8` 只省下 7 个刻度（约 0.875 次发送），不足以换回一次发送。
**唯一能翻面的条件是预算**：`b=1.25` 量子（`10` 刻度）+ `p=1/4`（`2` 刻度）⇒ `10−2=8` 恰好一次发送。
**推翻条件**：在 `b_tick=8`、`p∈{1/2,1/4,1/8}` 上出现 `IV_paid>1e-12`；或在 `b_tick=10`、`p=1/4` 上
解析式 `floor` 论证与实测策略不符（用 `IV_paid(b=10) > IV_paid(b=8)` 同报）。

**P-6（无信息观测不得有虚假收益）** `σ_csi=1e6`（`si2=1e12`）⇒ `0 ≤ IV_paid(p) ≤ 1e-9`（所有 `p`）。
**推翻条件**：任一格 `IV_paid > 1e-9` ⇒ 收益不是从读数来的。

**P-7（截断变异必须被抓住）** 变异体 `probe_ticks = int(p)`（`p<1` ⇒ 全免费）。
判据必须**至少 1 格**出现 `|V_mut − V_correct| > 1e-12`。
**若 0 格**：如实报"本闸无分辨力"，不许写成"截断无害"。

**两种结果都不支持"`0.226` 是 WTP"**：
- 若小实例上 `p>0` 全零 ⇒ 说明**包络不是约束**（价格只是折算，不是可支付上限）；
- 若出现正例 ⇒ 说明**价格改变了策略空间**（在小实例上），需要更大面板才能谈边界。
**不许**把任一种写成"预期中的正例"。

## §6 规模预算（**先算整腿，不按单格**；R4.2 教训）

1. 每个 `(alpha, p, b_tick 组)` 是**一条腿**，同一条腿共用一个引擎实例，`memo` **跨格累加**。
2. 方法（**写卡后、读数前的修订**）：**不写第二个可达性模型** —— 那会多一个可能与递推漂移的实现
   （R4.2 的 "`g_blackwell` 格点没先算规模"、R5.0 的 "接口假设错" 都是同族）；
   **也不编解析上界** —— 没推导的上界比没有更坏（R5.0 硬口径 5）。
   改为：**先把该腿全部格按顺序求值，再读 `len(memo)`**，因为 `memo` 本身就是"整腿并集"的定义；
   配三条机器可查的不变式（`T-8`）：① 求值前计数为 `0`；② 整腿计数 **>** 首格计数；
   ③ 重复查询同一格不改变计数（`memo` 复用生效）。三条缺一 ⇒ 规模读数不可信。
3. `STATE_CAP=6e6` 是硬墙。撞顶落盘 `capped=True`，判据里**单列**，不许当读数、不许 `break` 静默丢格。
4. 本卡面板（`n_m=17, τ≤4`）预期远低于硬墙；另做一条**外推腿**（`n_m∈{33,65}`、`τ∈{4,6}`、
   `p∈{1,1/4}`）只为回答"全网格在 CPU 上能不能跑"，**不产出价格结论**。
