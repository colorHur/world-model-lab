## §5 闭式候选（**先推导，再验证**；这是"先算再判"）

记 `n_users = 2`，`m_i = Σ_b(ni_e[i,b] − ni_a[i,b])`，`d_i = ρ_i − ρ_a`，
`G = m_0 + m_1`（总尝试数变化），`D = m_0 − m_1`（差分搬运量）。

**推导（纸上完成，未看任何数值）**：

1. `|m_0| + |m_1| = max(|G|, |D|)`（因 `m_0=(G+D)/2`、`m_1=(G−D)/2`，两数之和为 `G`、差为 `D`）。
2. `m_0 d_0 + m_1 d_1 = (G/2)(d_0+d_1) + (D/2)(d_0−d_1) = (G/2)(ρ_0+ρ_1−2ρ_a) + (D/2)(ρ_0−ρ_1)`。
3. ⇒ **`ku = [G(ρ_0+ρ_1−2ρ_a) + D(ρ_0−ρ_1)] / max(|G|, |D|)`**。
   定义 `ku_net = G(ρ_0+ρ_1−2ρ_a)/max(|G|,|D|)`、`ku_swap = D(ρ_0−ρ_1)/max(|G|,|D|)` ⇒ `ku = ku_net + ku_swap`。
4. **特例**：纯平衡交换（`G=0`，`m=(+q,−q)`）⇒ `max(|G|,|D|)=2q` ⇒ `ku = (ρ_0−ρ_1)·sign(q)` ⇒
   **`|ku| = |ρ_0−ρ_1|`**，即 R1.17 修好的上界 `2·max_i|d_i|` 在等权重时**恰好被取到**。
5. **有效上界（2 用户版）**：`ρ_a` 落在 `ρ_0,ρ_1` 之间 ⇒ `max_i|d_i| ≤ |ρ_0−ρ_1|`
   ⇒ `|ku| ≤ 2|ρ_0−ρ_1|`。**不许**写 `|ku| ≤ |ρ_0−ρ_1|` —— 那只在等权重（`ρ_a` 为中点）时成立，
   否则 `|ku|` 可以取到 `2|ρ_0−ρ_1|` 这一侧。
6. `kf = Σ_ib (2 m_ib/Σ|m_ib|)(ρ_ib−ρ_i)` ⇒ `|kf| ≤ max_ib|ρ_ib−ρ_i|`（加权平均，权重绝对值和为 2）。

### §5.2 写卡后、跑数前的**自我更正**（2026-10-24 23:24 `Get-Date`；`run_episode` 仍 = 0，面板仍 = 0 格）

上面 §5 第 6 条写的 `|kf| ≤ max_ib|ρ_ib−ρ_i|` **是错的**，漏了权重的 2 倍：

```
kf = Σ_ib w_ib (ρ_ib − ρ_i)，  w_ib = 2 m_ib / Σ_ib |m_ib|  ⇒  Σ_ib |w_ib| = 2
⇒ |kf| ≤ 2 · max_ib |ρ_ib − ρ_i|        （不是 max）
```

这与 R1.17 自伤 #4（`ku` 上界漏 TVD 的 `1/2`）**同族**：把"权重和为 2"写成"权重和为 1"。
`F4` 的断言相应改成 `|kf| ≤ 2·max_ib|ρ_ib−ρ_i|`；**原句保留在本文件里不删**，便于审计。

同时更正 §5 第 5 条的一处措辞：`|ku|` 的 2 用户有效上界是 **`2|ρ_0−ρ_1|`**，
`|ρ_0−ρ_1|` 只在 `ρ_a` 恰为中点时成立 —— 所以"取到 2 倍这一侧"不是可达性断言，只是上界方向。

## §6 冲突判据与停机规则（写死）

逐 ep，令 `old` = R1.16 的 `classify(...)["mechanism"]`，`new` = §3 的 `(u_state,f_state)`：

```
conflict_A: old == "H-A-FRAME-SELECTION" and f_state != NEG
conflict_B: old == "H-B-USER-ALLOCATION" and u_state != NEG
conflict_C: old == "BOTH-MECHANISMS"     and (u_state != NEG or f_state != NEG)
conflict   = conflict_A or conflict_B or conflict_C
```

**不是冲突的（单独计数，叫 `re-description`）**：`old == H-A` 而 `u_state == NEG`
（旧说"帧份额主导"，新说"用户通道也有害"）—— 这是**问法不同**，因为旧标签的"主导"从来不排除另一个通道。

份额爆过的那些 ep），则**必须停下**，写清两种答案各在什么口径下成立，**不许硬选一个当结论**。
