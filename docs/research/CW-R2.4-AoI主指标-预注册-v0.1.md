## §2 为什么不能直接把 `aoi_tavg` 立为主指标（写卡阶段的规则修正）

`aoi_tavg`（`runner.py:277`）的实现是
```python
served = [a for a in col if a >= 0]        # a = t − stamp，stamp<0 ⇔ 该用户尚未送达过
aoi_tavg = mean(served) if served else None
```
它有两个机械后果：

1. **删分母（D2，R1.8 已判死）**：任一用户全程未送达 ⇒ 该单位返 `None`。R2.3 的 `P1/ep101`
   正是如此，于是 `n=30` 实际只判了 29 个单位。
2. **★ 删窗口（D3，本轮新识别，未记录过）**：`a >= 0` 过滤掉的是**首次送达之前**的全部时隙。
   首次送达越晚 ⇒ 平均窗口越短 ⇒ 这段时间的陈旧度**不进分子也不进分母**。
   ⇒ 「先拖后服务」会**系统性**压低这个量。这是 D2 在时隙维度上的同构缺陷。
   本轮 `aoi_max` 已见 **229**（`P2/ep109` 弱臂），说明"长期不服务"确实在发生，D3 不是假想。

⇒ `aoi_tavg` 只能当**描述量**（它已在 R2.3 作描述出现过），**不许**升为主判。

## §3 主指标（写死，跑前定）

### §3.1 记号

单位 `u = (plant, ep)`，`n = 2 × 15 = 30`；用户 `i ∈ {0,1}`；时隙 `t = 0..T−1`（`T = n_slots`，逐格取实际值）。

### §3.2 两个非删除型变体（`A_t` 主、`A_T` 必同报）

对用户 `i`：`k_i` = 从未送达的时隙数（`n_unserved_slots_by_user[i]`），`τ_i = T − k_i` = 已服务时隙数，
`m_i = aoi_tavg_by_user[i]`（`k_i = T` 时 `m_i = None`）。

- **主变体 `A_t`**（时间填补）：`A_i = [ Σ_{t=0}^{k_i−1} t + m_i·τ_i ] / T`（`k_i = T` 时第二项为 0）
- **同报变体 `A_T`**（整期惩罚）：`A_i = [ k_i·T + m_i·τ_i ] / T`
- 单位量 `A_u = mean_i A_i`（两用户等权，与 R1.8 的 `mean_task_aoi` 同权口径）

**为什么 `A_t` 是主**：填补值 `t` 是"该用户在槽 `t` 的年龄下界"（真实年龄在未送达时为 ∞，
`t` 是最温和的有限替代）；`A_T` 是上界型惩罚。两个都单调于 `k_i`，差别只在斜率。
`A_t` 与 `A_T` 的判词**必须一致**，否则判 `AOI-VARIANT-CONFLICT` 且**不出主判**（§7-6）。
两个变体的公式在 `C10` 里用 `aoi_history` 直接复算验证（不靠"读代码觉得对"）。

★ `A_u` **永远有定义**（无 `None` 分支）⇒ 30 个单位全用，`n=30` 名副其实。

### §3.3 配对差与地板

- `Δ_u = A_u(prior_only) − A_u(belief_readout)`（`>0` ⇒ 弱基线更陈旧 ⇒ 强基线更好）
- `floor_u = |A_u(belief_readout, seed=2001) − A_u(belief_readout, seed=3102)|`（**同模型、同 episode、
  只换规划器采样种子**，与 R2.1/R2.3 的 `null_pair` 同定义）
- `beat_u = 1[|Δ_u| > floor_u]`

### §3.4 判据（`mech2` 的常量**一个都不改**）

三腿，全部用**精确二项**按 `n=30` 算（不写计数阈值，R2.2 硬口径①）：

| 腿 | 统计量 | 零分布 | `k_need` |
|---|---|---|---|
| `sign` | `n_pos = #{Δ_u > 0}` | `Bin(30, 1/2)`（§4 给条件化版本） | **20**（`p=0.049369`） |
| `neg` | `n_neg = #{Δ_u < 0}` | 同上 | 20 |
| `beat` | `n_beat = #{|Δ_u| > floor_u}` | `Bin(30, 1/2)`（**保守**，见 §4-N3） | 20 |

`ALPHA = 0.05`（`mech2.ALPHA`，写死）。**同报** Bonferroni `0.05/2 = 0.025`（`k_need=21`）：
本轮之前已在**成本量**上判过三轮，AoI 是第 2 个指标族 ⇒ 名义 `0.05` 不受 FWER 保护。

### §3.5 判词映射（互斥、覆盖、含显式反向）

| 条件 | 判词 | 下一动作 |
|---|---|---|
| `sign` ∧ `beat` | `AOI-SEPARATES` | **进 R2 训练段**（`H-R2-1`） |
| `neg` ∧ `beat` | `AOI-SEPARATES-REVERSED` | 停，按反向报（不许折进"分不开"） |
| `sign` ∧ ¬`beat` | `AOI-SIGN-ONLY-NO-MAGNITUDE` | 转"把 floor 做小" |
| `neg` ∧ ¬`beat` | `AOI-SIGN-ONLY-REVERSED` | 转"把 floor 做小"，反向必报 |
| ¬`sign` ∧ `beat` | `AOI-MAGNITUDE-ONLY-NO-SIGN` | 转"把 floor 做小" |
| ¬`sign` ∧ ¬`neg` ∧ ¬`beat` | **`NO-RESOLUTION-AT-N30`** | 转"把 floor 做小"，**不换第三个指标** |
| 单位数 ≠ 30 | `INCOMPLETE-PANEL` | 拒答 |
| 任一分量非有限 | `UNDEFINED` + 点名 | 拒答 |
| `A_t` / `A_T` 判词不一致 | `AOI-VARIANT-CONFLICT` | 拒答，待定 |

`sign` 与 `neg` 互斥（`Δ=0` 计入 `n_zero`）；两者同时显著在 `n=30` 下不可能
（`20+20>30` ⇒ 不可能，写入 `C7` 代验）。

## §4 ★ 条件化零分布（**先算，后谈判词**；R2.2 `D3` 的教训）

### §4.1 `N1` 符号零分布的条件化
`p0 = #{floor_u > 0} / 30`（**只用零控对算，不看 `Δ`**）。用精确二项检验 `p0` 是否偏离 `1/2`：
- 若偏离显著（`p<0.05`）⇒ 用 `Bin(30, p0)`（取与观测同侧的那个 `p0`）**重算** `sign` 腿，
- 判词取两者中**较保守**（较大 `p`）的结论；两套 `p` 都报。

★ 已知局限（必须写进交付）：`floor` 是"同模型换 seed"，而 `Δ` 是"同 seed 换模型" ——
两者的零分布**不是同一个**；`N1` 只能诊断"种子下标是否有系统性偏向"，**不能**替代 `Δ` 的零分布。

### §4.2 `N2` 幅度零分布（经验分位）
把 30 个 `floor_u` 当作"零假设下同一模型两次跑之差"的样本，报
`#{floor_u ≥ median|Δ|} / 30` 作为"中位效应在零分布中的经验分位"（越低越有分辨力）。

### §4.3 `N3` `beat` 腿的零分布是**保守**的（不是 `1/2`）
面板两臂用**同一** `plan_seed=2001` ⇒ 严格 CRN。`H0`（两模型等价）下 CRN 使 `|Δ_u|` 通常**远小于**
`floor_u`（后者来自**不同** seed）⇒ `P(beat | H0) < 1/2` ⇒ 用 `Bin(30, 1/2)` 算出的 `p` 是**上界**。
⇒ `beat` 腿不显著时不能说"没有幅度"；显著时才可用。**这条要在交付里逐字写出。**

### §4.4 分层：本轮**不分层**
R2.2 `D3` 已证按 `median(floor)` 分层后 `H0` 下 `beat` 率变成 0.7416（假阳性 24.9%）。
本轮只给不分层的三腿 + 分层的**描述计数**（明确标 `not-a-verdict`）。

### §4.5 `alpha` 敏感性
报 `0.05 / 0.025(Bonferroni) / 0.01` 三档的 `k_need` 与判词是否翻转。

## §5 解释任务（v4.1 队列第 1 条的"为什么"）

**必答**：为什么成本量三次判"测不出"，而机械量一次就差 21×？R1.8 的线索是"`mean_task_aoi` 不经 `x̂`"。

拆成两个可证伪的量（都已能用已落盘数据算，**不是新证据**，只作解释对账）。
★ 分解式（**恒等式**，不是发现）：`median|Δ| / median floor = (median|Δ|/median level) ÷ (median floor/median level)`。

- `H-R24-1a`（**分母假说**）：成本量测不出是因为**地板相对水平**太大。
  量：`median floor / median level`。已见 **0.2131**（成本） vs **0.1223**（AoI）⇒ 只差 **1.74×**。
- `H-R24-1b`（**分子假说**）：AoI 上的**相对效应**本身更大。
  量：`median|Δ| / median level`。已见 **0.4352**（成本） vs **2.5981**（AoI）⇒ 差 **5.97×**。
- 两者乘积必须等于 `median|Δ| / median floor` 的比值：`5.97 × 1.74 = 10.40`，
  实测 `21.24 / 2.042 = 10.40` —— **闭合**（`C11` 逐位核对，容差 1e-9）。

⇒ 预注册的判断：**分子（相对效应）是主因（≈6×），分母（地板）是次因（≈1.7×）**。
★ 这条**推翻**我在写卡前的初始猜测（原以为主因是分母）—— 记在案。
★ **不许**把"成本量测不出"写成"世界模型无用"；也**不许**把"机械量测得出"写成"成本不重要"。
★ 注意 `median(|Δ|/floor)` 与 `median|Δ| / median floor` **不是同一个量**（逐格 `ratio` 跨度 2176×，
  R2.3 已报）⇒ 交付里两者都报，并注明"判据用的是逐对 `beat`，不是任何一个中位比"（R2.2 硬口径②）。

- `H-R24-2`（动作差诊断，**不是判据**）：两臂 `policy_trace_hash` 与 `action_diff_frac`。
  若两臂动作几乎逐位相同而 AoI 差 27 槽 ⇒ 指标不可信，必须停；若动作差很大 ⇒ 差异有行为来源。
  只在交付里报数，不进判词。
