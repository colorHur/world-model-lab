★ 本轮**不**回答"该不该上学习器"，也不回答"信道信息无用"。

## 2. 引擎（写死）与其**声明的信息子集**

### 2.1 状态与动作

- 状态 `(t, P0, P1, m0, v0, m1, v1, b)`。
- 动作 `{HOLD, SEND_0, SEND_1, PROBE_0, PROBE_1}`，每槽**至多一个**资源动作。
- 每槽即时代价 `q·(P0 + P1)`（与 `plan_dp` 的 `imm` 同一口径；`q = plant.q_cost = 1.0`）。

### 2.2 传播（逐位照抄 `plan_dp` / `world` 的既有口径）

- 估计协方差：`f_i(P) = A_i²P + σ_w,i²`（`A=1`）；`SEND_i` **成功** → `d_i(P) = A_i²(1−g_i)P + σ_w,i²`，
  `g_i = P/(P + σ_meas²)`；**失败** → `f_i(P)`（与 `HOLD` 同态）。
- 信道信念：`m ← ρ·m`、`v ← ρ²v + (1−ρ²)`（`ρ = rho_panel[0] = 0.85`，归一 AR，稳态 sd = **1.0**）。
- `PROBE_i`：读数 `y = log h_i + N(0, σ_csi²)`，高斯共轭
  `g_p = v/(v+σ_csi²)`、`m' = m + g_p(y−m)`、`v' = vσ_csi²/(v+σ_csi²)`；`y` 用 **21 点**
  Gauss–Hermite 求积（与 R3.1 同点数，`G9` 用 41 点核对收敛）。
- `p̂_i = p_succ_expected(m_i, v_i, cfg)`（**80 点**求积，`posterior.py` 的决策口径，不改）。

### 2.3 ★★ 声明的**信息子集**（本轮的硬边界）

**窗口内 `ACK/NACK` 不进入信道信念**：`SEND` 的成败只影响任务侧 `P_i`，不改 `(m_i, v_i)`。

理由（不是偷懒）：R3.1 的 `J-B` 已证明在 `ack_mode="exact"`（研究基线）下 `(m,v)` **不是**
充分统计量 —— 要合法使用 ACK 必须携带整条 321 点网格后验，2 用户 × τ=4 的状态数不可算。
两个选项都只能二选一：① 关 ACK（本轮）；② 换成 `ack_mode="approx"` 的矩闭合（那会把
R3.1 刚判死的模型偷偷装回来）。**选 ①**，代价明写。

在 ① 之下，(m,v) **恰好**是充分统计量（高斯先验 + 高斯似然 ⇒ 后验族封闭），
所以本轮 DP **除 `m` 量化外是精确的**；唯一的近似是 `m` 的网格（见 §2.4）。

⇒ **本轮定价的是"探测读数"的信息价值，不是"全部可得信道信息"的价值。**
`ACK` 通道的信息价值仍未被定价（`J-B` 的结构性障碍未解，如实写进交付稿边界节）。

### 2.4 唯一的离散化：`m` 的网格

`m ∈ [-4, 4]`（公开先验 sd = 1 的 4σ），`n_m` 格；只在**探测之后**把 `m'` 吸附到最近格点
（与 R3.1 逐字同手法）；`P`、`v` 不做插值，按可达值精确存键。
`n_m` 阶梯：**τ=3 用 {9,17,33,65}；τ=4 用 {9,17,33}**（预先声明，不按结果加档）。

### 2.5 预算档（★ 预注册，不按结果移动）

`B_RATIO = 0.5` ⇒ `b0 = floor(0.5·τ)`：τ=3 → **1**、τ=4 → **2**；另加 τ=4/`b0=1` 的紧档。
**判据只在 `b0` 紧于 τ 的单元上取**（R3.1 §7-A5 的实测：`b0 = τ` 时 `SEND` 弱支配 `HOLD`，
动作对 `p̂` 完全不敏感 ⇒ `IV ≡ 0` 是设计的产物）。
**τ=1 为恒零控**：探测后无槽可用 ⇒ `IV_free(τ=1) ≡ 0`（R3.1 `G2b` 同款）。

`σ_csi` 阶梯：{0.05, 0.5, 2.0, 50.0}；**零信息对照** `σ_csi = 1e6`（`G5`）。

## 3. 三个**分开报**的量（沿用 R3.1 §7.5-2）

- `IV_free = V(禁探测, b0) − V(允许探测且探测免费, b0)` —— **毛价值**（只问分辨率）；
- `price   = V(禁探测, b0−1) − V(禁探测, b0)` —— 一个资源量子的**价格**（预算越少越贵 ⇒ ≥0）；
- `IV_net  = V(禁探测, b0) − V(允许探测且探测花 1 量子, b0)` —— **净价值**（买不买得起）。

**机制量**（描述，不承载判词）：根状态上「禁探测最优动作集」与「允许探测最优动作集」是否不同
（`n_tie_break`）；以及"禁探测最优动作是否**并列**"（`tie_action_count`）。

## 4. 判据（**看数前写定**）

- 噪声地板 `IV_NOISE = 1e-12`（沿用 R3.1：f64 在 O(1) 量级上的舍入 ~1e-16 高 4 个量级）。
- 分辨率容差 `IV_TOL = 0.10`：`|V_grid − V_ref| ≤ 0.10·|IV_free|`。

| 判 | 取值 | 触发条件 |
|---|---|---|
| `J-A` | `SCALE-2U-TRACTABLE` | `n_states(τ=4,n_m=33) ≤ 1e7` 且 `est_gib ≤ 4.0` 且 `wall ≤ 600 s` |
| | `SCALE-2U-MARGINAL` | 状态数 ≤ 1e9 |
| | `SCALE-2U-EXPLODES` | 其余 |
| `J-B` | `IV-2U-ABOVE-NOISE` | 至少一个**判据单元**（τ∈{3,4}、`b0` 紧、`σ_csi=0.05`、`n_m=33`、对称初值）`IV_free > IV_NOISE` |
| | `IV-2U-BELOW-NOISE` | 全部判据单元 `IV_free ≤ IV_NOISE` |
| `J-C` | `IV-2U-RESOLVABLE` | 对每个 `IV_free > IV_NOISE` 的单元，`n_m*` 存在（阶梯内找到满足 `IV_TOL` 的最小格数） |
| | `IV-2U-UNRESOLVED-BY-GRID` | 有单元找不到 `n_m*` ⇒ **只许写"网格分辨不了"，不许写"信息无价值"** |
| | `IV-2U-NO-MARGIN` | 无 `IV_free > IV_NOISE` 的单元 |

**决策规则（写死）**：
- `IV-2U-BELOW-NOISE` **或** `NO-TIE` ⇒ **R3 收口**，理由写"信道信息在本代价结构下（2 用户、探测与发送共用同一预算档）无可定价边际"，转 R4。
  ★ **不许**改 `σ_csi` / `A` / 过程噪声 / `b0` 追 PASS。
- `IV-2U-UNRESOLVED-BY-GRID` ⇒ 下一轮只做"网格加密/换表示"，**不得**跳到训练。
- `IV-2U-GROSS-ONLY` ⇒ 结论是"**瓶颈是价格，不是信息**"；下一轮要动的是 `c_probe` / 预算结构的**物理依据**（另立协议），不是学习器。

## 7. 跑后修订（本节只追加）

> 注：本节在**主面板（任何 `IV` 数值）之前**写入。此前只跑过"闸"（1 用户逐位对账、
> 暴力枚举一致性、预算单调、`τ=1` 零控、零信息对照），**没有看过任何 `IV_free/IV_net/price`
> 的判据单元读数**。因此下面三条是**跑前修订**，不是"照着结果改判据"。

**§7-A1 判 `J-E` 的形态换掉（原判据是缺陷判据）。**
原卡写"根状态两侧 `SEND` 的值**并列** ⇒ `边际`存在；`NO-TIE` ⇒ R3 收口"。
这条在**非对称 plant**（`plant.sigma_w = (0.02, 0.03)`）上**恒假**：两个用户的噪声不同，
两条 `SEND` 的值不可能相等。而"发给谁"这个边际靠的是**信道随机性**（同一用户这槽好、下槽可能差），
**不是**值并列。⇒ 并列不是边际存在的必要条件，原触发语会把"边际存在"误判成"边际不存在"。
新形态（都不看并列）：
- ① **对称 plant**（`sigma_w` 取同值）上，两条 `SEND` 的值必须相等（`≤1e-15`）——
  这证明"发给谁"确实是一个**值上无差别**、只能靠信息分开的自由度；
- ② **机制**：把探测设为免费后，**首步最优动作**是否从 `SEND_*` 变成 `PROBE_*`
  （`n_probe_chosen / n_judged`）——`IV_free>0` 只说"值变了"，这一条说"改了什么"。

**§7-A2 `m` 网格阶梯加密到 129（判据不变，只加密）。**
原卡 τ=4 只到 33 格，理由是"怕状态爆掉"。**实测**（跑前，只数状态不算值）：
`n_m=33` 的免费探测引擎只有 **9 343** 个记忆化状态、**0.02 s** ⇒ 判断规模的理由不成立。
⇒ 两档都加密到 `{9,17,33,65,129}`。**判据 `IV_TOL=0.10` 与 `J-C` 的定义一字未改**，
只是让"找不到 `n_m*`"这个结论不至于来自阶梯太短。

**§7-A3 `G3` 的单调方向写法。**
`V` 对 `b` 是**非增**（多给预算不会更差）⇒ 违反 = `seq[i+1] > seq[i]`。
首版把方向写反（把"下降"数成"上升"）⇒ 闸自己 FAIL 而引擎没错。**这是判据侧自伤，
不是被测物缺陷**；改正后 `G3` 通过、且 `b=0` 与 HOLD-only 闭式逐位相等（`≤1e-12`）。
附一条实测机制（写进交付稿）：`τ=4` 时 `V(b=3)=V(b=4)`、`τ=3` 时 `V(b=2)=V(b=3)`
—— **最后一槽的 `SEND`/`PROBE` 不影响任何后续决策** ⇒ 值只依赖 `min(b, τ−1)`（饱和律）。
