## 0. 一句话目标

把 R5.5 的 **ADF（单高斯矩匹配）** 换成 **网格直方图信念**，问同一个问题：
**在 L1 语义（ACK/NACK 更新信道信念）下，付费探测还值不值钱，ACK 会不会把它吃掉。**

**换表示，不换世界**：plant（`A`/`σ_w`/`σ_meas`/`q`）、动作集（HOLD / SEND_i / PROBE_i）、
预算刻度（`1 量子 = 8 刻度`，`SEND = 8` 刻度）、`ρ=0.999`、`κ=2`、`log h*=0`、`P0=0.01`、
目标函数 `q·Σ_i P_i` **一字节不动**。只换"信道信念用什么表示 + 怎么更新"。

## 1. 对象与协议变体

**协议变体 `CW-POMDP-v1.5-grid`**（相对 v1.4-ack 只换信念表示）：

| 项 | v1.4-ack（R5.5） | v1.5-grid（本轮） |
|---|---|---|
| 信道信念 | `(m, v)` 单高斯，ACK 用 ADF 矩匹配 | `n_w` 节点直方图 `p`，ACK 用**精确似然乘后归一** |
| 传播 | `m'=ρm`，`v'=ρ²v+(1−ρ²)` | `p' = p @ T`，`T[i,j] ∝ φ((x_j−ρx_i)/√(1−ρ²))`，**按目标行归一** |
| 探测读数 | 高斯观测 `y = x + N(0,σ_csi²)`，GH 节点求和 | **点观测**：读到节点 `j` 即 `p ← δ_j`（`σ_csi→0` 的极限） |
| `ps` | `∫ σ(κ(x−c)) N(m,v)`（80 点 GH） | `Σ_j p_j σ(κ(x_j−c))`（**精确求和**，无求积） |

**动作槽 = `τ−1`**（`V()` 里 `t==1` 直接返回终值，见 R5.3 §7.1-3）。

**四臂**（与 R5.5 同名同义，便于对照）：

| 臂 | PROBE | ACK 更新信念 |
|---|---|---|
| `A0` | 无 | 否（L2） |
| `A0p` | 无 | 是（L1） |
| `VL2` | 有（`p=0`，**免量子但不免槽**） | 否（L2） |
| `VL1` | 有（`p=0`，免量子不免槽） | 是（L1） |

`IV_probe_L2 = A0 − VL2`；`IV_probe_L1 = A0p − VL1`；`IV_ack = A0 − A0p`；
**主量 `survival = IV_probe_L1 / IV_probe_L2`**。

## 2. 明示的**动作空间限制**（不是近似，必须单列，不许静默）

1. ★★★ **`probe_max = 1`（每用户至多探测一次）** —— 主面板用。
   - **它不是"探测无穷次"的等价物**：两次探测之间隔了传播，第二次仍能再定位 ⇒ 这是**真限制**。
   - 依据：R5.0 实测"一次读数占免费臂价值的 83–100%"。**这条是上一轮的经验，不是本轮的前提**，
     所以本轮加一条**限制损失对照**：在最小可算格上用 `probe_max=2` 量一次，把差额报出来。
   - 若 `probe_max=2` 算不动 ⇒ 写 `probe_max_loss=UNMEASURED`，**不许写成"限制无害"**。
2. **网格支撑 `log h ∈ [−4, 4]`**：先验 `N(0,1)` 在支撑外的质量 `≈6.3e-5`，作为读数报出（不当 0）。
3. **`P` 维度不做离散化**：沿用 R5.2/R5.5 的浮点递推（`memo` 键为浮点，同一路径得同一浮点数）。
   ⇒ 本轮**不引入** `P` 的 snap 误差，误差只来自 `n_w`。这是本轮相对 R5.5 的一个净改进，要写进交付。

## 3. 判据（**跑前写死方向**）

### 3.1 硬闸（任一失败 ⇒ 整轮 `NO-VERDICT`，不许用"近似"解释）

| 闸 | 断言 | 容差 |
|---|---|---|
| `g_ps_ref` | `ps(先验)` 网格值 vs 连续参考 `p_succ_expected(0,1)` | 相对 ≤ `1e-3` |
| ★★★ `g_mart` | **在全部 `n_w` 个节点上**：`Σ_y P(y|j)·ps(prop(δ_j⊙lik_y)) − ps(prop(δ_j))` | `≤ 1e-9` |
| `g_mart_prior` | 同一式在**先验**上成立 | `≤ 1e-9` |
| ★★★ `g_mono` | **每格** `A0p ≤ A0`（零容差） | `≤ 0` |
| ★★★ `g_nonneg_ack` | **每格** `IV_ack ≥ 0`（`A0p ≤ A0` 的等价写法，单列防混） | `≤ 0` 违例 |
| `g_noinfo` | `κ=0` ⇒ `lik≡1/2` ⇒ 后验不动、`VL1 == A0p == A0` | `≤ 1e-12` |
| `g_budget` | `A0(b)` 关于 `b` **严格**递减 | 严格 |
| `g_nw3` | 三点 `n_w` 的 `A0p` 相对变化 ≤ 30%（否则 `GRID-UNRESOLVED`） | 30% |
| `g_size` | 四臂 `n_states>0`、无撞顶（`STATE_CAP=6e6`） | — |
| `g_ast` | 源码无 `int(p)` / `int(probe_cost)` 截断 | 0 命中 |
| `g_fp` | `n=1` 与 `n=2` 的 plant 指纹互异、`n_w` 三点互异 | — |

★★★ `g_mart` 与 `g_mono` 是本轮**新增的两条**，直接来自 R5.5 的教训：
- 上一轮 `G2-ackpost` 把 `(m,v)` 的**矩**对到 `9.4e-11` 全过，而 DP 真正消费的 `ps` 偏 `4.25e-3`
  ⇒ **闸要查下游真正消费的量**。所以本轮闸直接建在 `ps` 上，且**不是只查根节点**。
- 上一轮 `A0p > A0` 是 ADF 的偏置，被误读成"信息更多反而更差"。本轮把它写成硬闸：
  **精确贝叶斯下 `A0p ≤ A0` 必须零例外**；出现违例就是**接线错或数值错**，不许解释成物理。

### 3.2 主判（只在硬闸全过后才允许计算）

主量 `survival`，取 `b` 最大的那条腿（本轮 `b=24`）+ 最大的 `τ`（`τ=6`），并在 `b=16, τ=6` 复算。

| `survival` | 判词 |
|---|---|
| `n_measured = 0`（分母 `IV_probe_L2 ≤ 1e-12` 逐位零） | `UNMEASURED-DENOMINATOR-ZERO` |
| `> 1 + 1e-9` | `WIRING-SUSPECT`（精确信念下不可能） |
| `≤ 0.10` | `ACK-EATS-PROBE` |
| `≥ 0.90` | `ACK-DOES-NOT-EAT-PROBE` |
| 其他 | `ACK-PARTIALLY-EATS-PROBE` |

**另报一条**（不当主判）：`IV_ack` 与 `IV_probe_L1` 的**逐格符号谱**，以及 `b=8` 上是否仍逐位 `A0p==A0`。

### 3.3 否定条件（写死；命中就**不下判词**，只报读数）

1. `g_mono` 或 `g_nonneg_ack` 出现**任一格**违例 ⇒ `NO-VERDICT-WIRING`。**不许**写成"信息有害"。
2. `n_w` 三点 `A0p` 相对变化 > 30% ⇒ `GRID-UNRESOLVED`，`survival` 不报数（只报区间上界）。
3. 主格撞 `STATE_CAP` ⇒ 报 `SCALE-WALL`，**降 `n_w` 重跑并把 `n_w` 写在数字旁边**，不许跨 `n_w` 相减。
4. `IV_probe_L2` 在**所有**格逐位零 ⇒ `PROBE-WORTHLESS-GRID-L2`（这会是 L2 上的新负结果，与 R5.1–R5.3 的
   正例冲突 ⇒ **必须当场核 `g_ps_ref` 与 `g_mart`，先怀疑表示，不怀疑物理**）。
5. 本轮**不预言**一定有正例；也不允许为了提高 `survival` 的可测性去调 `ρ`、`κ`、`σ_w`、`τ`、`b`。

## 4. 面板与规模预算（跑前算，跑后报实测）

- `n_w ∈ {129, 257, 513}`（三点分辨率；`Δ = 8/(n_w−1)`：`0.0625 / 0.0312 / 0.0156`；
  传播核 sd `=√(1−ρ²)=0.0447` ⇒ `n_w=129` 时每 sd 仅 **0.72 格**，**偏粗，必须报**）。
- `τ ∈ {5, 6}`；`b ∈ {8, 16, 24}`（1/2/3 次发送）。
- `n_users = 1`（主，便宜，先跑）+ `n_users = 2`（**只在规模允许时**跑；`n=1` 的 `IV_probe` 在 R5.5 上逐位零，
  所以 `survival` 的分母必须来自 `n=2`）。
- 规模上限 `STATE_CAP = 6e6`；**memo 按腿累加**（单格可行 ≠ 整腿可行，R4.2 教训）。
- 先跑 `--size-only`（升序 `n_w`，撞顶即停），再按实测挑能跑完的最小三点。

**算不动是允许的结果**（`SCALE-WALL`），**编一个数是禁止的**。
