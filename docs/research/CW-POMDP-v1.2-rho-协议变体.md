## 1. 改了什么

**唯一改动**：`ChannelConfig.rho_panel` 取**单值** `(ρ,)`，`ρ ∈ {0.85, 0.90, 0.95, 0.98, 0.995, 0.999}`。
`config.py` **一个字节都不改**（v1.1 的默认 `(0.85, 0.98)`、`mainline_config()`、
`v11_validate()` 全部保持原样；变体在实验脚本里构造配置对象时替换）。

**没改的**（逐条列，便于审计）：

| 动作空间 | `HOLD / SEND_i / PROBE_i` | 同 |

## 2. `ρ` 的物理含义（这是"改世界"的依据，不是调参）

归一 AR(1)：`log h_{t+1} = ρ·log h_t + sqrt(1−ρ²)·s_t`，`s_t~N(0,1)`。
稳定分布恒为 `N(0,1)`（**与 `ρ` 无关**；旧文档里"`ρ=0.98` 稳态 sd=5.03"是把未归一公式套错了）。

| `ρ` | 5 槽后自相关 `ρ⁵` | 去相关时间常数 `−1/ln ρ`（槽） | 方差恢复时间 `1/(1−ρ²)`（槽） |
|---|---|---|---|
| 0.85 | 0.4437 | 6.15 | 3.604 |
| 0.90 | 0.5905 | 9.49 | 5.263 |
| 0.95 | 0.7738 | 19.50 | 10.256 |
| 0.98 | 0.9039 | 49.50 | 25.253 |
| 0.995 | 0.9752 | 199.50 | 100.251 |
| 0.999 | 0.9950 | 999.50 | 500.250 |

（表由 Python 现场计算，非手抄。`ρ=0.85` 对应「一帧 1 ms 尺度快衰」的抽象，`ρ≥0.995` 对应
「整个窗口内信道基本静止」的抽象 —— 两者都是**开发面板的抽象**，不是任何真实系统的拟合参数。）

★ 一条**结构性恒等式**（本轮 `A0` 闸的靶子）：根状态 `m=0, v=1` 是 `ρ` 映射的不动点
⇒ **无探测臂与 `ΔV_q` 逐位与 `ρ` 无关**，`ρ` 只通过「读数之后信念怎么衰减」起作用。
这条把「跨 `ρ` 比较」从"比两个不同的世界"收敛成"比同一个世界的不同记忆长度"。

## 3. 证据纪律

1. **v1.1 的全部旧证据仍是 `ρ=0.85`**，一份不覆盖、不重跑；v1.2 的证据放**新目录**、
   新 `run-id`（含源码内容哈希），表头标 `CW-POMDP-v1.2-rho`。
2. **同一个比值不许跨档取数**：`ratio = IV/ΔV_q` 的分子分母必须来自**同一个 `ρ` 的同一个引擎**。
   跨档只允许比「同一格在不同 `ρ` 下的 `ratio`」，且必须写成 `ratio(ρ₁)/ratio(ρ₂)` 并注明这是
   **世界依赖**（memory dependence），不是方法改善。
3. 本变体**只**用于回答「有效期」问题；它不产生任何关于「方法更好」的主张。
4. 变体不引入新动作、新信息权限、新特权；策略可用信息与 v1.1 完全相同。
