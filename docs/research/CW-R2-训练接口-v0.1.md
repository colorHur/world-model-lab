## §1 三条不许动的（改动 ⇒ 另立协议，本轮结论作废）

1. **信息权限**：训练出来的模型只能看 `SchedulerView`（公开视图）。`require_view()` 的类型恒等 +
   键集相等两条仍在；`cost_true_by_user` / `w_realized` / 失败 SEND 的 `y_t` **一律不可见**。
   `deploy(privileged=True)` 必须继续 `PermissionError`。
2. **协议** `CW-POMDP-v1.1`；事件配对 `slot`；`c_probe = c_data = 1`。
3. **判据常量**：`mech2.ALPHA`、`mech3` 任何常量、`k_need` 表**不许**为了某轮改动。

## §2 模型容量（上限，写死）

| 项 | 上限 | 理由 |
|---|---|---|
| 可训练参数 | **≤ 5×10⁴** | R2 立项卡 `H-R2-1` 写的是"小学习模型"；超过就不是"小" |
| 输入 | `SchedulerView` 的 **20 个公开字段**（键集由 `require_view` 保证） | 不许多喂 |
| 输出 | 与 `ModelOutput` 同构（逐用户预测代价 + 不确定度） | 不许直接输出动作（那是策略，不是模型） |
| 结构 | 至多 2 隐层 / 至多 64 宽 | 与"≤5e4 参数"自洽 |

★ **不许**用"加深加宽"去换 PASS。要换先证明"当前容量下已经收敛"（学习曲线平台 ≥ 20% 训练预算）。

## §3 训练预算（本机 CPU 可跑）

| 项 | 值 |
|---|---|
| 训练 episode 集 | `0–69`（**与 dev `100–114` 不相交**） |
| 每轮梯度步上限 | 2×10⁴ |
| 墙钟上限 | **≤ 30 min**（纯 CPU） |
| 训练种子 | **≥ 3 个**（`7 / 17 / 27`），**必须分层**报告 |
| 早停 | 允许，但**只看训练集**；dev 集只用于最终评价 |

## §4 优化目标（写死）

```
L = MSE( 逐用户预测代价 , 逐用户真实代价 )   ← 仅在训练集上
```

- **不许**把评价指标（`A_t`）直接当训练损失：那会让"评价"与"优化"同源，
  于是"模型好"变成同义反复（R2 立项卡已写明：评价只用 `A_t` + `cost_true_per_step`）。
- 允许加正则（权重衰减），但**不许**按 dev 集调正则系数。

## §5 评价（只两条，写死）

1. **主**：`A_t`（非删除型全时隙均值，R2.4 口径）
2. **必报**：`cost_true_per_step` + **逐用户 `r_i`**（R17）

**禁用**：`ku` / `kf` / `share*`（`OBJECTIVE["forbidden"]` 已在代码里写死）；
`mean_task_aoi` 旧口径（删窗口）；任何"综合分"。

## §6 比较与分层（防"用平均掩盖受损用户"）

- 统计单位 = **完整 episode**（不是时间步），按 `(plant, ep)` 配对。
- **必须按训练种子分层报**：`Δ(seed)` 三个值 + 合并值，**不许**只报合并。
- 主判仍用逐对符号/幅度两腿 + 精确二项（`k_need` 按 `n` 现算），**不写计数阈值**。
- 报告必须含：`median|Δ|`、`median floor`、`|Δ|/floor`、逐用户 `r_i` 分布、
  以及"有 ≥1 用户成本上升的单元数"。**Pareto 权衡允许，但要用这些列显式表达。**

- 这套接口的**可复用部分**是：公开视图的权限边界 + AST 扫描 + 评价禁用表 + 反例自证。
  它对应 AI 工程岗的"评测/对齐基础设施"，是本课题里**最像工程能力**的一块。
