## §2 学习假设 `H-R2-1` 的具体化（"损失怎么算、分母是谁"）

**被测物定义（本轮唯一的学习对象）**

| 项 | 定义 |
|---|---|
| 模型 | `ResidualReadout`：输入 = **15 维公开特征**（`x_hat, P_hat, stamp, task_aoi, h_mean, h_var, csi_stamp, csi_aoi` × 逐用户 8 + 全局 7：`prior.{x_mean,x_var,h_log_mean,h_log_var}, t, budget_left, budget_total`），输出 = **只改均值**：`x̂ = x̂_base + Δ`，`P̂ = P̂_base`（**原样**） |
| 结构 | `d_in=15 → 32 → 32 → 1`（2 隐层、宽 32 ≤ 64）；参数 `（15×32+32）+（32×32+32）+（32×1+1）= 512+1056+33 = 1601` |
| 初始化 | 末层权重与偏置**全零** ⇒ `Δ ≡ 0` ⇒ 逐步**逐位**等于 `belief_readout`（闸 `G2` 钉） |
| 训练损失 | `L = mean_{样本,用户} (x̂ − x_true)²`（**状态空间**；`x_true` 只作标签，永不进输入） |
| 分母 | 相对损失 = `MSE_learned / MSE_base`，`MSE_base` = 同一个 dev 样本上 `x̂_base` 对同一标签的 MSE；**逐 episode 配对**取中位 |
| 训练数据 | 行为策略 = **研究基线的规划器本身**（`raw` ≡ `belief_readout`，R2.1 `B3` 已证逐位恒等）；`train` ep `0–69` |
| dev | ep `100–114`（`T4b` 守着与训练集零交集），**只用于最终评价** |

**假设**：`H-R2-1` = dev 上 `A_t(learned) / A_t(baseline) ≤ 1.05`（即劣化不超过 5%）。

### §2.1 `C4` 裁定：为什么主损失是状态空间 MSE，而不是接口卡 §4 字面的"代价空间 MSE"

接口卡 §4 写 `L = MSE(逐用户预测代价, 逐用户真实代价)`。照字面实现会有一个**结构缺陷**：

- 逐槽代价 = `q·x²（+ r·u²）`，对 `x` 的**符号不敏感**；
- 而规划器把 `x̂` 当**有符号**状态做传播（`x̂' = α x̂`）与候选打分 ⇒ 符号错了，`x²` 一点不差。
- ⇒ 代价空间损失对"符号错误"**恒不敏感**，训练出来的模型可以代价 MSE 很低而传播全错。

裁定：**主损失用状态空间 MSE**，代价空间 MSE 只作**必报诊断**（`L_cost_learned / L_cost_base`）。
可检查性：闸 `G6` 构造一个"只翻符号"的假模型，要求状态空间损失**显著变差**、代价空间损失**逐位不变**
（若两者都不变 ⇒ 这条裁定就是空话）。

### §2.2 ★★ headroom 声明（本卡最重要的一条，防止把"打平"包装成"学到"）

在本环境里，`x̂_base` 是**已知线性高斯 + 精确 ACK** 下的接收端后验 ⇒ 它是该信息集上的 MMSE 估计。
因此留给学习器的**期望空间是 0**：

- 学习器**最好只能打平**；"显著优于基线"在理论上不该出现。
- 所以主判不是"更好"，而是**不劣化**（§2 的 ≤5%）。
- ★ 若闭环真出现 `A_t(learned) < 0.95 × A_t(baseline)` ⇒ 按 §3 判 `SUSPECT`，**先查泄漏/缺陷**，
  不许直接写成"学习模型超过解析基线"（那条结论在数学上要求基线不是 MMSE，本环境不满足）。

## §4 学习曲线平台判据

**平台** = 最后 **20%** 训练预算（即最后 `0.2 × N_STEPS` 步）内，训练损失相对下降 `< 1%`。
未平台 ⇒ 本轮**不许**报告 dev 结论，判 `NOT-CONVERGED`。
（判据的机器化：`loss[start] → loss[end]` 的相对差；`start` = `0.8·N` 步处的移动平均。）
