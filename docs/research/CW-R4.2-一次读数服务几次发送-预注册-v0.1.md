## 0. 为什么这一轮问「`b` × `τ`」——R4.1 的机制句自相矛盾

R4.1 §7.1-4 写的机制是：

> 「峰值格每一档都是 `(τ=5,b=1)` 的**单次发送时机**问题；读数一旦覆盖整个窗口，
> 就**没有第二个发射机会**去用它的新鲜度 ⇒ 线性增长的前提在 `τ≤5` 里不存在。」

这句话与它自己的数据**在方向上相反**。同一个证据文件里（`r41.json`，`ρ=0.999, α=2.5, P=0.01, τ=5`）：

| `b`（窗口内可用量子数） | `ratio_free`（毛价值/量子） | `probe_chosen` |
|---|---|---|
| 1 | **0.15254** | True |
| 2 | **0.04399** | True |
| 3 | **0.0**（逐位零） | **False** |
| 4 | **0.0**（逐位零） | **False** |

**量子越多，读数的毛价值越低，到 `b≥3` 直接归零，而且最优策略连"免费探测"都不用。**
若"没有第二个发射机会"是卡点，那么 `b=3`（探测后还剩 2 次发送）应当**更**值钱，而不是归零。

所以本轮把问题从"窗口够不够长"改成**"读数的价值随可用发送数怎么变"**：

> **一次读数能服务几次发送？** 是"越多发送、同一读数用得越多 ⇒ 更值钱"（R4.1 的隐含假设），
> 还是"发送数一够、探测就变得**不必要**"（替代品）？

这两个答案对论文的含义完全不同：
前者说"再给我更长窗口/更多次发送就能买得起"；后者说**「买不起」的成因不是价格、不是窗口，是任务结构**。

## 1. 三条**互相排斥**的跑前预测（数据只能选一条）

记 `V_free(b,τ)` = 免量子探测臂的最优期望成本，`IV_free = A0 − V_free`，
`ratio_free = IV_free / ΔV_q`（单位：个量子），`b = ⌊预算/量子⌋`，`τ` = 窗口槽数。

- **`Q-A`（多服务放大 / R4.1 的隐含假设）**：一条读数能被**每一次**后续发送用上
  ⇒ `IV_free(b)` 随 `b` **单调升**，且 `b=3`（探测后剩 2 次发送）≈ 2× `b=2`。
  按此律外推 `(τ=5,b=3,ρ=0.999)` 应 ≈ **0.088**，`(τ=8,b=3)` 应 **>0.3**，跨 1 量子 ⇒ **买得起**。
- **`Q-B`（稀缺替代）**：信息价值来自**稀缺**——预算刚好不够把所有用户都服务到"不必挑时机"时，
  才需要知道信道去挑人/挑时机；一旦多出一个量子，最优策略改用**冗余额度对冲**而不是**买信息**。
  预测：`IV_free(b)` 对 `b` **弱单调不增**，且 `b≥3` 在 `α=2.5, P=0.01` 上**逐位为零**。
- **`Q-C`（窗口主导）**：`b=2` 的毛价值随 `τ` 增长（`τ=4→0`、`τ=5→0.044` 已见阈值），
  继续拉长窗口（`τ=6,7,8`）会接近线性涨。预测 `ratio_free(b=2,τ=8,ρ=0.999) ≥ 1.6 × 0.044 = 0.070`
  且**持续上升**（不饱和）。

★ `Q-A` 与 `Q-B` 在 `b` 轴上互斥；`Q-B` 与 `Q-C` 可以同时成立（稀缺 + 窗口在 `b=2` 上仍起作用），
  但 `Q-A` 与 `Q-B` 不能。**判据必须能分开这三种，而不是只判"买不买得起"。**

## 2. 本轮**新增的一个可算事实**（不是猜想，是恒等式）

`IV_paid ≤ IV_free`（同 `b` 下付费臂的策略集 ⊆ 免量子臂的策略集 ⇒ `V_free ≤ V_paid`）。
在 `r41.json` 的 210 格上**零违例**（本轮把它做成闸 `g_paid_le_free`）。

更重要的一条：**`b=1` 上付费探测结构上无发送可用**——探测吃掉唯一的量子后 `b−1=0`，
DP 里 `if b>=1` 的 SEND 分支不再进入 ⇒ 读数不影响任何后续动作 ⇒ `IV_paid(b=1) ≡ 0` **逐位为零**。

而 R4.0/R4.1 的**价格距离**（"便宜 9.5×/8.8×/6.2×"）**恰恰是用 `b=1` 那格的毛价值算的**。
在整数量子记账下，`b=1` 的毛价值**无法被购买**：把价格从 1 降到 0.106 也买不到"半个发送"。
⇒ 本轮必须把价格距离改成**只在 `b≥2`（可购买区）里算**，并同报 `b=1` 的不可购买性。

### 3.1 `n_m`（`m` 网格点数）的**跑前规则**（先跑 `--scale` 探针，只读状态数/秒，不读判据量）

### 4.2 判词（组合唯一，按序取第一条命中）

- `W1` **窗口检验**（`ρ=0.999, b=2`）：`R_W := ratio_free(τ=8) / ratio_free(τ=5)`
  - `WINDOW-STILL-GROWS`：`R_W ≥ 1.60`（≈ 按 `τ` 线性）**且** `ratio_free(τ=8) > ratio_free(τ=7) > ratio_free(τ=6)` 严格增；
  - `WINDOW-SATURATES`：`R_W < 1.30`；
  - 其余 → `WINDOW-MIXED`（同报 4 个点，不下二元结论）。
- `S1` **多发送检验**：`b=3`（或 `b=4`）上 `IV_free > max(1e-12, 0.1×IV_free(b=2))` 视为"多一次发送放大了读数价值"
  - `MULTI-SEND-AMPLIFIES`：存在这样的格；
  - `MULTI-SEND-NEUTRAL`：全部 `IV_free(b≥3) ≤ 1e-12`（逐位零）；
  - `MULTI-SEND-DECAYS`：`0 < IV_free(b≥3) ≤ 0.1×IV_free(b=2)`。
- `P1` **购买检验**：`max ratio_free`（`b≥2` 区） vs 1
  - `BUYS-WITH-SPARE-SLOTS` / `NOT-BUYS`。
- `D1` **价格距离（可购买区重算）**：`d = 1 / max_{b≥2} IV_free`（个量子）；同报 `b=1` 的
  `IV_free` 与"不可购买（整数）"标注。
- `H1` **稀缺替代律**：对每个 `τ`、`ρ`，`IV_free(b)` 非增（`tol 1e-15`）⇒ `SCARCITY-SUBSTITUTION-HOLDS`，
  否则报出违例所在格。

### 4.3 汇总（唯一）

```
gates 有失败                                   → NO-VERDICT-GATE-FAIL

```

## 5. 否定条件（跑前写死：什么结果会推翻我自己）

1. **`b≥3` 出现 `IV_free > 1e-12`** ⇒ `Q-B` 被否证，"多发送 ⇒ 信息不必要"错。
2. **`τ=8, b=2` 的 `ratio_free > 1`** ⇒ R4 收口结论被推翻，必须改写论文方法节。
3. **`ratio_free(b=2)` 在 `τ=5..8` 严格增且 `R_W ≥ 1.6`** ⇒ `Q-C` 成立，
   R4.1 的"饱和"只是 `τ≤5` 的窗口效应，`τ≥9` 必须继续扫。
4. **`g_probe_live` 在零格上找不到 `PROBE_i` 键** ⇒ 那些零是**接线缺陷**，不是结论。

## 6. 不要做（先写死）

- 不把 `b=1` 的毛价值折成"价格须降几倍"（整数记账下不可购买）。
- 不把 `α=2.5, P=0.01, 2 用户` 的结论外推到 `κ<1`／3 用户／`P=0.05`／`τ≥9`。
- 不用 `ρ` 两档的比值当"记忆长度效应"（R4.1 已证饱和）。
- 不开训、不升过程噪声、不改 `c_probe`、不动被测物一字节。
- 不重跑旧 P3；不改写任何历史证据（只追加更正指针）。

## 3.2 可行性修订（写于面板之前，只基于**状态数实测**，未读任何判据量）

`date` 实测 **2026-10-26 19:1x +08:00**。探针只打印 `n_states / sec / capped`，
**刻意不打印 A0/IV**，所以本节是在"没看见结果"的情况下写的。

实测（`ρ=0.98, α=2.5, P=0.01`，`STATE_CAP=6e6`）：

| `(τ,b)` | `n_m=65` | `n_m=33` | `n_m=17` |
|---|---|---|---|
| (8,4) | **6,000,007 capped** | **6,000,002 capped** | 5,855,828 ok / 52.5 s |
| (8,3) | **6,000,008 capped** | **6,000,005 capped** | 3,213,620 ok / 33.7 s |
| (8,2) | **6,000,001 capped** | 3,402,837 ok / 40.8 s | ok |
| (7,4) | **6,000,007 capped** | 2,864,235 ok / 17.5 s | ok |
| (7,3) | 5,856,722 ok / 37.8 s | ok | ok |
| (7,2) | 3,759,610 ok / 29.1 s | ok | ok |

⇒ **一个统一网格跑不完 `τ=8`**。按 STATE §7.2 预授权的三选一（降 `n_m` / 对 `b` 截断 / 分片记忆化），
本轮选**前两个的组合**（分片记忆化会改被测物的记忆化语义，不做）：

- **腿 `A`（主判，`n_m=33`）**：`τ∈{5,6,7}` × `b∈{1,2,3,4}`（`τ=7,b=4` 实测 2.86e6 可行）
- **腿 `B`（窗口，`n_m=17`）**：`τ∈{5,6,7,8}` × `b∈{1,2,3,4}` —— **唯一能到 `τ=8` 的自洽网格**
  （`τ=8,b=4` 实测 5.86e6 可行；`b≥3` 在 `τ=8` 上**只有 `n_m=17` 可行**）
- **腿 `C`（分辨率核对，`n_m=65`）**：`τ∈{5,6,7}` × `b∈{1,2,3}`（`τ=7,b=3` 实测 5.86e6 可行；
  `b=4` 在 `n_m=65` 上不可行，**明确记为未扫**）

**跨网格纪律（本节新加，跑前写死）**：
1. 任何 **`b` 轴**或 **`τ` 轴**的比较**只在同一腿内做**（同 `n_m`）；
2. 跨腿只允许做**方向一致性**核对，**不许**把两个腿的数相除当效应量；
3. `τ=8` 的任何读数**只能与腿 `B` 内 `τ=5,6,7` 比**，不得与腿 `A/C` 的细网格值比；
4. 分辨率三点检查改在 **`(τ=7, b=2)` 与 `(τ=7, b=3)`** 上做（`n_m∈{17,33,65}` 全可行）；
   `(τ=8, b=2)` 只能两点（`65` capped）⇒ **必须报"两点，不能判稳/不稳"**（R4.1 硬口径 §7.5-1）。

本节之后，判据（§4）**一字不改**，只是把"哪个腿算哪个判词"写清：
`W1` 用腿 `B`（并报腿 `A/C` 在 `τ≤7` 的方向核对）；`S1/H1` 每条腿各算一次、全部报出；
`P1` 取**所有腿**的 `b≥2` 最大值（带网格标签）；`D1` 用**腿 `C`（最细网格）** 的可购买区最大值。
