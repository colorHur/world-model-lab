## 1 题名与摘要

**中文**：预算受限远程估计中信道测量的决策价值与资源机会成本
**English (working)**: *The Decision Value and Opportunity Cost of Channel Measurement in Budget-Constrained Remote Estimation*

**摘要（只写已测到的）**

> 在"发送整包不可分、预算按整数刻度记账"的远程估计设定下，我们把"是否花预算探测一次信道"
> 建成有限视界 POMDP 并**精确求解**（网格贝叶斯、无函数近似）。在 `n=2` 用户、`τ∈{5,6}`、
> `b∈{8,9,10,12,16,20,24}` 刻度、探测价 `p∈{0,1,2,4,8}` 的 42 个格上，
> 得到两点可复核的结论：
> **(i)** 探测价值对价格**不是连续响应**，而是**阶跃** —— 设 `s = b mod 8`（预算余数），
> 则 `IV_probe(p) = IV_probe(0)·1{p ≤ s}` 在 **210/210 个读数上逐位成立**；
> `p` 一越过余数，最优成本与**从不探测完全相同**。
> **(ii)** 在能测到的所有格里，一次探测的价值上限是 `A0p` 的 **0.061%–0.620%**。
> 二者合起来给出一个**否定性但可操作**的结论：在本文模型类里，"把测量定价"不是连续的资源分配问题，
> 而是**整数配额**问题；且在已扫描的参数区内，该测量的决策价值小到不足以支撑"按价购买测量"的设计。
>
> **摘要不主张**：不主张测量普遍不值钱（只覆盖已扫描的 `(b,τ,p)` 与 `n=2`、`ρ=0.999`、点观测）；
> 不主张世界模型/学习方法有优势（本文零学习组件）。

## 3 方法与协议

| 维 | 设定 |
|---|---|
| 对象层级 | **L1**：ACK/NACK 以精确似然更新信道信念（`world.py` `ack_mode="exact"`）；★ L2 结果只作诊断，不作主图 |
| 状态 | `(t, P, m, v, b, w-grid)`；信念用**网格直方图**（`n_w ∈ {129,257,513}`，`log h ∈ [-4,4]`），`ps` 精确求和，`P` 不离散化 |
| 动作 | `{SEND, PROBE, IDLE}`；`probe_max = 1`（每格一次）；`probe_total = 1`（**全局一次**，见 §6 限制） |
| 代价记账 | 1 次发送 = **8 刻度**（不可分整包）；探测价 `p ∈ {0,1,2,4,8}` 刻度；★ 探测**另占一个动作时隙**（`p=0` 也占） |
| 视界 | `τ ∈ {5,6}`（动作槽 = `τ−1`） |
| 指标 | `IV = A0p − VL1`，单位 = 发送量子（1 量子 = 8 刻度）；**必同报** `A0p` 与 `IV/A0p` |
| 概率模型 | `ρ = 0.999`、`P0 = 0.01`、`σ_w ∈ {0.02, 0.05}`、`κ = 2`（观测噪声倍率） |
| 探测类型 | **点观测**（`σ_csi → 0`，近乎完美 CSI；真实量化/时延/估计误差**未建模**） |
| 求解 | 精确 DP（无训练、无 episode、无函数近似）；确定性 ⇒ **无置信区间**，只报网格三点与状态上限 |
| 统计单位 | 每个格 = 一次确定性求解；不做"时间步凑样本" |

## 6 限制（写进正文，不藏在附录）

1. **点观测**：探测 = 近乎完美 CSI（`σ_csi → 0`）。真实量化、时延、估计误差**未建模**。
2. **`n = 2`**：只有两用户；`n ≥ 3` 的状态规模已撞 `6e6`（R5.2/R5.3 记录）。
3. **`probe_max = 1`、`probe_total = 1`**：每格最多一次探测、全局最多一次。该限制的代价 **只在 `n_w=33` 量到**
   （4 格：1 格无靶子、2 格逐位 0、1 格 0.14%），`n_w=129` **`UNMEASURED`**
   ⇒ 本文所有幅度都应读作"在 `probe_total=1` 下的值"。
4. **单 `ρ = 0.999`**、单 `κ = 2`、`σ_w ∈ {0.02,0.05}`：**无跨参数检验**。
5. **无强基线**：本轮没有与 (a) 从不探测的最优策略、(b) 视 CSI 免费的最优策略、(c) N2 的 pilot-free 方案
   做**同信息同预算**对比 ⇒ 不能声称"探测相对某基线的价值"。
6. **无闭环物理时域**：指标是 `A0p − VL1`（估计器成本），**未**桥接到固定物理时域的闭环控制成本。
7. **无置信区间**：确定性 DP，不报 `CI`；只报网格三点与状态上限。
